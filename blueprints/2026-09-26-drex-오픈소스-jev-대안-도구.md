# Drex – 오픈소스 Jev 대안 도구

## 쉽게 말하면
Drex는 유료 AI 모델(Jev) 대신 무료로 쓸 수 있는 오픈소스 버전이라고 보면 됩니다. 자동차로 치면 고급 브랜드차 대신 성능은 비슷한데 공짜로 뜯어 고칠 수 있는 오픈소스 차량이 나온 셈입니다. 코드가 공개돼 있어서 내 컴퓨터에 직접 설치해 돌리거나, 필요에 맞게 뜯어고쳐 쓸 수 있습니다.

## 이걸로 할 수 있는 것
1. Jev API 비용 없이 로컬 맥북에서 반복 업무(요약, 분류, 초안 작성)를 자동화할 수 있습니다.
2. Claude Code와 함께 "저비용 보조 모델"로 붙여, 간단한 작업은 Drex가 처리하고 복잡한 작업만 Claude Code로 넘기는 비용 절감 파이프라인을 만들 수 있습니다.
3. Drex를 활용한 "무료 Jev 대체 자동화 세팅" 자체를 상품화해서 소규모 기업·1인 사업자에게 컨설팅/납품할 수 있습니다.

## 개요
Drex는 Jev(TypeSafe AI System One)의 오픈소스 대안으로, 자체 호스팅이 가능해 API 비용과 데이터 외부 유출 우려를 동시에 줄여줍니다. 개인 맥북에서 실행하면 특정 반복 작업(분류, 태깅, 룰 기반 판단)을 무료로 자동화할 수 있고, Claude Code 워크플로우의 앞단 필터 역할로 붙이면 전체 AI 파이프라인 비용을 낮추는 데 활용할 수 있습니다.

## 구현 가능성: 중
- 근거: 출처 기사(nace.ai/drex)가 HN 게시물로, 포인트 1점·댓글 0개 수준이라 검증된 정보가 거의 없고, 실제 기능·설치 난이도·맥북 호환성이 불확실합니다.
- Jev 자체가 2026-09 출시된 신규 모델이라, "대안 도구"인 Drex도 매우 최신이거나 아직 미성숙한 프로젝트일 가능성이 높습니다.
- 오픈소스이므로 기술적 진입장벽은 낮지만, 실제 프로덕션 자동화 수익화까지는 검증/테스트 시간이 추가로 필요합니다.

## 필요 도구
- Drex 오픈소스 저장소 (무료, GitHub 추정 — 정확한 리포지토리 URL은 nace.ai/drex 방문 후 확인 필요)
- 맥북 로컬 실행 환경: Python 또는 Node.js 런타임 (무료)
- Docker (선택, 무료) — 격리된 환경에서 Drex 실행 시
- Claude Code CLI (기존 사용 중, 유료 API 크레딧 필요)
- (선택) ngrok 또는 유사 터널링 도구 — 로컬 Drex를 API처럼 외부에 노출할 경우 (무료 티어 존재)

## 구현 단계
1. https://www.nace.ai/drex 페이지와 HN 댓글(현재 0개)을 직접 확인해 Drex의 실제 소스코드 저장소 링크와 라이선스를 파악합니다.
2. 로컬 맥북에 Drex를 클론/설치하고 `README`에 따라 최소 실행(hello world 수준 추론 요청)까지 성공시킵니다.
3. Drex가 지원하는 입출력 형식(텍스트, JSON 등)을 확인하고, 현재 운영 중인 ai-info-radar 같은 반복 작업(요약·분류) 중 하나를 골라 Drex로 대체 테스트합니다.
4. Claude Code 워크플로우에 "1차 필터 = Drex, 2차 정밀 처리 = Claude Code" 구조로 연결해 비용/속도 차이를 측정합니다.
5. 측정 결과(정확도, 속도, 비용 절감분)를 문서화하고, 쓸만하면 "Jev 유료 비용을 Drex로 대체" 사례로 블로그/포트폴리오화해 컨설팅 영업 자료로 활용합니다.

## 예상 공수
- 탐색 및 설치: 2~3시간 (난이도: 중, 문서화가 빈약할 가능성)
- 파이프라인 연동 테스트: 4~6시간 (난이도: 중~상, 실제 성능 검증 필요)
- 총 예상: 1~2일 작업 (수익화 콘텐츠화까지 포함 시 3일)

## 리스크/유의점
- 출처 신뢰도가 낮음 (HN 포인트 1, 댓글 0) — 실제 존재/품질 여부를 먼저 검증해야 하며, 과장된 마케팅 페이지일 가능성 배제 불가.
- Jev와의 기능 격차(정확도, 컨텍스트 길이 등)가 클 경우 "대안"으로서 실용성이 떨어질 수 있음.
- 로컬 모델 실행 시 맥북 리소스(메모리/전력) 부담 확인 필요.
- 오픈소스라도 라이선스 조건(상업적 이용 가능 여부)을 반드시 확인 후 수익화 활동에 사용해야 함.
