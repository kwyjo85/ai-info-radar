# Python 25줄로 Jev 구현하기

## 쉽게 말하면
Jev 같은 AI 코딩 에이전트는 사실 화려한 마법이 아니라 "질문하고 → 도구를 쓰고 → 결과를 다시 보여주고"를 반복하는 아주 단순한 반복문(loop)입니다. 비유하자면 유능한 비서가 할 일 목록을 하나씩 확인하며 "이 작업엔 이 도구를 쓰면 되겠다"를 반복하는 것뿐이고, 이 글은 그 반복문의 뼈대를 파이썬 25줄로 그대로 드러내 보여줍니다.

## 이걸로 할 수 있는 것
1. Claude API로 나만의 초경량 "미니 Jev/Claude Code" 스크립트를 만들어, 반복되는 파일 정리·리서치·요약 작업을 자동 실행시킨다.
2. 이 핵심 루프 구조를 이해해두면, 고객사에 "Claude Code를 활용한 맞춤형 자동화 에이전트" 컨설팅·외주를 제안할 때 원리를 자신 있게 설명할 수 있다.
3. 도구 호출(tool use) 부분만 바꿔가며 "블로그 초안 작성 봇", "엑셀 데이터 검증 봇" 등 판매 가능한 소형 자동화 상품을 여러 개 빠르게 시제품화한다.

## 개요
이 글은 AI 에이전트(예: Jev, Claude Code 같은 도구)의 핵심이 실제로는 "LLM 호출 → 도구 실행 → 결과를 다시 LLM에 넣기"를 반복하는 짧은 while 루프에 불과함을 25줄짜리 최소 구현으로 보여줍니다. 복잡한 프레임워크(LangChain 등) 없이도 API 호출과 도구 실행만으로 동작하는 에이전트를 만들 수 있다는 것이 핵심 가치이며, 이를 이해하면 Claude Code 같은 상용 도구를 "블랙박스"가 아니라 직접 커스터마이징 가능한 대상으로 다룰 수 있게 됩니다.

## 구현 가능성: 상
- 파이썬 기본 문법 + Anthropic API 호출만으로 구성되어 외부 인프라나 특수 권한이 필요 없음.
- 맥북 로컬 환경(Python 3.10+, 텍스트 에디터)만으로 즉시 실행 가능.
- 사용자가 이미 Claude Code, Jev 등 에이전트형 AI를 업무에 활용 중이므로 배경지식 장벽이 낮음.

## 필요 도구
- Python 3.10+ (무료, 로컬 설치)
- Anthropic API 키 (유료, 사용량 기반 과금 — console.anthropic.com에서 발급)
- `anthropic` 파이썬 SDK (`pip install anthropic`, 무료)
- (선택) `subprocess`, `os` 등 표준 라이브러리 — 파일 읽기/쓰기, 셸 명령 실행용 도구 정의에 사용 (무료)
- 코드 에디터: VS Code 등 (무료)

## 구현 단계
1. `pip install anthropic`으로 SDK를 설치하고, Anthropic API 키를 환경변수(`ANTHROPIC_API_KEY`)로 등록한다.
2. 원문 코드를 그대로 옮겨 최소 동작 버전(약 25줄)을 로컬에서 한 번 실행해, "메시지 전송 → 응답 확인 → 도구 호출 시 실행 → 결과 재전송" 루프가 동작하는 것을 눈으로 확인한다.
3. 예시로 제공되는 도구(파일 읽기 등)를 자신의 실제 작업에 맞는 도구로 교체한다 — 예: 특정 폴더의 파일 목록을 정리하는 함수, 웹 검색 결과를 요약하는 함수 등.
4. 시스템 프롬프트를 바꿔가며 "블로그 초안 작성기", "엑셀 검증기" 등 2~3가지 미니 에이전트 변형을 만들어 실제 반복 업무(예: 리포트 초안 생성)에 적용해본다.
5. 동작이 검증되면, 이 스크립트를 launchd(맥OS 스케줄러)나 간단한 CLI 명령으로 감싸 실제로 매일/매주 자동 실행되게 만든다.
6. 이 원리 설명 + 맞춤 스크립트를 패키징해, "우리 업무에 맞는 미니 AI 에이전트 제작" 형태의 소규모 외주/컨설팅 상품으로 정리한다.

## 예상 공수
- 원문 코드 실행 및 이해: 30분~1시간 (난이도: 하)
- 자신의 업무용 도구로 교체·커스터마이징: 2~4시간 (난이도: 중)
- 자동 실행(스케줄링) 및 상품화 정리: 추가 3~5시간 (난이도: 중)

## 리스크/유의점
- API 호출량이 늘면 비용이 누적되므로, 반복 루프에 최대 반복 횟수(iteration limit)를 반드시 넣어야 함.
- 도구 함수가 파일 삭제·셸 명령 실행 등을 포함하면 에이전트가 의도치 않은 동작을 할 위험이 있으므로, 처음엔 읽기 전용 도구로만 테스트할 것.
- 25줄 최소 구현은 에러 처리·재시도 로직이 거의 없어 프로덕션 품질이 아니므로, 외주 상품화 전에는 안정성 보강이 필요함.
