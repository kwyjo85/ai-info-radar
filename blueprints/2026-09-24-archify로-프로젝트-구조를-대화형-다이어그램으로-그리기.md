# Archify로 프로젝트 구조를 대화형 다이어그램으로 그리기

## 쉽게 말하면
복잡한 프로젝트 구조를 말로 설명하는 대신, "이거 어떻게 돌아가는지 그려줘"라고 말하면 클릭하면서 살펴볼 수 있는 지도가 자동으로 나오는 도구입니다. 건축가가 손으로 그리던 설계도를, 이제는 AI 비서에게 말만 하면 완성해주는 셈이죠. 노드를 클릭하면 관련된 부분만 밝아지고, "여기 캐시 하나 추가해줘"라고 말하면 그 자리에서 그림이 다시 그려집니다.

## 이걸로 할 수 있는 것
1. 클라이언트에게 "AI 자동화 컨설팅" 제안서를 쓸 때, 텍스트 설명 대신 클릭 가능한 아키텍처 다이어그램을 첨부해 신뢰도와 단가를 동시에 올리기
2. ai-info-radar의 "수집→분석→채점→암호화→배포" 파이프라인을 한 장으로 그려 README와 포트폴리오에 상시 게시해 잠재 고객에게 기술력 증명하기
3. 코드 리뷰나 PR 머지 전, 구조 변화 전후를 자동 비교한 다이어그램을 팀/클라이언트 보고 자료로 재활용해 "설명 시간"을 줄이고 그만큼 더 많은 프로젝트를 수임하기

## 개요
Archify는 Claude Code(및 Cursor, Codex)에 설치하는 에이전트 스킬로, 코드베이스나 프로젝트 폴더를 가리키기만 하면 인터랙티브 아키텍처 다이어그램(HTML)을 생성합니다. 채팅으로 "이 부분 바꿔줘"라고 하면 즉시 재작도되고, 화살표 꼬임·라벨 겹침 같은 품질 검사를 통과한 뒤에야 결과물을 보여주며, PNG·SVG·WebM 내보내기와 머지 전 구조 비교 기능까지 갖췄습니다. 핵심 가치는 "설명 자료 제작 시간"을 대폭 줄여, 같은 시간에 더 많은 자동화·컨설팅 결과물을 판매할 수 있게 해준다는 점입니다.

## 구현 가능성: 상
- Claude Code 스킬 설치 방식이라 별도 서버·인프라 구축 불필요, 이미 보유한 MacBook + Claude Code 환경에 그대로 적용 가능
- GitHub 스타 6만 개 이상, MIT 라이선스의 검증된 오픈소스이며 공식 README 설치 명령이 그대로 존재해 "댓글로 설치기 받기" 같은 비공식 경로 없이도 바로 설치 가능
- 인스타 대시보드 자체 평가에서도 8.3/10(실현 5, 난이도 1)로 이미 실현 가능성이 높게 채점됨

## 필요 도구
- Claude Code (이미 사용 중, 무료/구독형)
- Archify 스킬 — tt-a1i/archify (GitHub 공개 저장소, 무료)
- Git (설치·클론용, macOS 기본 내장, 무료)
- (선택) 기존 GitHub Pages/gh-pages 배포 환경 — 생성된 HTML 다이어그램 게시용, 이미 보유 중이라 추가 비용 없음
- (선택) Cursor 또는 Codex — 다른 에이전트 환경에서도 동일 스킬 재사용 시

## 구현 단계
1. tt-a1i/archify GitHub README에 안내된 공식 설치 명령을 터미널에서 그대로 실행해 Claude Code에 스킬로 등록 (댓글로 받는 비공식 설치기 대신 공식 명령 사용 — 게시물 근거에서도 동일하다고 확인됨)
2. Claude Code 재시작 후 스킬 목록에서 archify 인식 여부 확인
3. 현재 ai-info-radar 프로젝트 루트를 가리키고 "수집→분석→채점→암호화→배포 흐름을 그려줘"라고 요청해 첫 다이어그램 생성
4. 생성된 HTML을 저장소 내 `diagrams/` 또는 `docs/`에 저장하고 README에 링크 삽입, 노드 클릭 시 연결 강조가 잘 동작하는지 확인
5. 채팅으로 "캐시 레이어 하나 추가해줘" 같은 수정 요청을 한 번 시도해 실시간 재작도 기능 검증
6. 클라이언트용 제안서 1건에 실제로 적용해보고, PNG/SVG 내보내기로 문서에 첨부 — 반응이 좋으면 앞으로 모든 자동화 제안서의 표준 산출물 포맷으로 채택
7. 이후 PR 작업 시 머지 전/후 구조 비교 기능을 사용해 코드 리뷰 보고 자료로도 확장 활용

## 예상 공수
설치부터 첫 다이어그램 생성까지 약 30분~1시간, 난이도는 하(공식 설치 명령 + 자연어 프롬프트 수준). 이후 다이어그램 1건당 추가 생성 시간은 5~10분 내외로 매우 짧아, 반복 활용 시 시간당 산출물 단가가 빠르게 개선됨.

## 리스크/유의점
- 초기 단계 오픈소스라 잦은 업데이트로 프롬프트 문법·출력 형식이 바뀔 수 있음 — 사용 전 README 최신 버전 확인 필요
- 클라이언트에게 공개하는 다이어그램에 내부 API 키·경로·민감 로직이 노출되지 않도록 프롬프트 작성 시 마스킹 필요
- Archify는 tt-a1i의 오픈소스이며 원 게시물 작성자(rebornlabs.ai)가 만든 것은 "한 줄 설치기"뿐이므로, 공식 설치 경로와 비공식 설치기를 혼동하지 않도록 주의
- 텍스트 설명만으로 충분한 간단 작업까지 다이어그램화하면 오히려 시간 낭비 — 클라이언트 제안·복잡한 다단계 자동화처럼 "시각화가 설득력을 높이는" 장면에 선택적으로 사용
