# 다인자 주식 퀀트 프레임워크 튜토리얼과 AI 금융 자료집

## 쉽게 말하면
주식 시장을 여러 각도(가격, 거래량, 재무지표 등)에서 동시에 분석해서 "왜 오르고 내리는지"를 숫자로 설명하는 방법을 배우는 무료 교재라고 생각하면 됩니다. 요리로 치면 레시피북이지, 완성된 요리(실전 매매 전략)를 파는 곳은 아닙니다. AI(LLM, 에이전트)를 금융에 접목한 최신 연구 사례도 함께 정리되어 있어, 이론과 최신 트렌드를 동시에 훑을 수 있습니다.

## 이걸로 할 수 있는 것
1. 퇴근 후 저녁 시간에 다인자(멀티팩터) 퀀트 모델의 기본 개념(모멘텀, 밸류, 퀄리티 팩터 등)을 순서대로 학습해 자신만의 주식 스크리닝 로직의 이론적 토대를 만들 수 있습니다.
2. 자료집에 정리된 LLM/Agent 기반 금융 연구 논문 목록에서 관심 주제만 골라 읽고, 향후 AI 트레이딩 봇 설계 시 참고할 아이디어 노트를 만들 수 있습니다.
3. MacBook에서 Python으로 튜토리얼 코드를 직접 실행해보며, 팩터 계산 → 백테스트 흐름을 손으로 익히는 개인 학습 프로젝트를 진행할 수 있습니다.

## 개요
이 저장소는 실전 매매 신호를 자동 생성하는 도구가 아니라, 멀티팩터 퀀트 프레임워크의 개념과 코드 구조를 배우는 오픈소스 교육 자료이며, 여기에 AI+금융 관련 학술/산업 자료가 큐레이션되어 있습니다. 가치는 "바로 쓸 수 있는 자동화"가 아니라, 이후 사용자가 직접 만들 AI 주식 트레이딩 시스템의 팩터 설계·리서치 역량을 다지는 기초 학습 자료라는 점입니다.

## 구현 가능성
**상** — GitHub에 공개된 Python 코드와 문서를 그대로 클론해서 로컬(MacBook)에서 읽고 실행하기만 하면 되므로 기술적 장벽이 낮고, 별도 API 키나 유료 서비스 없이 학습 자체는 즉시 가능합니다. 단, "실전 자동매매 자동화"로 연결하려면 추가 개발이 필요해 그 부분은 별도 과제입니다.

## 필요 도구
- GitHub 계정 및 `git` 명령 (무료)
- Python 3.9+ 환경 [추정, 저장소 요구 버전은 공식 문서 확인 필요] (무료)
- 가상환경 관리: `venv` 또는 `conda` (무료)
- Jupyter Notebook / JupyterLab — 튜토리얼 코드 실습용 (무료)
- pandas, numpy, matplotlib 등 데이터 분석 라이브러리 [공식 문서 확인 필요, 저장소 requirements.txt 확인 필요] (무료)
- 메모 정리용 노트 앱(Notion, Obsidian 등) — 학습한 팩터 개념·논문 요약 정리용 (무료/일부 유료)
- (선택) VS Code — 코드 읽기·실행용 (무료)

## 구현 단계
1. 터미널에서 `git clone https://github.com/Barca0412/Introduction-to-Quantitative-Finance.git` 실행해 저장소를 MacBook에 다운로드한다.
2. `cd Introduction-to-Quantitative-Finance` 후 README와 폴더 구조를 훑어 다인자 퀀트 튜토리얼 파트와 AI+금융 자료집 파트를 구분한다.
3. `python3 -m venv venv && source venv/bin/activate`로 가상환경을 만들고, 저장소에 `requirements.txt`가 있으면 `pip install -r requirements.txt`로 의존성을 설치한다 [파일 존재 여부 공식 문서 확인 필요].
4. Jupyter Notebook을 실행해(`jupyter notebook`) 다인자 프레임워크 튜토리얼을 챕터 순서대로 따라가며 코드를 직접 실행하고 결과를 확인한다.
5. 학계/업계 자료 목록 중 관심 있는 논문(LLM, Agent, benchmark 관련)만 골라 읽고, 핵심 아이디어를 3줄 요약으로 개인 노트에 정리한다.
6. 학습한 내용을 자신의 "AI 주식매매" 프로젝트 대시보드/노트에 참고 학습자료 링크와 함께 등록해, 향후 팩터 설계나 백테스트 로직 개발 시 다시 찾아볼 수 있게 인덱싱한다.
7. (선택) 튜토리얼에서 배운 팩터 계산 로직을 자신이 관심 있는 종목군(예: 한국 상장주)에 맞게 변형해 소규모 실험 노트북을 별도로 만든다.

## 예상 공수
- 저장소 클론 및 환경 설정: 30분~1시간, 난이도 하
- 다인자 퀀트 튜토리얼 완독 및 코드 실습: 4~8시간 [추정, 튜토리얼 분량에 따라 변동] , 난이도 중
- AI+금융 자료집 논문 선별 학습: 논문당 1~2시간, 필요한 만큼 누적, 난이도 중~상
- 전체적으로 "기초 다지기" 목적이라면 1~2주 내 병행 학습으로 충분

## 리스크/유의점
- 이 저장소는 실전 매매 전략이나 수익 검증된 알고리즘이 아니라 교육/자료 취합형이므로, 여기서 배운 내용을 곧바로 실계좌 매매에 적용하면 손실 위험이 있습니다.
- 중국어(중문) 설명이 포함되어 있을 가능성이 있어[원문 캡션 기준 추정], 번역기를 병행 사용해야 할 수 있습니다.
- 저장소가 활발히 업데이트되지 않거나(이번 주 스타 증가 +0) 일부 코드가 최신 라이브러리 버전과 호환되지 않을 수 있으므로, 실행 전 의존성 버전을 확인해야 합니다 [공식 문서 확인 필요].
- 학습용 자료를 실제 자동매매 시스템에 연결하려면 별도의 리스크 관리, 백테스트 검증, 실시간 데이터 연동 설계가 추가로 필요합니다.
