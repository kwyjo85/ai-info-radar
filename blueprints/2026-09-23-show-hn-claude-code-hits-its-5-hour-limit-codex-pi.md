# legcli — Claude Code 5시간 한도 걸리면 같은 터미널에서 Codex가 바로 이어받기

## 쉽게 말하면
Claude Code는 일정 시간(약 5시간) 이상 쓰면 "오늘은 여기까지" 하고 멈추는 사용량 한도가 있습니다. legcli는 이 한도에 걸리는 순간을 감지해서, 같은 터미널 창 안에서 자동으로 Codex(OpenAI의 코딩 AI)로 바통을 넘겨 작업을 끊김 없이 계속하게 해주는 작은 도구입니다. 마치 휴대폰 배터리가 떨어지면 보조배터리로 자동 전환되듯, 한 AI가 지치면 다른 AI가 이어받아 일을 멈추지 않게 해줍니다.

## 이걸로 할 수 있는 것
1. 사이클 산출 파이프라인처럼 긴 자동화 작업을 돌리다가 Claude Code 한도에 걸려도, 터미널을 바꾸거나 재시작하지 않고 Codex가 이어받아 계속 진행시킬 수 있습니다.
2. 외주로 "AI 코딩 자동화 세팅"을 제공할 때, 고객이 한도 걱정 없이 밤새 배치 작업을 돌릴 수 있는 무중단 워크플로를 패키징해 판매할 수 있습니다.
3. Jev 관련 리서치·개발 작업을 몰아서 할 때, 한도 도달 후 수동으로 다른 도구를 켜는 전환 비용(맥락 재설명 등)을 없애 하루 작업 시간을 실질적으로 늘릴 수 있습니다.

## 개요
legcli는 Claude Code CLI 세션의 사용량 한도(레이트 리밋) 도달을 모니터링하다가, 한도에 걸리면 동일 터미널·동일 작업 맥락에서 Codex CLI로 자동 전환해주는 래퍼(wrapper) 도구입니다. 핵심 가치는 "AI 코딩 어시스턴트 가용 시간의 무중단화"로, 장시간 자동화 작업이나 여러 구독 한도를 넘나드는 업무 흐름에서 다운타임을 줄여줍니다.

## 구현 가능성 — 중
- CLI 래퍼 형태라 설치 자체는 간단할 가능성이 높지만, Show HN 코멘트가 0개·포인트 2점으로 사실상 검증되지 않은 신생 도구입니다.
- Codex CLI로 "같은 맥락"을 넘기는 부분(대화 이력, 작업 상태 이전)이 실제로 얼마나 매끄러운지는 소스 코드를 직접 읽어봐야 판단 가능하며, 단순히 "새 세션 시작"에 그칠 수도 있습니다.
- 사용자는 별도 OpenAI/Codex 계정·API 키가 필요해 추가 구독 결정이 선행되어야 합니다.

## 필요 도구
- **legcli** (GitHub: ucsandman/legcli) — 무료, 오픈소스 (라이선스 확인 필요)
- **Claude Code CLI** (이미 사용 중) — 기존 구독 요금제
- **OpenAI Codex CLI / ChatGPT 계정 또는 OpenAI API 키** — 유료 (별도 구독/사용량 과금)
- **Node.js 또는 Python** (legcli 구현 언어에 따라, 저장소 README 확인 필요) — 무료

## 구현 단계
1. `git clone https://github.com/ucsandman/legcli`로 저장소를 받아 README에서 지원 언어/런타임과 설치 요구사항을 확인합니다.
2. Codex CLI를 별도로 설치하고 OpenAI 계정/API 키로 로그인해 정상 작동하는지 단독으로 먼저 테스트합니다.
3. legcli를 로컬에 설치한 뒤, Claude Code 세션을 legcli 래퍼로 감싸서 실행하고 정상적으로 명령이 패스스루(pass-through) 되는지 확인합니다.
4. 실제로 한도에 걸릴 때까지 기다리기보다, 소스 코드에서 한도 감지 로직(에러 메시지 패턴 매칭 등)을 확인해 임의로 트리거해보거나 짧은 테스트 한도 값으로 동작을 재현해봅니다.
5. Codex로 전환된 뒤 기존 작업 맥락(현재 디렉터리, 최근 지시사항)이 얼마나 유지되는지 실제 소규모 작업(예: 사이클 산출 스크립트 수정)으로 검증합니다.
6. 문제없이 동작하면, 밤새 도는 자동화 파이프라인(예: 인스타 대시보드 데이터 수집·블루프린트 생성 사이클)에 legcli 래퍼를 적용해 한도로 인한 파이프라인 중단을 없앱니다.

## 예상 공수
- 저장소 확인 및 Codex CLI 단독 설치·테스트: 1~2시간
- legcli 설치 및 Claude Code 래핑 검증: 2~3시간
- 한도 전환 로직 재현 테스트: 1~2시간
- 기존 자동화 파이프라인 통합: 2~3시간
- 난이도: 중 (신생 도구라 문서 부족, 두 개의 서로 다른 CLI 생태계를 동시에 다뤄야 함)

## 리스크/유의점
- Show HN 포인트 2점, 댓글 0개로 실사용 검증이 전혀 없어 도입 전 소스 코드를 직접 읽고 신뢰성을 판단해야 합니다.
- Codex로 전환 시 Claude Code와 다른 모델 특성(코드 스타일, 지시 해석 방식)으로 인해 작업 일관성이 깨질 수 있어, 중요한 작업에는 전환 시점에 결과물을 재검토하는 습관이 필요합니다.
- Codex 사용은 별도 유료 계정/API 비용이 발생하므로, 실제로 한도 초과가 잦지 않다면 투자 대비 효과가 낮을 수 있습니다.
- 1인 유지보수 프로젝트일 가능성이 높아, Claude Code나 Codex CLI의 인터페이스가 바뀌면 legcli가 먼저 깨질 위험이 있습니다.
