# Claude Code의 AGENTS.md 폴백 사각지대를 노리는 "멀티에이전트 설정 감사" 유료 도구

## 개요
Claude Code는 CLAUDE.md가 없을 때 AGENTS.md를 폴백으로 읽지만, 두 파일의 우선순위·병합 규칙·Claude Code 전용 지시(권한, 훅, 서브에이전트 정의 등)가 AGENTS.md 표준에는 없어 여러 AI 코딩 도구(Claude Code, Codex, Cursor 등)를 동시에 쓰는 팀에서는 설정 누락·충돌이 조용히 발생합니다. 이 틈을 겨냥해 리포지토리의 CLAUDE.md/AGENTS.md를 스캔하고 Jev로 규칙을 구조화 추출해 "이 저장소에서 어떤 에이전트가 어떤 지시를 놓치는지"를 진단해주는 CLI/GitHub Action을 만들어 개발팀에 유료로 판매할 수 있습니다.

## 구현 가능성 — 상
- 원문 자체가 "CLAUDE.md와 AGENTS.md의 차이, 폴백이 커버하지 못하는 부분"을 다루는 기술 문서이므로 규칙(우선순위, 병합 로직, 누락 항목) 목록화가 명확하게 가능합니다.
- Jev는 마크다운 텍스트에서 "이 지시가 권한/훅/서브에이전트/모델 지정 중 무엇에 해당하는가" 같은 분류·태깅 작업에 적합하며, 대량 리포지토리를 배치로 스캔할 때 LLM보다 훨씬 저렴합니다.
- MacBook 로컬에서 Node/Python CLI + 파일 파싱만으로 MVP 제작이 가능해 외부 인프라 의존이 거의 없습니다.

## 필요 도구
- **Jev API** (TypeSafe AI System One) — 유료, 지시문 분류/태깅용 (사용량 과금)
- **Claude Code CLI** — 무료(구독 포함), 실제 동작 검증 및 자체 개발 환경
- **Node.js 20+ 또는 Python 3.11+** — 무료, CLI 본체
- **simple-git 또는 GitPython** — 무료, 대상 리포지토리 클론/스캔
- **remark/markdown-it (JS) 또는 markdown-it-py** — 무료, CLAUDE.md/AGENTS.md 파싱
- **GitHub Actions / GitHub App API** — 무료 티어 존재, PR에 감사 결과 코멘트 게시
- **Stripe API 또는 Gumroad** — 무료 연동(수수료만), CLI 라이선스/구독 과금
- **원문 출처**: samplexbro.github.io/agentsmesh 가이드 — 경쟁/참고 자료로 활용 (유사 오픈소스 프로젝트 "agentsmesh" 존재 여부 확인 필요)

## 구현 단계
1. Claude Code, Codex, Cursor 등 주요 AI 코딩 도구별로 "설정 파일 우선순위·폴백 규칙"을 원문과 공식 문서에서 정리해 규칙 테이블(YAML)로 작성.
2. CLAUDE.md/AGENTS.md를 파싱해 섹션 단위로 추출하는 파서 작성, 프론트매터·헤딩·리스트 항목을 구조화된 JSON으로 변환.
3. 추출된 각 지시 항목을 Jev에 전달해 카테고리(권한/훅/서브에이전트/모델선택/워크플로우/기타)로 태깅하고, "AGENTS.md 표준에 없는 Claude Code 전용 항목"인지 여부를 확신도와 함께 분류.
4. 1단계 규칙 테이블과 대조해 "이 리포지토리는 AGENTS.md만 있고 Claude Code 전용 훅/권한 설정이 없어 특정 기능이 폴백되지 않는다" 같은 갭 리포트를 생성하는 로직 구현.
5. CLI(`agentsmesh-audit scan .`)로 로컬 실행 시 콘솔 리포트 출력, MacBook에서 실제 자기 리포지토리로 드라이런하며 오탐/누락 보정.
6. GitHub Action으로 패키징해 PR마다 자동으로 갭 리포트를 코멘트로 남기는 워크플로우 구현, 공개 리포로 무료 데모 제공.
7. 유료 티어 설계: 무료(로컬 CLI, 리포지토리 1개) / 유료(GitHub Action 자동화, 여러 리포지토리, Slack 알림) — Stripe/Gumroad로 라이선스 키 발급 및 검증 로직 추가.
8. Claude Code를 실무에서 여러 저장소에 적용 중인 개발팀(에이전시, 스타트업)에 데모 후 파일럿 1~2곳 확보, 실제 발견된 갭 사례를 마케팅 콘텐츠(블로그/X)로 공개해 유입 확보.

## 예상 공수
- 규칙 정리 + 파서 MVP(1~2단계): 6~8시간
- Jev 분류 파이프라인(3~4단계): 8~10시간
- CLI + 드라이런 검증(5단계): 4~6시간
- GitHub Action 패키징(6단계): 6~8시간
- 과금/라이선스 연동(7단계): 4~6시간
- 총 개발 공수: 약 28~38시간, 난이도: 중 (마크다운 파싱·분류 로직은 단순하나, 여러 AI 도구별 실제 폴백 동작을 정확히 검증하는 데 조사 시간이 소요됨)

## 리스크/유의점
- Claude Code, Codex 등 각 도구의 설정 파일 폴백 규칙은 버전업에 따라 자주 바뀔 수 있어, 규칙 테이블을 지속적으로 갱신하는 유지보수 비용이 발생함.
- 원문이 Hacker News에서 포인트 3점, 댓글 0개로 검증되지 않은 개인 블로그 수준의 정보이므로, 실제 구현 전 Anthropic 공식 문서와 대조해 사실관계를 재확인해야 함(잘못된 규칙으로 감사 리포트를 만들면 신뢰도 손상).
- "agentsmesh"라는 이름이 이미 원문 사이트에서 쓰이고 있어 동일/유사 오픈소스 도구가 존재할 가능성이 높음 — 출시 전 경쟁 제품 여부와 라이선스를 반드시 확인.
- 타깃 시장(여러 AI 코딩 에이전트를 동시 운영하는 팀)이 아직 좁아 초기 유료 전환이 느릴 수 있으므로, 우선 무료 오픈소스 CLI로 커뮤니티를 모으고 유료 기능(자동화/알림/멀티리포)으로 수익화하는 오픈코어 전략이 안전함.
- Jev API 호출이 리포지토리당 수십~수백 건 발생할 수 있어, 대상 리포지토리 규모에 따라 예상 밖 비용이 커지지 않도록 파일 수/토큰 상한을 설정해야 함.
