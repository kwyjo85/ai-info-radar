# MCP 서버 기반 토큰 사용량 절감 — nxm-memory 도입 블루프린트

## 개요
`nxm-memory`는 MCP(Model Context Protocol) 서버로 동작하며, 대화/작업 컨텍스트를 외부 메모리 저장소에 위임해 매 요청마다 전체 컨텍스트를 재전송하지 않도록 해주는 도구입니다. Claude Code나 Jev 기반 자동화 파이프라인에서 반복적으로 큰 컨텍스트를 다루는 작업(코드베이스 리뷰, 장기 프로젝트 관리, 고객 응대 봇 등)에 적용하면 토큰 비용을 직접적으로 낮출 수 있어, 자동화 서비스를 외부에 판매할 때 원가 경쟁력을 확보하는 데 유리합니다.

## 구현 가능성 — 중
- MCP 프로토콜은 Claude Code에서 표준으로 지원되므로 서버 등록 자체는 난이도가 낮음.
- 다만 저장소(github.com/dangranaz/nxm-memory)가 스타/이슈가 거의 없는 신생 프로젝트로 추정되어(HN 포인트 1, 댓글 0), 문서화 수준과 안정성을 직접 검증해야 하는 리스크가 있음.
- 실제 "토큰 절감 효과"를 수익화 관점에서 검증하려면 Before/After 토큰 사용량 비교 실험이 필요해 검증 공수가 추가됨.

## 필요 도구
- **Claude Code** (이미 보유, MCP 클라이언트 역할) — 무료(구독 내 포함)
- **nxm-memory MCP 서버** (github.com/dangranaz/nxm-memory) — 무료(오픈소스, 라이선스 확인 필요)
- **Node.js/Python 런타임** (서버 구현 언어에 따라 결정, repo README 확인 필요) — 무료
- **로컬 벡터/키-값 저장소** (SQLite 또는 내장 파일 기반 추정) — 무료
- **Claude API 사용량 대시보드** (console.anthropic.com) — 토큰 절감 효과 측정용, 무료
- (선택) **Jev API** — Jev를 활용한 자동화 워크플로우에 동일 MCP 서버를 연결할 경우

## 구현 단계
1. `git clone https://github.com/dangranaz/nxm-memory` 후 README를 읽고 실행 런타임(Node/Python) 및 필수 의존성 설치.
2. 로컬에서 MCP 서버를 단독 실행해 정상 기동 여부와 로그를 확인 (`npm start` 또는 `python server.py` 등, repo 구조에 따라 다름).
3. Claude Code의 `.claude/settings.json` 또는 프로젝트 MCP 설정 파일에 서버를 등록 (`claude mcp add nxm-memory <command>` 형태).
4. 실제 반복 작업 하나(예: cocobaby/ai-info-radar 저장소의 블루프린트 생성 루틴)를 nxm-memory 연결 전/후로 나눠 동일 프롬프트로 실행, `console.anthropic.com` 사용량 로그에서 input 토큰 수를 비교.
5. 절감률이 유의미하면(예: 20% 이상) 개인 자동화 파이프라인(예: 반복되는 정보 수집·요약·블루프린트 생성 크론)에 상시 적용.
6. 검증된 세팅을 "MCP 기반 토큰 절감 컨설팅" 패키지로 문서화해, Claude Code를 도입하려는 소규모 팀/1인 개발자 대상 유료 세팅 대행 서비스로 제안 (수익화 포인트).
7. 안정성이 확인되면 Jev 연동 자동화 워크플로우에도 동일 메모리 서버를 붙여 장기 실행 작업의 컨텍스트 재사용 구조로 확장.

## 예상 공수
- 설치 및 로컬 검증: 1~2시간 (난이도: 하)
- Claude Code MCP 등록 및 연동 테스트: 1~2시간 (난이도: 중)
- Before/After 토큰 절감 효과 측정: 2~3시간 (난이도: 중, 반복 실행 필요)
- 컨설팅/서비스 패키지화 문서 작성: 2시간 (난이도: 하)
- **총 예상: 6~9시간**

## 리스크/유의점
- 저장소 인지도가 낮아(HN 포인트 1) 유지보수 지속성과 보안 검증이 부족할 수 있음 — 프로덕션 투입 전 코드 직접 검토 필요.
- 외부 메모리 서버에 대화 컨텍스트를 저장하는 구조이므로, 고객사 코드/민감 정보를 다루는 자동화에 적용 시 데이터 보관 위치와 암호화 여부를 반드시 확인.
- 토큰 절감이 실제로는 미미하거나 특정 워크로드(긴 대화, 반복 컨텍스트)에서만 효과가 있을 수 있어, 범용 적용 전 측정 단계를 생략하지 말 것.
- MCP 서버 자체 장애 시 Claude Code 작업 전체가 중단될 수 있으므로 폴백(비활성화 옵션) 경로를 마련해야 함.
