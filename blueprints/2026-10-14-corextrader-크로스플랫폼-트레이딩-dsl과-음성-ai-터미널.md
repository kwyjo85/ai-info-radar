# CoreXTrader로 구현하는 AI 기반 주식 자동매매 전략 — MacBook 환경 구축 블루프린트

## 쉽게 말하면
CoreXTrader는 트레이더를 위한 전용 프로그래밍 언어(TDSL)와 AI 코딩 비서를 함께 제공하는 트레이딩 프로그램입니다. 엑셀에 매크로를 짜듯 "이 조건이면 사고, 저 조건이면 팔아라"라는 규칙을 코드로 적어두면, AI가 그 코드를 같이 작성해주고 프로그램이 24시간 대신 실행해 줍니다.

## 이걸로 할 수 있는 것
1. 볼린저밴드 같은 기술적 지표 기반 전략을 TDSL 코드로 작성하고, AI 어시스턴트(TDSL Agent)에게 자연어로 전략 초안을 요청할 수 있다.
2. 작성한 전략을 과거 틱 데이터로 백테스트해 실제 자금 투입 전에 수익률·낙폭(drawdown)을 점검할 수 있다.
3. PC에서 전략을 돌려두고 외부에서는 Android 모바일 앱으로 같은 계좌 상태와 매매 신호 알림을 실시간으로 확인할 수 있다.

## 개요
CoreXTrader는 자체 DSL(TDSL), AI 코드 어시스턴트, 틱 단위 백테스트 엔진을 하나로 묶어 전략 설계·검증·실행 과정을 자동화하는 플랫폼입니다. 반복적인 지표 계산과 매매 판단을 코드화함으로써 매번 차트를 수동으로 보지 않아도 되는 자동매매 체계를 구축할 수 있습니다. 다만 공식 자료상 연동 브로커는 cTrader, Binance, MetaTrader 5, Bybit, Testnet 등 주로 FX·크립토 중심으로 나열되어 있으며, 국내·해외 "주식" 전용 증권사 연동 여부는 [공식 문서 확인 필요]입니다.

## 구현 가능성 — 중
근거: TDSL 전략 작성, AI 보조 코딩, 백테스트 기능 자체는 원문에 명시되어 있어 기능적 구현 가능성은 높습니다. 그러나 (1) 공식 다운로드가 `.exe`(Windows), Google Play(Android), Linux로만 명시되어 있고 macOS 네이티브 클라이언트는 원문에 없어 MacBook에서 직접 설치가 불가능하다는 제약이 있으며, (2) 연동 브로커 목록에 주식 전용 증권사가 명시되지 않아 "주식" 트레이딩에 바로 적용 가능한지 사전 확인이 필요하기 때문입니다.

## 필요 도구
- CoreXTrader 데스크톱 클라이언트 (`.exe`, Windows 전용으로 원문에 명시) — 다운로드 자체는 무료로 보임 [추정, 가격 정책 원문에 명시 없음]
- CoreXTrader Linux 빌드 — 다운로드 가능 명시, 비용 정보 원문 없음
- CoreXTrader Android 앱 (Google Play) — 무료 다운로드로 보임 [추정]
- Windows/Linux 구동용 가상환경: UTM(무료) 또는 Parallels Desktop(유료) 등 [추정 — 원문에 macOS 경로 없음, Mac에서 실행하려면 사용자가 별도 준비 필요]
- 브로커/거래소 계좌: cTrader, Binance, MetaTrader 5, Bybit, Testnet 중 하나 (계좌 개설·API 키 발급 필요, 비용은 각 거래소 정책에 따름)
- Strategy IDE (CoreXTrader 내장) — 별도 비용 명시 없음

## 구현 단계
1. corextrader.com의 공식 Documentation에서 macOS 지원 여부와 브로커별 "주식" 상품 제공 여부를 먼저 확인한다. [공식 문서 확인 필요]
2. 보유 중인 MacBook이 Apple Silicon인지 Intel인지 확인하고, Windows `.exe` 또는 Linux 빌드를 구동할 가상환경(UTM, Parallels 등)을 준비한다. [추정 — 원문에 macOS 경로 없음]
3. 가상환경에 Windows 또는 Linux를 설치한 뒤 그 안에 CoreXTrader 클라이언트를 설치한다.
4. Testnet trading 계정으로 먼저 로그인해 실거래 자금 없이 플랫폼 UI와 TDSL Agent 사용법을 익힌다.
5. Strategy IDE에서 제공되는 샘플 코드(예: `bollinger-bands.tdsl`)를 열어 `about`, `struct`, `enum`, `display` 블록 구조를 분석한다.
6. TDSL Agent에게 자연어로 원하는 전략 로직(예: 이동평균 교차, RSI 과매도 매수)을 요청해 초안 코드를 생성한다.
7. 생성된 전략을 Advanced Strategy Tester로 틱 단위 백테스트하고 수익률·낙폭을 검토한다.
8. 문제가 없으면 소액 실계좌 또는 데모 계좌로 전환해 라이브 신호가 백테스트와 일치하는지(Live/Test Logic Parity) 모니터링한다.
9. Android 앱을 설치해 PC-모바일 동기화로 외부에서도 계좌 상태와 알림을 확인하도록 설정한다.

## 예상 공수
- 초기 환경 구축(가상머신 + 클라이언트 설치): 3~5시간
- TDSL 학습 및 샘플 전략 작성: 5~8시간
- 백테스트·검증 반복: 3~6시간
- 총 소요: 병행 작업 기준 약 1~2주
- 난이도: 중~상 (DSL 학습 곡선 + macOS 비공식 설치 과정으로 인해 일반 사용자 기준보다 높음)

## 리스크/유의점
- macOS 네이티브 클라이언트가 원문에 없으므로 가상머신/에뮬레이터를 경유한 설치는 성능 저하, 라이선스 문제, 호환성 이슈가 발생할 수 있다 [추정].
- TDSL 바이트코드(`.tbc`)는 "irreversible compilation"으로 명시되어 있어, 컴파일 후 원본 소스 복구가 불가능할 수 있으므로 원본 `.tdsl` 파일을 반드시 별도 백업해야 한다.
- 연동 브로커 목록이 주로 FX·크립토 중심이므로 "주식" 종목 매매가 실제로 지원되는지 사전에 반드시 확인해야 하며, 미확인 상태로 전략을 짜면 헛수고가 될 수 있다.
- AI가 생성한 전략 코드를 그대로 신뢰하지 말고, 반드시 백테스트와 소액 실거래 검증을 거친 뒤 자본 규모를 확대해야 한다.
- 거래소 API 키 등 민감 정보는 가상환경에 저장 시 유출 위험이 있으므로 키 관리에 주의한다.
