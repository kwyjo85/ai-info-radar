# AI 매매봇 백테스트 함정 방지 시스템: 과적합·MDD·손절 자동 검증 파이프라인

## 쉽게 말하면
자동매매 봇을 만드는 건 자율주행차를 학습시키는 것과 비슷합니다. 맑은 날 도로 영상만 보고 학습한 자율주행차가 비 오는 날 사고를 내듯, 과거 특정 구간 데이터에만 맞춰진 봇은 실전에서 무너집니다. 이 블루프린트는 봇을 실전에 투입하기 전, "이 봇이 정말 안전한가?"를 개인 맥북에서 자동으로 검증하는 체크 시스템을 만드는 것입니다.

## 이걸로 할 수 있는 것
1. 매매 전략을 코딩한 뒤, 본 적 없는 최근 기간 데이터로 자동 재검증해서 과적합 여부를 스스로 판단할 수 있다.
2. 백테스트 결과에서 수익률만 보지 않고 최대낙폭(MDD)·수수료·슬리피지를 자동 계산해 리포트로 받아볼 수 있다.
3. 실계좌 투입 전 1개월 이상 모의투자(페이퍼 트레이딩)를 자동 실행하고 매일 손절 로직이 제대로 작동했는지 슬랙/이메일로 알림받을 수 있다.

## 개요
이 시스템은 "백테스트 수익률이 높다 = 실전에서도 좋다"는 착각을 막기 위해, 아웃오브샘플 검증·MDD 계산·거래비용 반영·스탑로스 로직 강제·페이퍼 트레이딩 자동 실행을 파이프라인화합니다. 개인 투자자가 놓치기 쉬운 검증 단계를 코드로 강제해, 실전 투입 전 위험 신호를 조기에 발견하는 것이 핵심 가치입니다.

## 구현 가능성
**중**
- 백테스트 프레임워크(backtrader, vectorbt 등)와 국내 증권사 API(키움 OpenAPI, 한국투자증권 API)는 이미 존재하고 개인 맥북에서 실행 가능하지만, 실시간 자동매매 연동은 API 인증·보안 설정에 시간이 걸림.
- MDD·거래비용 계산 로직 자체는 간단한 수식이라 구현 난이도는 낮으나, "과적합 판단"은 정량 기준을 직접 설계해야 해서 [추정] 사용자의 도메인 판단이 필요함.
- 원문 근거([첫 단계])에 아웃오브샘플 검증, MDD/비용 계산, 스탑로스, 1개월 모의투자가 명시되어 있어 이 네 가지는 그대로 구현 가능.

## 필요 도구
- **Python 3.10+** (무료) — 전체 파이프라인 언어
- **backtrader 또는 vectorbt** (무료, 오픈소스) — 백테스트 엔진, MDD/샤프비율 자동 계산 기능 포함 [공식 문서 확인 필요]
- **pandas, numpy** (무료) — 데이터 처리
- **한국투자증권 Open API 또는 키움증권 OpenAPI+** (무료 가입, 실거래 시 수수료 별도) — 실시간 시세/모의투자/주문 API
- **yfinance 또는 pykrx** (무료) — 과거 국내/해외 주가 데이터 수집
- **cron 또는 macOS launchd** (무료, macOS 기본 내장) — 매일 자동 실행 스케줄링
- **Slack Webhook 또는 SMTP 이메일** (무료) — 알림 발송
- **SQLite** (무료) — 거래 로그·MDD 이력 저장
- **Jupyter Notebook** (무료) — 백테스트 결과 시각화 및 리포트 확인

## 구현 단계
1. 맥북에 Python 가상환경(venv) 생성 후 backtrader(또는 vectorbt), pandas, pykrx/yfinance 설치.
2. 매매 전략 코드를 작성하고, 전체 데이터를 "학습 구간"과 "아웃오브샘플 구간(예: 최근 3개월)"으로 명확히 분리 [추정: 분할 비율은 전략에 따라 조정].
3. 백테스트 실행 시 수익률 대신 MDD, 승률, 거래당 수수료(예: 0.015% 기준 [원문 근거])와 슬리피지를 함께 계산하는 리포트 함수를 작성.
4. 전략 로직에 스탑로스(예: 진입가 대비 -N% 도달 시 자동 청산) 조건을 코드로 강제 삽입하고, 이 조건 없이는 봇이 실행되지 않도록 검증 로직 추가.
5. 아웃오브샘플 구간에서 백테스트를 재실행하여 학습 구간 대비 MDD·수익률 괴리가 큰 경우 "과적합 경고"를 출력하도록 조건문 작성.
6. 한국투자증권/키움 모의투자 API 연동하여 실계좌 투입 전 최소 1개월간 자동 매매를 페이퍼 트레이딩 환경에서 실행.
7. macOS launchd 또는 cron으로 매일 장 마감 후 모의투자 결과를 자동 집계하고, MDD·손절 발동 이력을 Slack/이메일로 알림.
8. 1개월 경과 후 모의투자 성과와 백테스트 성과를 비교하는 리포트를 생성하고, 괴리가 크면 실계좌 투입을 보류하는 의사결정 체크리스트 적용.

## 예상 공수
- 환경 세팅 + 백테스트 엔진 설치: 2~3시간 (난이도: 하)
- 전략 코드 + MDD/비용 계산 로직 작성: 6~10시간 (난이도: 중)
- 증권사 API 연동 + 모의투자 자동화: 8~15시간 (난이도: 중~상, API 인증 이슈로 변동 큼)
- 알림/스케줄링 설정: 2~3시간 (난이도: 하)
- **총 예상: 약 18~31시간** (난이도: 중, 1인 개발 기준 [추정])

## 리스크/유의점
- 증권사 API는 정책 변경이 잦아 [공식 문서 확인 필요] 인증 방식이 문서와 다를 수 있음.
- 모의투자 환경은 실제 체결 지연·슬리피지를 완벽히 재현하지 못하므로, 모의투자 성과도 100% 신뢰해서는 안 됨.
- 과적합 판단 기준(괴리 허용치)을 지나치게 느슨하게 설정하면 경고 시스템이 무력화될 수 있음 — 보수적 기준 권장.
- 실계좌 API 키·자동 주문 권한을 다루므로 코드 오류 시 실제 금전 손실로 직결됨. 최초 실계좌 투입 시 소액으로 시작 권장.
- 자동매매는 국내 자본시장법상 알고리즘 매매 신고 등 규제 이슈가 있을 수 있어 [공식 문서 확인 필요] 증권사 약관을 사전 확인해야 함.
