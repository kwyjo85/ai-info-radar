# Geo Pulse 벤치마킹 — 지정학 뉴스 실시간 분류를 수익형 브리핑 서비스로

## 쉽게 말하면
전 세계 뉴스를 계속 읽으면서 "이건 어느 나라 얘기고, 무슨 종류의 사건이고, 얼마나 심각한가"를 자동으로 분류해주는 로봇 편집자를 만드는 것입니다. 사람이 밤새 CNN, 로이터, 각국 뉴스를 뒤지는 대신, AI가 대신 읽고 "오늘의 지정학 리스크 요약"을 정리해주는 셈이죠.

## 이걸로 할 수 있는 것
1. 아침에 눈뜨자마자 "오늘 미·중, 중동, 러시아 관련 주요 사건 3줄 요약"을 텔레그램으로 받아본다.
2. 무역·투자·컨설팅 고객에게 "지정학 리스크 데일리 브리핑"을 유료 구독 상품으로 판매한다.
3. 이미 운영 중인 ai-info-radar 파이프라인에 "지정학" 주제 채널을 하나 추가해, 기존 대시보드에 지역별 리스크 지도를 얹는다.

## 개요
Geo Pulse는 지정학 관련 뉴스를 실시간으로 수집해 카테고리(국가/지역/사건 유형/심각도 등)로 자동 분류해 보여주는 서비스입니다. 핵심 가치는 "정보 과잉 속에서 중요한 지정학 신호만 걸러내는 속도"이며, 이는 금융(원자재·환율 트레이딩), 무역, 컨설팅, 저널리즘 등 정보 격차가 곧 돈이 되는 영역에서 유료 수요가 뚜렷합니다.

## 구현 가능성 — 상
근거: 사용자는 이미 ai-info-radar에서 RSS/HN/Google 뉴스 수집 → LLM 채점(haiku) → gh-pages 대시보드 배포 → 텔레그램 알림까지 동일한 파이프라인을 launchd로 30분 주기 운영 중입니다. Geo Pulse는 "주제 필터 + 분류 스키마"만 지정학용으로 바꾸면 되는 구조적 재사용이며, 신규 인프라 구축이 아니라 기존 시스템의 파생 상품에 가깝습니다.

## 필요 도구
- **기존 인프라 재사용**: ai-info-radar의 수집기, claude CLI 헤드리스(구독 요금제, 추가 비용 없음), launchd, GitHub Pages — 모두 무료(기존 GitHub 무료 티어)
- **지정학 전용 뉴스 소스**(무료): Google News RSS(국가/사건 키워드별), Reuters World RSS, AP World RSS, GDELT Project(전 세계 이벤트 데이터, 무료 API/BigQuery)
- **선택 — 유료 원문 API**: NewsAPI.org(월 $0~449, 무료 티어는 개발용 한정) 또는 NewsData.io(무료 티어 있음) — 소스 다양성 늘릴 때만
- **분류용 LLM**: 기존 claude CLI(haiku, 구독 내 무료) — 국가·지역·사건유형·심각도 태깅 프롬프트만 추가
- **지도/시각화**: 기존 대시보드가 정적 HTML이면 Leaflet.js(무료, MIT) 또는 간단한 SVG 세계지도 컴포넌트
- **유료화 시**: Stripe(결제, 거래수수료만) 또는 Buttondown/Substack(뉴스레터 구독, 무료~월 $9~)

## 구현 단계
1. GDELT나 Google News RSS에서 "지정학" 키워드 세트(국경분쟁, 제재, 정상회담, 군사충돌, 무역전쟁 등)를 정의하고, 기존 수집기 모듈에 신규 소스로 추가.
2. haiku 채점 프롬프트를 복제해 `geo_category`(국가/지역), `event_type`(외교/군사/경제제재/무역 등), `severity`(1~5) 3개 필드를 추가로 뽑는 채점 스텝을 만든다.
3. 하루 단위로 지역별·심각도별 집계를 만들어 기존 gh-pages 대시보드에 "지정학 리스크" 탭을 하나 추가(정적 HTML + 간단한 지도 표시).
4. 텔레그램 봇에 "지정학 브리핑" 명령/자동 발송 스케줄을 하나 더 추가(기존 브리핑 로직 재사용, 다른 topic 필터만 적용).
5. 2주간 스스로 사용해보며 태깅 정확도·노이즈(관련 없는 뉴스 오분류)를 점검하고 프롬프트를 다듬는다.
6. 품질이 안정되면 지인/타깃 고객(무역·투자 관련 종사자) 1~2명에게 무료 체험판으로 브리핑을 보내 피드백 수집.
7. 반응이 좋으면 Substack/Buttondown으로 유료 구독 티어(예: 월 1~3만원)를 만들고, 대시보드는 무료 요약 + 상세 리포트는 유료로 구조화.

## 예상 공수
- 1~4단계(내부용 MVP, 기존 인프라 재사용): 6~10시간, 난이도 하~중
- 5~6단계(품질 검증·시범 운영): 1~2주간 자투리 시간(하루 20~30분 모니터링), 난이도 하
- 7단계(수익화 셋업: 결제·구독 페이지): 4~6시간, 난이도 중

## 리스크/유의점
- 지정학 뉴스는 오역·오분류 시 민감할 수 있어(전쟁/분쟁 관련), LLM 요약을 그대로 유료 상품에 노출하기 전 사람이 한 번 검수하는 단계를 두는 것이 안전합니다.
- 유료 구독으로 발전시킬 경우 "속보성"이 핵심 가치인데, 현재 30분 주기 launchd 배치로는 실시간성에서 상용 서비스(예: 원본 Geo Pulse)에 못 미칠 수 있어 기대치 관리가 필요합니다.
- GDELT·뉴스 API의 라이선스/재배포 정책을 확인해, 원문 전체를 유료 상품에 재게시하지 않고 요약·분석만 제공하는 형태로 설계해야 저작권 이슈를 피할 수 있습니다.
- 기존 ai-info-radar가 이미 "AI 자동화 수익화" 주제로 운영 중이므로, 신규 기능 추가 전 텔레그램 명령 기능처럼 자동 모드 안전 검사에 걸리는 설계는 피해야 합니다.
