# Claude Council: 5명 에이전트가 결정을 검토하는 스킬

## 쉽게 말하면
회의실에 성격이 다른 조언자 다섯 명(트집쟁이, 원점 재검토자, 낙관주의자, 문외한, 실무자)을 앉혀놓고 한 가지 고민을 동시에 물어본 뒤, 서로 답을 익명으로 다시 읽게 하고, 마지막에 사회자 두 명이 정리해주는 것과 같습니다. 다만 이 다섯 명과 두 사회자는 전부 클로드이고, 터미널 명령어 한 줄로 내 컴퓨터에 설치됩니다.

## 이걸로 할 수 있는 것
1. 인스타 대시보드에 유료 크리에이터(예: Jev)를 새로 추가할지 말지 결정하기 전에 `/claude-council`로 다섯 관점 검토를 돌려본다.
2. 가격 정책(예: 8,900원 단일가 vs 상위 등급 병행)을 바꾸기 전에 실행/전제/낙관/맥락없음 관점의 반박을 미리 받아본다.
3. Claude Code 자동화 스킬을 클라이언트에게 유료로 제안하기 전, "이 자동화가 실제로 클라이언트 업무에 먹힐지"를 카운슬에 먼저 물어 설득력 있는 근거를 확보한다.

## 개요
결정 하나를 다섯 개의 독립된 서브에이전트가 각기 다른 페르소나(허점 찾기·전제 검증·낙관 시나리오·무맥락 관찰자·실행 담당)로 동시에 검토하고, 익명 상호 리뷰 후 두 명의 의장이 종합과 소수의견을 남기는 오픈소스 Claude Code 스킬이다. 애매한 의사결정(기능 우선순위, 가격, 배포 방식 등)을 혼자 판단하는 대신 구조화된 다각도 검증을 거치게 해, 결정의 질과 설득력을 높이는 데 가치가 있다.

## 구현 가능성: 상
- GitHub에 실존하는 저장소(TorpedoD/claude-council, MIT 라이선스)이며 `npx skills add`로 설치 방식이 명확함.
- 별도 API 키나 외부 서비스 연동이 필요 없고, 기존 Claude Code 구독 안에서 서브에이전트로만 동작함.
- 이미 macOS 터미널 + Claude Code 환경이 세팅되어 있으므로 추가 인프라 없이 즉시 시도 가능.

## 필요 도구
- Claude Code (기존 구독, 추가 비용 없음)
- Node.js / npx (무료, 이미 설치되어 있을 가능성 높음)
- TorpedoD/claude-council 저장소 (무료, MIT 오픈소스)
- 터미널 (zsh, 기본 제공)

## 구현 단계
1. 터미널에서 `npx skills add TorpedoD/claude-council` 실행해 `~/.claude/skills/claude-council/`에 설치한다 (파일 14개: SKILL.md, references 7편, scripts 4개, 보고서 틀·시험 묶음 포함되는지 확인).
2. 설치 후 `ls ~/.claude/skills/claude-council/` 로 파일 개수를 세어 정상 설치를 검증한다 (동명 파일 있으면 덮어쓰지 않고 건너뛰는 방식이므로 재설치 시에도 안전).
3. 현재 `ai-info-radar` 프로젝트 안에서 Claude Code를 실행하고, 실제로 애매한 결정 하나를 골라 테스트한다 — 예: "Jev 크리에이터를 대시보드 소스에 새로 추가할지" 또는 "다이제스트 브리핑 주기를 몇 시간으로 할지".
4. `/claude-council [고민되는 결정 문장]` 형태로 실행하고, 다섯 에이전트의 개별 답변과 두 의장의 종합·소수의견 출력을 끝까지 읽는다.
5. 카운슬 결과를 그대로 따르지 말고, 다수 의견과 소수 의견을 비교해 본인이 최종 판단을 내리는 습관을 들인다.
6. 수익화 관점에서는, 이 워크플로를 "의사결정 리뷰 서비스"로 패키징해 클라이언트(소상공인/1인 사업자)에게 "AI로 사업 결정을 다각도 검증받기" 형태의 컨설팅 상품으로 제안할지 검토한다 (예: 가격 정책, 마케팅 문구, 신규 기능 출시 여부를 대신 돌려주고 정리해주는 유료 세션).

## 예상 공수
- 설치 및 첫 테스트: 15~30분 (난이도: 하)
- 실제 프로젝트 의사결정에 적용해보고 결과 검증: 1~2시간 (난이도: 중, 반복 사용하며 익숙해지는 데 시간 소요)
- 수익화 상품으로 패키징(문서화, 가격 설계, 시연 자료): 별도 3~5시간 (난이도: 중)

## 리스크/유의점
- claude-council은 제3자 오픈소스 프로젝트이며 사용자(또는 인스타 계정 운영자)가 만들거나 제휴한 것이 아니므로, 유지보수 중단이나 방향 전환 리스크가 존재한다.
- 동일 프로젝트를 그대로 복제한 저장소가 여럿 존재하며 일부는 라이선스 파일이 없으므로, 반드시 MIT로 명시된 원본(TorpedoD/claude-council)만 사용해야 한다.
- 저장소 다운로드 자체는 무료지만 Claude Code 구독 비용은 별도이며, 서브에이전트 5개+의장 2개를 동시에 돌리므로 토큰 소모가 단일 질문보다 크다 — 반복 사용 시 비용을 체크할 것.
- 이 스킬은 결정을 대신 내려주지 않는다. 다섯 갈래 관점을 제공할 뿐이며 최종 선택과 책임은 사용자에게 있다 — 특히 유료 컨설팅 상품으로 판매할 경우 "AI가 결정해준다"는 식의 과장된 마케팅 문구는 피해야 한다.
