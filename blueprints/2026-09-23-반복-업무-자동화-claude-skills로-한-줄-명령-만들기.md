# 반복 업무 자동화: Claude Skills로 한 줄 명령 만들기

## 쉽게 말하면
Claude Skills는 "이 작업을 할 땐 이렇게 해줘"라는 매뉴얼을 폴더 하나(SKILL.md)에 미리 적어두는 기능입니다. 매번 처음부터 프롬프트를 길게 쓰는 대신, 요리 레시피 카드를 꺼내듯 "이 스킬 써줘"라고 한 줄만 말하면 Claude가 정해진 절차대로 결과물을 만들어줍니다. 한 번 잘 만들어두면 계속 재사용되는 나만의 자동화 버튼이 되는 셈입니다.

## 이걸로 할 수 있는 것
1. 매주 쓰는 "리서치 요약 → 블로그 초안" 작업을 스킬 하나로 만들어 한 줄 명령으로 끝내기
2. 클라이언트 보고서용 xlsx/docx 생성 작업을 표준 포맷 스킬로 만들어 반복 요청마다 즉시 출력받기
3. 지금 만들고 있는 "AI 정보 레이더 → 블루프린트 문서" 파이프라인 자체를 스킬로 등록해, 이 컨설팅 산출물 생성을 원클릭화하기

## 개요
Claude Code(또는 Claude.ai)의 Skills 기능을 이용해 반복되는 업무 절차(콘텐츠 기획, 리서치 요약, 문서 생성 등)를 SKILL.md 파일로 표준화하고, 매번 프롬프트를 새로 짜는 대신 짧은 트리거 한 줄로 실행하는 자동화입니다. 프롬프트 엔지니어링 비용을 없애고 결과물 일관성을 높여, 반복 작업을 대행/컨설팅으로 판매할 때 품질과 속도를 동시에 확보할 수 있다는 데 가치가 있습니다.

## 구현 가능성: 상
Claude Code에 이미 내장된 정식 기능(`~/.claude/skills/`)이며 별도 설치나 우회 없이 바로 사용 가능합니다. 현재 저장소(`ai-info-radar`)에도 이미 skills 폴더 구조를 다루는 맥락이 있어(예: `run`, `init` 등 프로젝트 스킬 존재), 학습 곡선 없이 오늘 바로 적용 가능합니다.

## 필요 도구
- Claude Code (이미 사용 중, 무료/구독 내 포함)
- GitHub 저장소 `anthropics/skills` (무료, 참고용 예시 스킬 모음)
- 텍스트 에디터 (SKILL.md 작성용, 별도 비용 없음)
- (선택) Claude.ai Pro/Team 플랜의 Settings > Skills 업로드 기능 — Claude.ai에서도 쓰려면 필요, 이미 구독 중이면 추가 비용 없음

## 구현 단계
1. `github.com/anthropics/skills` 저장소를 훑어 본인 업무(리서치 요약, docx/xlsx 생성, 콘텐츠 기획)와 겹치는 스킬 2~3개를 찾아 로컬에 클론하거나 파일만 복사한다.
2. 본인이 매주 반복하는 업무 1개를 선정한다 (예: "인스타/뉴스 리서치 → 이 블루프린트 문서 생성" 파이프라인).
3. 해당 업무를 위한 `SKILL.md`를 직접 작성한다: ① 스킬 이름 ② 언제 트리거되는지 조건 ③ 단계별 절차 ④ 출력 형식(현재 이 프롬프트의 "# 제목 / ## 쉽게 말하면..." 구조 그대로 템플릿화).
4. `~/.claude/skills/<스킬이름>/SKILL.md` 경로에 저장한다 (Claude.ai만 쓴다면 Settings > Skills에 동일 내용 업로드).
5. 1주일간 실제 업무에 사용하면서 출력이 흔들리거나 형식을 벗어나는 부분을 기록한다.
6. 흔들리는 부분에 대해 SKILL.md에 "좋은 예/나쁜 예" 샘플을 추가해 정확도를 보정한다.
7. (수익화 관점) 안정화된 스킬을 "AI 업무 자동화 컨설팅" 산출물의 일부로 패키징 — 클라이언트에게 스킬 세트 + 사용 가이드를 함께 납품하는 상품화를 고려한다.

## 예상 공수
- 저장소 탐색 + 스킬 선정: 30분~1시간 (난이도 하)
- SKILL.md 초안 작성 1개: 1~2시간 (난이도 중)
- 1주일 실사용 + 보정 사이클: 하루 10분씩 누적 1~2시간 (난이도 하)
- 총 초기 투입: 반나절 이내, 이후 유지보수는 거의 없음

## 리스크/유의점
- 원본 게시물의 "3달 만에 팔로워 9만"은 스킬 자체의 효과가 아니라 콘텐츠 전략 결과일 가능성이 높으므로, 스킬 도입만으로 유사한 성과를 기대하지 않는다.
- 공개된 8개 스킬 목록은 `anthropics/skills`에서 대부분 무료로 구할 수 있으므로, 인스타 댓글에 "문서"를 달아 유료/개인 배포본을 받을 필요는 없다 (프라이버시·출처 불명 리스크만 추가됨).
- SKILL.md가 너무 구체적이면 업무 변형(예외 케이스)에 취약해지므로, 처음엔 느슨하게 작성하고 실사용 피드백으로 점진적으로 구체화하는 것이 안전하다.
