# Laya-CoreML 벤치마킹 — Mac 로컬에서 돌아가는 Jev 대체 모델로 오프라인/무료 타입 추론 SDK 만들기

## 개요
laya-coreml은 Jev처럼 "타입 값 + 확신도"를 즉시 반환하는 모델을 Apple Silicon Mac에서 CoreML로 로컬 구동할 수 있게 포팅한 프로젝트로 보이며, 이는 API 호출 비용·네트워크 지연·데이터 유출 우려 없이 Jev급 추론을 완전 오프라인으로 할 수 있다는 가치가 있다. 이를 검증해 API 비용에 민감한 개인 개발자/인디해커를 대상으로 "로컬 우선 Jev 대체 SDK"를 판매하거나, macOS 앱(오프라인 분류·라우팅 기능)에 임베딩해 일회성 구매 제품으로 수익화할 수 있다.

## 구현 가능성 — 중
- 가능 근거: CoreML은 애플 공식 온디바이스 추론 프레임워크로 문서화가 잘 되어 있고 Apple Silicon Mac에서 Neural Engine 가속을 바로 활용할 수 있으며, 저장소가 공개돼 있어 즉시 클론해 테스트 가능하다.
- 제약 근거: HN 포인트 1점, 댓글 0개로 사실상 검증되지 않은 프로젝트이며, 실제로 Jev와 동등한 정확도·속도를 내는지, 라이선스가 상업적 재배포를 허용하는지 확인되지 않았다. "laya"라는 이름이 실제 Jev(TypeSafe AI System One) 아키텍처를 재현한 것인지 단순 분류기 수준인지 원문 설명이 부족해 코드/README를 직접 확인해야 한다.

## 필요 도구
- laya-coreml GitHub 저장소 (무료, 오픈소스 — 라이선스 확인 필요)
- Xcode + coremltools (모델 변환/빌드, 무료)
- Apple Silicon MacBook (M1 이상, 사용자 보유)
- Python 3.10+ / PyTorch (모델 변환·벤치마크용, 무료)
- Swift Package Manager 또는 Python CoreML 런타임 바인딩 (무료)
- TypeSafe AI Jev API 키 (유료, 종량제 — 비교 벤치마크용)
- pytest + 시간 측정 스크립트 (무료)
- Homebrew (의존성 관리, 무료)
- Gumroad 또는 GitHub Sponsors (판매 채널, 거래 수수료만 발생)

## 구현 단계
1. laya-coreml 저장소를 클론해 README와 라이선스(MIT/Apache 등 상업적 이용 가능 여부)를 확인하고, 모델 아키텍처·입출력 스펙(타입 스키마, 확신도 반환 형식)을 파악한다.
2. Xcode/coremltools로 로컬 환경에 모델을 빌드하고, 샘플 입력으로 실제 추론이 동작하는지 1차 스모크 테스트를 수행한다.
3. Jev API와 동일한 태스크(예: 텍스트 분류, 라우팅 판단 등) 10~20개 샘플을 준비해 laya-coreml 로컬 추론과 Jev API 결과(정확도, 지연시간, 비용)를 나란히 비교하는 벤치마크 스크립트를 작성한다.
4. 벤치마크 결과를 바탕으로 laya-coreml이 실사용 가능한 수준(정확도 격차, 지연시간)인지 판단하고, 격차가 크면 파인튜닝 또는 양자화(quantization)로 정확도-속도 트레이드오프를 조정한다.
5. 검증된 모델을 macOS용 경량 SDK(Swift Package 또는 Python 패키지)로 감싸 "오프라인 Jev 대체 라우터" 형태로 패키징한다 — API 키 불필요, 완전 로컬 실행이 핵심 셀링 포인트.
6. 이 SDK를 개인 개발자/인디해커 대상으로 GitHub Sponsors 또는 Gumroad를 통해 "라이선스 + 지원" 형태로 판매하거나, macOS 메뉴바 앱(예: 로컬 이메일/파일 자동 분류기)에 임베딩해 일회성 구매 앱으로 출시한다.
7. 오프라인 상태에서 실시간 분류가 동작하는 데모를 만들어 Show HN/Product Hunt에 공개해 초기 사용자를 모으고, 피드백에 따라 지원 태스크 종류를 확장한다.

## 예상 공수
- 저장소 검증 + 라이선스 확인: 1~2시간
- CoreML 빌드/스모크 테스트: 4~6시간
- Jev 대비 벤치마크 스크립트: 6~8시간
- 정확도/속도 튜닝(양자화 등): 8~12시간
- SDK 패키징(Swift/Python): 8~10시간
- 판매 채널(Gumroad/앱) 셋업: 4~6시간
- **총 31~44시간 (1~2주 파트타임), 난이도: 중상** (CoreML/모델 변환 경험이 없으면 상)

## 리스크/유의점
- 원문 신호가 극히 약함(포인트 1, 댓글 0) — laya-coreml이 실제로 Jev 수준의 정확도를 내는지, 심지어 활발히 유지보수되는 프로젝트인지부터 직접 검증해야 하며, 방치된(dead) 프로젝트일 위험이 있다.
- 오픈소스 모델을 상업적으로 재패키징/판매할 경우 라이선스(특히 학습 데이터나 원본 가중치 출처)를 명확히 확인하지 않으면 법적 리스크가 있다.
- Jev는 TypeSafe AI의 상표/제품이므로 "Jev 대체품"이라는 마케팅 문구가 상표권을 침해하지 않도록 "Jev 호환" 대신 "Jev와 유사한 로컬 추론"처럼 표현에 유의해야 한다.
- Apple Silicon 전용(Neural Engine 의존)일 가능성이 높아 Intel Mac이나 다른 OS 사용자는 지원 대상에서 제외될 수 있다.
