# Jev 기반 서브에이전트 라우터 (OpenCode Agent Router)

## 쉽게 말하면
여러 알바생에게 일을 나눠줄 때, 어려운 일은 숙련자에게 맡기고 쉬운 일은 저렴한 신입에게 맡기면 같은 인건비로 더 많은 일을 처리할 수 있습니다. OpenCode Agent Router는 이 원리를 AI 에이전트(Jev)에 그대로 적용해, 작업 난이도에 따라 자동으로 비싼 모델과 저렴한 모델에 일을 나눠 보내주는 도구입니다. 결과적으로 같은 구독료로 AI를 더 오래, 더 많이 쓸 수 있게 됩니다.

## 이걸로 할 수 있는 것
1. Claude Code에서 실행하는 서브에이전트 작업(파일 검색, 코드 리뷰, 아키텍처 설계 등)을 유형별로 나눠, 단순 작업은 저렴한 모델로, 복잡한 작업만 고급 모델로 보내 월 구독 사용량을 아끼는 개인용 설정을 만든다.
2. 이렇게 확보한 여유 사용량으로 고객사 코드베이스 감사·리팩토링·자동화 스크립트 제작 같은 유료 컨설팅 작업을 추가로 더 처리해 같은 구독료로 매출을 늘린다.
3. 다듬어진 라우팅 규칙 세트를 "Claude Code 비용 최적화 셋업" 상품으로 패키징해 다른 프리랜서나 소규모 에이전시에 판매한다.

## 개요
OpenCode Agent Router는 들어오는 작업의 성격을 판단해 적합한 모델로 자동 분배하는 라우팅 레이어로, 목적은 비용 절감과 구독 한도(요청 수·토큰) 연장입니다. Claude Code 사용자 입장에서는 이 발상을 서브에이전트 정의(model 지정)에 그대로 이식하면, 별도 도구 없이도 동일한 절감 효과를 낼 수 있습니다.

## 구현 가능성: 상
- Claude Code는 이미 서브에이전트별 model override(sonnet/opus/haiku 등)를 공식 지원하며, `.claude/agents/*.md` frontmatter에서 모델을 지정할 수 있고 Agent 호출 시에도 model 파라미터로 개별 지정이 가능함(현재 세션에서도 확인된 기능).
- 즉 oc-agent-router 코드를 그대로 이식할 필요 없이, 기존 Claude Code 기능만으로 유사한 라우팅을 macOS 개인 환경에서 바로 구현 가능.

## 필요 도구
- Claude Code CLI (이미 사용 중, 유료 구독)
- `.claude/agents/*.md` 에이전트 정의 파일 (무료, 직접 작성)
- oc-agent-router 저장소 — https://github.com/maharshi365/oc-agent-router (무료, 라우팅 아이디어 참고용)
- 텍스트 에디터/스크립트 (무료, 라우팅 규칙 정리용)
- (선택) 사용량 추적용 세션 로그 분석 스크립트 (무료, 직접 작성)

## 구현 단계
1. oc-agent-router 저장소를 읽고 어떤 기준(작업 키워드, 요청 유형 등)으로 모델을 분배하는지 라우팅 로직을 파악한다.
2. 본인이 자주 쓰는 Claude Code 작업을 유형별로 분류한다 (단순 검색/파일 찾기, 코드 리뷰, 아키텍처 설계, 반복 리팩토링 등).
3. 각 유형에 맞는 최소 비용 모델을 매핑한 표를 만든다 (예: 검색·grep류 → Haiku, 코드리뷰·버그탐지 → Sonnet, 복잡한 멀티스텝 설계 → Opus).
4. `.claude/agents/` 아래에 유형별 서브에이전트 정의 파일을 만들고 frontmatter에 model을 지정한다 (예: 검색 전용 에이전트에 model: haiku).
5. Agent tool 호출 시 규칙에 따라 subagent_type과 model을 명시적으로 지정하는 습관을 들이거나, 프롬프트 키워드에 따라 자동으로 적절한 에이전트를 고르는 간단한 스킬/래퍼 스크립트를 만든다.
6. 1~2주간 사용량(토큰 소비, 구독 한도 도달 빈도)을 기록해 라우팅 적용 전후를 비교한다.
7. 절감 효과가 확인되면 라우팅 규칙을 CLAUDE.md나 스킬로 문서화해 재사용하고, 효과가 크면 "Claude Code 비용 최적화 셋업" 서비스로 다른 사용자에게 제안한다.

## 예상 공수
- 저장소 조사 및 라우팅 규칙 설계: 1~2시간 (난이도: 하)
- 서브에이전트 정의 파일 작성 및 테스트: 2~3시간 (난이도: 중)
- 사용량 비교 측정: 1주일 자연 관찰 + 30분 분석 (난이도: 하)
- 총합: 실작업 4~6시간 + 1주 관찰

## 리스크/유의점
- 무리하게 저렴한 모델로 라우팅하면 복잡한 작업의 품질이 떨어져 재작업 비용이 오히려 더 들 수 있음 — 품질 저하가 감지되면 즉시 상위 모델로 되돌릴 기준을 미리 세울 것.
- oc-agent-router는 HN 포인트 1점, 댓글 0개인 초기 단계 프로젝트로 커뮤니티 검증이 거의 없음 — 코드를 그대로 가져다 쓰기보다 아이디어만 참고하고 Claude Code 자체 기능으로 구현하는 편이 안전.
- 모델별 가격·구독 한도 정책은 자주 바뀌므로, 구현 전 최신 Claude Code 요금제 정책을 다시 확인해야 함.
