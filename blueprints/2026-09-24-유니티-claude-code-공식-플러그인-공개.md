# 유니티 공식 Claude Code 플러그인으로 게임 개발 자동화·수익화하기

## 쉽게 말하면
유니티(게임 만드는 프로그램)가 클로드 코드와 공식으로 손을 잡아서, 이제 채팅하듯 말로 지시하면 게임 코드와 씬을 직접 만들고 고쳐주는 기능이 생겼습니다. 마치 게임 개발 조수를 한 명 고용한 것과 같아서, 혼자서도 프로토타입 게임이나 인앱 로직을 훨씬 빠르게 완성할 수 있습니다.

## 이걸로 할 수 있는 것
1. "몬스터가 플레이어를 추적하는 AI 붙여줘" 같은 말로 유니티 씬 안의 오브젝트·스크립트를 자동 생성/수정할 수 있습니다.
2. 주말에 아이디어 하나를 잡아 클로드 코드가 프로토타입 뼈대(캐릭터 조작, UI, 저장 시스템)를 짜게 하고, 나는 게임성과 아트만 다듬어 스팀/itch.io에 빠르게 출시할 수 있습니다.
3. 유니티 초보 클라이언트를 위해 "버그 자동 진단 + 수정 제안" 워크플로를 만들어 외주·컨설팅 상품으로 판매할 수 있습니다.

## 개요
유니티 에디터와 클로드 코드를 공식 플러그인으로 연결해, 자연어 지시만으로 C# 스크립트 작성, 씬 조작, 버그 수정, 리팩터링을 자동화합니다. 반복적인 유니티 보일러플레이트 작업 시간을 줄여 1인 개발자도 프로토타입~출시 사이클을 크게 단축할 수 있다는 점이 핵심 가치입니다.

## 구현 가능성
**상** — 유니티 공식 지원 플러그인이므로 설치·인증 절차가 표준화되어 있고, 맥북에서 유니티 에디터 자체가 이미 정식 지원됩니다. 클로드 코드도 이미 macOS에서 정상 동작하므로 추가 인프라 없이 개인 환경에서 바로 시도 가능합니다.

## 필요 도구
- Unity Hub + Unity Editor (무료, Personal 라이선스 기준 연 매출 20만 달러 미만 무료)
- Claude Code CLI (Anthropic 계정/API 사용량 기준 과금)
- Claude Code용 Unity 공식 플러그인 (무료, Unity Asset Store 또는 Package Manager에서 설치 추정 — 정식 출시 공지 확인 필요)
- Git (버전 관리, 무료)
- (선택) Steam/itch.io 개발자 계정 — 출시 시 Steam Direct는 건당 100달러

## 구현 단계
1. Unity Hub에서 최신 LTS 버전 Unity Editor를 macOS에 설치한다.
2. 터미널에서 `claude` CLI가 정상 실행되는지 확인하고, 기존 워크플로(ai-info-radar 등)와 별도 프로젝트 디렉터리를 만든다.
3. Unity 공식 발표(전자신문 기사·Unity 블로그)를 확인해 플러그인 설치 경로(Package Manager vs Asset Store)와 요구 버전을 파악한다.
4. 플러그인 설치 후 Unity 프로젝트 루트에서 Claude Code를 연결하고, 간단한 테스트 지시("빈 큐브를 생성해줘")로 연동을 검증한다.
5. 작은 프로토타입 하나(예: 3분짜리 캐주얼 게임)를 정해 클로드 코드에 스크립트/씬 생성을 위임하며 실사용 워크플로를 체득한다.
6. 반복되는 지시 패턴(캐릭터 컨트롤러, UI 바인딩 등)을 커스텀 슬래시 커맨드나 CLAUDE.md 규칙으로 정리해 재사용 가능한 템플릿화한다.
7. 완성된 미니 게임을 itch.io에 무료/유료로 올리거나, 워크플로 자체를 노션/유튜브 콘텐츠로 정리해 "유니티+클로드 코드 활용법" 강의·전자책으로 판매를 검토한다.

## 예상 공수
- 설치·연동 테스트: 1~2시간 (난이도 하)
- 첫 프로토타입 완성: 8~15시간 (난이도 중, 유니티 사전 지식에 따라 변동)
- 재사용 템플릿/콘텐츠화: 추가 5~10시간 (난이도 중)

## 리스크/유의점
- 플러그인이 방금 공개된 상태라 문서·안정성이 미흡할 수 있어 초기에는 버그·호환성 이슈에 부딪힐 가능성이 높다.
- 유니티 Personal 라이선스 매출 한도, Asset Store 정책 등 상업화 시 라이선스 조건을 사전 확인해야 한다.
- AI가 생성한 코드의 저작권·에셋 출처 문제는 출시 전 직접 검수가 필요하다.
- 클로드 코드 API 사용량이 늘면 비용이 발생하므로, 프로토타입 단계부터 사용량을 모니터링하는 것이 좋다.
