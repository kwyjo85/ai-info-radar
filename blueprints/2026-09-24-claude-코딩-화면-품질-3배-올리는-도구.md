# Claude 코딩 화면 품질 3배 올리는 도구

## 쉽게 말하면
클로드에게 코드만 시키면 "일단 돌아가는" 화면을 만들지만, 자기가 만든 화면을 직접 눈으로 보고 고치는 눈(Playwright), 세련된 디자인 감각을 참고하는 안목(Taste Skill), 사진 한 장을 코드로 바꾸는 손(Image to Code)을 붙여주면 결과물이 확 달라집니다. 요리사에게 완성된 요리를 직접 맛보게 하고, 유명 셰프의 플레이팅 사진을 참고자료로 주고, 손님이 원하는 요리 사진을 보여주는 것과 같습니다.

## 이걸로 할 수 있는 것
1. ig-dashboard 같은 개인 프로젝트 화면을 클로드가 스스로 스크린샷 찍어 확인하며 촌스러운 배치·색상을 자동으로 고치게 한다.
2. 고객사(코코베이비 등) 랜딩페이지 시안을 만들 때 원하는 레퍼런스 디자인 사진 한 장만 던져주면 비슷한 코드가 바로 나온다.
3. Claude Code 기반 외주/사이드 프로젝트에서 "디자인 감각 있는 코더"로 포지셔닝해 프리랜서 단가를 올리는 근거로 삼는다.

## 개요
이 블루프린트는 Claude Code에 (1) 브라우저 자가검증 도구 Playwright MCP, (2) 디자인 레퍼런스 학습 스킬, (3) 이미지→코드 변환 스킬을 결합해, 클로드가 만든 웹 화면의 완성도를 사람이 일일이 지적하지 않아도 스스로 끌어올리게 만드는 워크플로우입니다. 반복적인 "이거 좀 촌스러운데 고쳐줘" 피드백 사이클을 줄여, 코딩 시간당 산출물 품질과 작업 속도를 동시에 높이는 것이 핵심 가치입니다.

## 구현 가능성 — 상
- Playwright MCP는 Anthropic 공식/커뮤니티에서 실제로 배포 중이고, 이미 이 사용자의 Aside 브라우저 자동화 작업에서 Playwright를 활용 중이라 도구 자체에 대한 학습 곡선이 낮음.
- Taste Skill·Image to Code는 정확한 저장소명은 확인이 필요하지만, "디자인 레퍼런스 기반 스타일 가이드 스킬"과 "스크린샷/이미지→코드"는 Claude Code 스킬 생태계에서 흔한 패턴이라 유사 오픈소스를 찾거나 직접 만들기도 어렵지 않음.
- 세 도구 모두 개인 맥북 환경(로컬 Claude Code)에서 설치·실행이 가능해 별도 서버나 인프라가 필요 없음.

## 필요 도구
- Claude Code (이미 사용 중, 유료 구독 필요)
- Playwright MCP 플러그인 — 무료 (Claude Code 마켓플레이스/플러그인 검색으로 설치)
- Node.js + Playwright 브라우저 바이너리 — 무료 (`npx playwright install` 시 자동 다운로드)
- Taste Skill(또는 유사 "design reference" 스킬) — GitHub 검색 필요, 대부분 무료 오픈소스
- Image to Code 스킬(또는 유사 "screenshot-to-code" 스킬) — GitHub 검색 필요, 대부분 무료
- (선택) 디자인 레퍼런스 이미지 수집용 Dribbble/Mobbin 스크린샷 — 무료(공개 이미지 참고 수준)

## 구현 단계
1. Claude Code에서 `/plugin` 또는 설정 → 플러그인 → 찾아보기에서 "Playwright" 검색해 설치하고, `npx playwright install`로 브라우저 바이너리를 받는다.
2. 터미널에서 "claude code taste skill", "claude skill design reference", "image to code claude skill", "screenshot to code skill" 등의 키워드로 GitHub를 검색해 스타(★) 수와 최근 커밋 활성도로 신뢰할 만한 저장소 2~3개를 후보로 추린다.
3. 후보 스킬의 README를 읽고 라이선스·필요 API 키(있다면) 확인 후, `.claude/skills/` 또는 프로젝트 로컬 스킬 폴더에 클론/설치한다.
4. 이 ig-dashboard 프로젝트의 `dashboard.html`을 테스트 베드로 삼아, "Playwright로 지금 화면 확인하고 레이아웃 개선해줘" 같은 프롬프트로 1차 테스트를 돌려 자가검증이 실제로 작동하는지 확인한다.
5. Taste Skill을 적용해 동일 화면에 디자인 개선 프롬프트를 다시 실행하고, 색상·여백·타이포그래피 변화를 기록한다.
6. 원하는 디자인 사진 1장을 준비해 Image to Code로 새 컴포넌트를 하나 생성해보고 실제 코드 품질(시맨틱 마크업, 반응형 여부)을 점검한다.
7. 적용 전/후 스크린샷을 나란히 캡처해 비교 문서(또는 블로그/포트폴리오용 사례)로 남긴다.
8. 효과가 확인되면 이 워크플로우를 표준 스킬 세트로 CLAUDE.md 또는 프로젝트 템플릿에 등록해, 이후 외주·사이드 프로젝트마다 재사용한다.

## 예상 공수
- Playwright 설치·설정: 30분 (난이도 하)
- Taste Skill/Image to Code 후보 조사 및 설치: 1~2시간 (난이도 중, 신뢰할 저장소 선별이 관건)
- ig-dashboard로 전후 비교 테스트: 1~2시간 (난이도 중)
- 총 예상 공수: 약 3~4시간, 난이도는 중(도구 설치는 쉽지만 "제대로 된" 오픈소스 스킬을 골라내는 검증 과정이 시간이 걸림)

## 리스크/유의점
- Taste Skill·Image to Code는 정확한 공식 명칭/저장소가 아직 미확인 상태라, 이름만 보고 설치하면 저품질/방치된 프로젝트를 잡을 수 있음 — 반드시 커밋 이력·이슈·스타 수를 먼저 확인.
- Playwright로 브라우저를 반복 실행하면 로컬 리소스(CPU/메모리)를 소모하므로, 배터리·발열이 민감한 맥북 환경에서는 장시간 자동 루프는 지양.
- Image to Code로 만든 결과물은 저작권 있는 디자인을 그대로 베낄 위험이 있으므로, 고객 납품용 코드에는 레퍼런스 사진의 출처와 라이선스를 확인한 뒤 사용.
- 캡션의 "설치 링크 댓글 요청"은 마케팅용 유도이며 실제 링크가 아니므로, 원문 게시물에 의존하지 말고 위 단계처럼 직접 검색·검증할 것.
