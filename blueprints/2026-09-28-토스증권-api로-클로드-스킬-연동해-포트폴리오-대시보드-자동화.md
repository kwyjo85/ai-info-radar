# 한국투자증권 API + Claude Code 스킬로 포트폴리오 대시보드 자동화

## 쉽게 말하면
매일 아침 신문·증권사 앱을 일일이 뒤져가며 내 주식 상황을 확인하는 대신, 비서 한 명을 고용해서 "오늘 내 계좌 상태, 실적 발표 일정, 리밸런싱 필요 여부를 정리해서 보고해줘"라고 시키는 것과 같습니다. 단, 이 비서는 사람이 아니라 Claude이고, 증권사 API를 통해 실제 계좌 데이터를 읽어와서 매일 같은 형식의 보고서를 자동으로 만들어줍니다.

## 이걸로 할 수 있는 것
1. 아침에 컴퓨터를 켜면 보유 종목 현황·평가손익·오늘의 실적 발표 일정이 요약된 대시보드를 바로 받아본다.
2. 관심 기업을 입력하면 "무엇으로 돈을 버는지, 매출 구성, 경쟁사, 망하는 시나리오"를 정리한 카드를 자동 생성해 빠르게 기업을 훑어본다.
3. 목표 자산배분 비율을 설정해두면 현재 포트폴리오와 비교해 "무엇을 얼마나 사고팔아야 하는지" 리밸런싱 계산 결과를 받는다.

## 개요
증권사 API로 보유 종목·잔고·거래 내역을 조회하고, Claude Code 스킬이 이 데이터를 가공해 대시보드·기업 분석·리밸런싱 계산 결과를 자동 생성하는 파이프라인입니다. 매일 손으로 계좌를 확인하고 뉴스를 검색하는 반복 작업을 없애고, 투자 판단에 필요한 정보를 한 번에 요약받아 의사결정 속도를 높이는 데 가치가 있습니다. 실거래 자동주문이 아닌 "조회·요약 전용"으로 범위를 한정하는 것이 안전합니다.

## 구현 가능성
**중**
- 근거: 원문의 토스증권 API는 공식 오픈API가 비공개이며 비공식(스크래핑) 경로를 써야 하므로 계정 정지·약관 위반 리스크가 있습니다 [출처의 근거 항목]. 반면 한국투자증권은 공식 오픈API(`open-trading-api`, github.com/koreainvestment/open-trading-api)를 제공하므로 이를 대체 사용하면 구현 가능성이 올라갑니다. 다만 API 인증서 발급, 토큰 관리, Claude Code 스킬 폴더 구조 설계 등 개인 사용자에게는 다소 진입장벽이 있어 "상"까지는 아닙니다.

## 필요 도구
- **Claude (Claude Code / Claude Desktop 스킬 기능)** — 유료 (Pro/Team 플랜 필요 여부 [공식 문서 확인 필요])
- **한국투자증권 open-trading-api** — 무료(증권 계좌 개설 및 API 신청 필요), github.com/koreainvestment/open-trading-api
- **Python 3.x** — 무료, API 호출 스크립트 작성용
- **requests / pandas 라이브러리** — 무료, 데이터 조회·가공용
- **macOS 크론(cron) 또는 launchd** — 무료, 매일 아침 자동 실행 스케줄링용
- **(선택) 실적 발표 일정 API/캘린더 서비스** — 별도 무료/유료 서비스 확인 필요 [공식 문서 확인 필요]
- **로컬 전용 폴더 (예: `~/Desktop/stock-skill/`)** — 스킬·스크립트·설정 파일 저장용

## 구현 단계
1. 한국투자증권 계좌를 개설하고 홈페이지에서 오픈API 이용 신청 후 앱키(App Key)·앱시크릿(App Secret)을 발급받는다.
2. `github.com/koreainvestment/open-trading-api`를 클론하여 샘플 코드로 인증 토큰 발급 및 잔고 조회가 정상 동작하는지 먼저 터미널에서 테스트한다.
3. 맥 데스크탑에 `stock-skill` 전용 폴더를 만들고, 그 안에 Claude Code 스킬 정의 파일과 Python 조회 스크립트(보유종목, 평가손익, 실적일정 조회 함수)를 배치한다.
4. Claude Code에서 해당 스킬을 등록해 "오늘 내 포트폴리오 요약해줘" 같은 명령으로 스크립트를 호출하고 결과를 받아오는지 확인한다.
5. 기업 해독 카드(사업모델, 매출구성, 경쟁사, 리스크 시나리오)를 만들도록 Claude에게 프롬프트 템플릿을 스킬 안에 작성해 넣는다.
6. 목표 자산배분 비율(예: 주식 70%/현금 30%)을 설정 파일에 입력하고, 현재 잔고와 비교해 매수·매도 수량을 계산하는 로직을 스크립트에 추가한다.
7. **자동 매매 주문 기능은 구현하지 않고 조회·요약까지만** 스킬 권한을 제한한다.
8. macOS `launchd`로 매일 아침 정해진 시간에 스크립트+Claude 요약 실행을 예약해 결과를 파일이나 메시지로 받아본다.
9. 1~2주간 실사용하며 API 에러 처리, 토큰 만료 갱신 로직 등을 보완한다.

## 예상 공수
- API 신청·발급 및 테스트: 2~4시간
- Claude Code 스킬 폴더 구성 및 연동: 4~6시간
- 대시보드/기업 카드/리밸런싱 로직 작성: 6~10시간
- 자동 스케줄링 및 안정화: 2~3시간
- **총 예상: 14~23시간, 난이도: 중상 (프로그래밍 기초 및 API 인증 경험 필요)**

## 리스크/유의점
- 원문의 토스증권 API는 비공식 경로일 가능성이 높아 약관 위반·계정 제재 리스크가 있으므로, 공식 API를 제공하는 증권사로 대체하는 것을 권장합니다.
- 실거래 자동주문 기능을 절대 포함하지 말고 조회·요약 전용으로 범위를 한정해야 오작동으로 인한 금전적 손실을 막을 수 있습니다.
- API 인증키(App Key/Secret)와 계좌 정보는 로컬 파일에 평문 저장하지 말고 환경변수나 macOS 키체인에 보관해야 합니다.
- Claude가 생성하는 기업 분석·리밸런싱 결과는 투자 조언이 아니며, 데이터 오류나 환각(hallucination) 가능성이 있으므로 최종 투자 판단은 반드시 본인이 직접 검증해야 합니다.
- 실적 발표 일정 등 부가 데이터는 별도 API/서비스 연동이 필요하며 원문에는 구체적 소스가 명시되어 있지 않으므로 [공식 문서 확인 필요] 상태입니다.
