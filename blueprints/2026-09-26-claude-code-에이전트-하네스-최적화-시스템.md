# ECC: Claude Code 에이전트 하네스 최적화 시스템으로 "실수 안 하는 에이전트" 만들기

## 쉽게 말하면
ECC는 Claude Code에게 "스킬(매뉴얼)", "인스팅트(자동으로 지키는 습관 규칙)", "메모리(과거 작업 기억)", "보안 검사"를 한 번에 심어주는 플러그인입니다. 신입 직원에게 사규집·체크리스트·인수인계 노트를 한꺼번에 쥐여주는 것과 비슷해서, 매번 같은 주의사항을 말로 반복하지 않아도 에이전트가 알아서 실수를 줄입니다.

## 이걸로 할 수 있는 것
1. 매번 "블루프린트는 blueprints/ 폴더에 이 형식으로 써줘"라고 반복 지시하지 않아도, 인스팅트가 자동으로 형식을 지키게 만들어 반복 작업의 지시 비용을 줄인다.
2. 고객사 코드 자동화 외주 작업에서 "커밋 전 시크릿 노출 확인" 같은 보안 체크가 자동으로 걸려, 사고 리스크를 줄인 상태로 납품 속도를 높인다.
3. 여러 프로젝트(코코베이비 대시보드, 외주 건 등)를 오가며 작업할 때 프로젝트별 메모리가 쌓여, "이 프로젝트는 이렇게 일해야 한다"를 매번 새로 설명하지 않아도 된다.

## 개요
ECC는 Claude Code(및 Codex, Cursor 등)의 동작 방식 자체를 커스터마이징하는 하네스 레이어로, 반복되는 지시(스킬)·규칙(인스팅트)·기억(메모리)·안전장치(보안 검사)를 코드가 아니라 설정/플러그인으로 주입합니다. 자동화 수익화 관점에서 가치는 "에이전트를 매번 처음부터 훈련시키는 시간"을 줄여, 같은 시간에 더 많은 자동화 상품·외주 건을 처리할 수 있게 해준다는 점입니다. 다만 기능이 많은 만큼 컨텍스트 토큰 소모가 커서, 목적 없이 전체를 켜두면 오히려 비용·속도 손해가 날 수 있습니다.

## 구현 가능성: 상
- Claude Code 플러그인 형태로 설치되는 표준 확장이라, 별도 인프라나 API 키 발급 없이 공식 채널(marketplace/plugin)에서 바로 적용 가능.
- 26만 스타로 검증 규모가 크고 활발히 관리되는 프로젝트라 문서/이슈 트래킹이 상대적으로 잘 되어 있을 가능성이 높음.
- 단, "과장 3" 평가와 급격한 주간 스타 증가(+6,865)는 어뷰징/가짜 미러 위험 신호이므로, 실제 유용성은 직접 써보기 전까지 상 등급을 전적으로 신뢰하기 어려움.

## 필요 도구
- Claude Code CLI (무료, 이미 사용 중)
- ECC 플러그인 (오픈소스, 무료 — 반드시 공식 슬러그 `ecc@ecc` 또는 공식 저장소 affaan-m/ECC 경유로만 설치)
- (선택) `/context` 명령어 — 설치 전후 토큰 오버헤드 비교용, Claude Code 내장 기능이라 무료

## 구현 단계
1. GitHub에서 `affaan-m/ECC` 저장소가 맞는지 organization/작성자 확인 후, 공식 plugin marketplace 또는 저장소 README에 명시된 설치 명령으로만 설치한다 (검색으로 나오는 유사 이름 미러는 설치 금지).
2. 설치 시 다른 스킬/규칙 팩(예: agent-skills 등)을 동시에 켜지 말고, ECC 단독으로 기본 설정 상태에서 시작한다.
3. 설치 직후 `/context`로 기준 토큰 사용량을 기록해 둔다.
4. 1주일간 평소 하던 작업(블루프린트 작성, 대시보드 데이터 수집, 외주 코드 작업 등)을 그대로 수행하면서 ECC를 켠 상태로 사용한다.
5. 1주일 후 다시 `/context`로 토큰 오버헤드를 측정하고, 체감상 실수(형식 누락, 반복 지시 필요 여부)가 줄었는지 비교한다.
6. 오버헤드가 크거나 실효성이 낮은 모듈은 끄고, 메모리·보안 검사처럼 실질적으로 도움이 된 모듈만 남긴다.
7. 반복 작업(예: 인스타 대시보드 데이터 수집 루틴, 블루프린트 생성 루틴)에서 인스팅트가 실제로 형식 실수·누락을 줄이는지 2주 더 관찰 후 상시 사용 여부를 결정한다.

## 예상 공수
- 총 2~3시간 (설치·기본 설정 1시간, 1주일간 관찰은 별도 작업 시간에 자연 포함, 측정·정리 1~2시간)
- 난이도: 하 (표준 플러그인 설치 수준이나, 모듈 정리·측정에 약간의 주의 필요)

## 리스크/유의점
- 가짜 미러 저장소가 존재한다고 명시되어 있으므로, 설치 전 반드시 공식 저장소 URL·plugin 슬러그를 재확인할 것 (악성 코드 주입 위험).
- "올인원" 특성상 컨텍스트 토큰을 많이 소모해, 짧고 단순한 작업에서는 오히려 응답 속도·비용이 나빠질 수 있음.
- 다른 스킬/규칙 팩과 기능이 겹치면 충돌(우선순위 꼬임, 중복 지시)이 발생할 수 있어 동시 설치는 피할 것.
- 26만 스타·주간 +6,865 증가는 이례적으로 커서 스타 조작 가능성을 배제할 수 없음 — 커뮤니티 평판(이슈, 토론)을 별도로 확인 후 신뢰도를 판단할 것.
