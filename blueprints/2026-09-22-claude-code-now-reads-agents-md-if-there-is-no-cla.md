# Claude Code AGENTS.md 자동 인식 도입

## 개요
Claude Code가 프로젝트 루트에 `CLAUDE.md`가 없을 경우 `AGENTS.md`를 자동으로 읽어 컨텍스트로 사용하는 기능이 추가되었습니다. 이는 여러 AI 코딩 도구(Cursor, Codex, Claude Code 등)가 공통으로 참조하는 단일 설정 파일 표준으로 수렴하고 있음을 의미하며, 개인 개발 환경에서는 도구별 중복 문서 관리 부담을 줄이고 일관된 코딩 규칙을 여러 AI 에이전트에 동시 적용할 수 있게 해줍니다.

## 구현 가능성
**상** — 별도의 코드 작성이나 인프라 구축 없이 파일 하나만 준비하면 즉시 적용되는 기능입니다. macOS 로컬 환경에서 Claude Code CLI만 설치되어 있으면 추가 설정 없이 동작하며, 기존 `CLAUDE.md` 운영 경험을 그대로 재사용할 수 있어 구현 난이도가 매우 낮습니다.

## 필요 도구
- **Claude Code CLI** (무료 — Claude Pro/Max 구독 또는 API 종량제 사용 시 실제 사용료 발생)
- 텍스트 에디터 (VS Code 등, 무료)
- 기존에 운영 중인 리포지토리 (Git, 무료)
- (선택) Cursor, OpenAI Codex CLI 등 AGENTS.md를 함께 지원하는 타 AI 도구 — 표준 파일 공유 효과 확인용 (도구별 무료/유료 상이)

## 구현 단계
1. 현재 사용 중인 macOS의 Claude Code 버전을 확인합니다: `claude --version` 실행 후 최신 changelog(https://code.claude.com/docs/en/changelog) 대비 AGENTS.md 지원 버전인지 확인, 구버전이면 `claude update` 또는 npm 패키지 업데이트로 최신화합니다.
2. 대상 프로젝트 루트에 기존 `CLAUDE.md`가 있는지 확인합니다(`ls CLAUDE.md`). 이미 있다면 우선순위상 `AGENTS.md`가 무시되므로, 마이그레이션 여부를 먼저 결정합니다.
3. `CLAUDE.md`가 없는 프로젝트, 또는 타 AI 도구(Cursor/Codex)와 공용으로 쓸 프로젝트를 선정해 루트에 `AGENTS.md` 파일을 새로 작성합니다. 내용은 프로젝트 개요, 빌드/테스트 명령어, 코딩 컨벤션, 디렉터리 구조 설명 등 기존 CLAUDE.md에 담던 정보와 동일하게 구성합니다.
4. 기존에 `CLAUDE.md`를 운영 중이던 프로젝트라면, 두 파일의 내용을 통합해 `AGENTS.md` 하나로 옮기고 `CLAUDE.md`는 삭제(또는 `AGENTS.md`로 symlink)해 중복 관리를 없앱니다. 단, Claude Code 전용 지시사항(예: 특정 도구 사용 금지 등)이 있다면 호환성 테스트 후 이전합니다.
5. Claude Code를 재시작하거나 새 세션을 열어 `/status` 또는 초기 프롬프트에서 컨텍스트에 프로젝트 정보가 정상적으로 로드되는지 확인합니다. 간단한 질문("이 프로젝트 빌드 명령어가 뭐야?")으로 파일 인식 여부를 검증합니다.
6. 여러 리포지토리를 관리하는 경우, 이 표준화 작업을 적용할 프로젝트 목록을 만들고 순차적으로 `AGENTS.md`로 전환합니다. (선택) 개인 dotfiles나 템플릿 리포지토리에 `AGENTS.md` 템플릿을 저장해 새 프로젝트 생성 시 재사용합니다.

## 예상 공수
- 단일 프로젝트 신규 작성: 30분~1시간 (난이도: 하)
- 기존 CLAUDE.md → AGENTS.md 마이그레이션 (프로젝트당): 15~30분 (난이도: 하)
- 여러 프로젝트(5개 내외) 일괄 전환 + 검증: 총 2~3시간 (난이도: 하~중)

## 리스크/유의점
- `CLAUDE.md`와 `AGENTS.md`가 동시에 존재할 경우 우선순위 규칙(CLAUDE.md 우선)을 정확히 확인하지 않으면 의도한 파일이 무시될 수 있습니다.
- Claude Code 특화 지시문(예: 특정 슬래시 커맨드, 훅 설정 안내 등)을 AGENTS.md로 그대로 옮기면 다른 AI 도구(Cursor 등)에서 불필요하거나 혼동을 줄 수 있으므로, 공용 부분과 도구별 특화 부분을 분리 관리하는 것이 안전합니다.
- 버전이 낮은 Claude Code에서는 이 기능이 동작하지 않으므로 사전 버전 확인이 필수입니다.
- 민감 정보(API 키, 내부 인프라 상세)를 AGENTS.md에 넣지 않도록 주의 — 여러 AI 도구가 이 파일을 읽는다는 점에서 노출 범위가 CLAUDE.md 대비 넓어질 수 있습니다.
