# Sitcom Flavour — Claude Code 답변에 캐릭터 성격 입히기

## 쉽게 말하면
회사 안내 로봇이 늘 딱딱하게 말하다가 성공했을 때만 예능 자막처럼 "이야~" 하고 한마디 던지면, 사람들이 그 로봇에 정을 붙이고 더 자주 찾게 됩니다. CLAUDE.md(작업 규칙 파일)에 문장 한 줄만 추가하면 Claude Code가 일이 잘 풀렸을 때 "Noice", "Hot damn" 같은 시트콤 대사를 타이밍 좋게 섞어줍니다.

## 이걸로 할 수 있는 것
1. 장시간 코딩 세션에서 지치지 않도록 개인 Claude Code에 소소한 재미 요소를 넣는다.
2. AI 자동화 컨설팅 미팅에서 "CLAUDE.md 한 줄로 이렇게까지 커스터마이징된다"는 것을 보여주는 라이브 데모 소재로 쓴다.
3. Jev 등 사내/개인용 AI 어시스턴트에 브랜드 말투(페르소나)를 입혀 사용자들이 더 자주, 더 오래 쓰게 만드는 "채택률 개선" 상품 아이디어로 확장한다.

## 개요
CLAUDE.md에 조건부 스타일 지시문 한 줄을 추가해 Claude Code 응답 톤에 캐릭터 성격을 씌우는 기법입니다. 코드나 API 호출 없이 텍스트 지시만으로 AI 경험을 차별화할 수 있다는 점이 핵심 가치이며, 원격 저장소나 영구 산출물에는 새지 않도록 스코프를 제한하는 것이 설계의 핵심입니다.

## 구현 가능성: 상
근거: CLAUDE.md는 이미 사용 중인 파일이고 텍스트 한 줄 추가만으로 즉시 재현 가능합니다. HN에 공유된 실제 사례와 MIT 라이선스 오픈소스 플러그인이 이미 존재해 검증된 패턴입니다.

## 필요 도구
- Claude Code CLI (이미 보유, 무료)
- CLAUDE.md 파일 편집 (무료, 기본 텍스트 에디터)
- (선택) sitcom-flavour 플러그인 — GitHub, MIT 라이선스, 무료 (https://ada.tools/sitcom-flavour/ 에서 링크 확인)
- (선택, 상품화 시) GitHub Pages — 템플릿/랜딩페이지 호스팅용, 무료

## 구현 단계
1. 현재 프로젝트 또는 글로벌 CLAUDE.md 파일을 열어 "톤/스타일" 섹션에 규칙 문장을 추가한다.
2. 규칙에 트리거 조건과 금지 조건을 명확히 명시한다 — 예: "승리·클린 결과일 때만, 원격에 push되거나 대화 밖으로 남는 산출물에는 절대 넣지 않기".
3. 며칠간 실제 세션에서 트리거 빈도와 타이밍이 적절한지 관찰하고 문구를 다듬는다.
4. 컨설팅/포트폴리오 활용을 원하면 B99·오피스·프렌즈 등 캐릭터별 CLAUDE.md 스니펫을 정리해 GitHub 템플릿 저장소로 만든다.
5. 클라이언트 미팅에서 "Claude Code 커스터마이징 사례"로 짧게 시연해 컨설팅 서비스의 신뢰도·차별점을 보여준다.
6. Jev 프로젝트에 적용을 검토할 경우, 별도 페르소나 규칙 파일을 만들어 클라이언트/상황별로 On·Off 토글 가능하게 구성한다.

## 예상 공수
개인 적용: 5~10분, 난이도 최하(문장 한 줄 추가 수준)
템플릿·포트폴리오화: 1~2시간, 난이도 하

## 리스크/유의점
- 클라이언트 대상 세션이나 진지한 작업에서 과도하게 트리거되면 전문성이 떨어져 보여 역효과가 날 수 있음.
- 원격 저장소에 올라가는 커밋 메시지, 문서, PR 설명 등 "남는 산출물"에는 절대 섞이지 않도록 규칙에 명시해야 함(이미 사용자 지침에도 유사한 원칙 존재).
- 직접적인 매출 창출 효과는 낮고, 주로 "브랜딩·차별화·데모 소재" 성격의 부가가치이므로 핵심 자동화 수익 모델 대비 우선순위는 낮게 두는 것이 적절함.
