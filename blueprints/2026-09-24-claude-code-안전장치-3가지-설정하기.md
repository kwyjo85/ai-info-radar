# Claude Code 안전장치 3가지 설정하기

## 쉽게 말하면
클로드에게 코드를 맡길 때 "일단 계획부터 보여줘", "다른 사람이 한 번 더 검토해줘", "같은 실수는 메모해뒀다가 다음엔 걸러줘"라는 안전벨트 세 개를 채우는 것입니다. 자동차에 브레이크·에어백·후방카메라를 다는 것과 비슷해서, 사고가 아예 안 나는 건 아니지만 사고 나도 크게 안 다칩니다.

## 이걸로 할 수 있는 것
1. 클라이언트 프로젝트에서 클로드가 파일을 바로 고치기 전에 계획만 먼저 보여주게 해서, 잘못된 수정이 배포되기 전에 걸러낸다.
2. 부업으로 만드는 Jev/자동화 스크립트를 별도 세션(서브에이전트)에게 다시 검토시켜, 원 작성자가 놓친 가정 오류(버그)를 발견해 신뢰도를 높인다.
3. ai-info-radar 같은 반복 운영 프로젝트에서 collector.js 등에 실수를 CLAUDE.md에 규칙으로 쌓아, 같은 실수를 유료 자동화 상품에서 반복하지 않는다.

## 개요
Claude Code의 plan mode, 교차검증용 서브에이전트, CLAUDE.md 규칙 누적이라는 세 가지 공식 기능을 설정 파일 한 번 손보는 것만으로 상시 적용되게 만드는 것입니다. 수익화 관점에서는 "AI가 짠 코드/자동화를 고객에게 넘기기 전 품질 게이트"로 작동해, 유료 자동화 서비스나 Jev 기반 상품의 신뢰도와 재작업 비용을 동시에 개선합니다.

## 구현 가능성
**상** — 전부 Claude Code 공식 기능(permission-mode, CLAUDE.md, subagent)이고 설정 파일 경로·CLI 플래그가 이미 정확히 확인됨. 코드 작성이나 외부 API 연동 없이 설정 변경 + 텍스트 파일 작성만으로 즉시 적용 가능하며, 이미 사용 중인 ai-info-radar 프로젝트에 바로 붙일 수 있음.

## 필요 도구
- Claude Code CLI (이미 사용 중, 무료 설치·유료는 Anthropic 사용량 과금)
- `~/.claude/settings.json` (Claude Code 내장 설정 파일, 비용 없음)
- 텍스트 에디터 (VS Code 등, 무료)
- (선택) rebornlabs.ai 배포기 스크립트 — 셸 원라이너, 무료(MIT), 다만 제3자 스크립트이므로 내용 검토 후 사용 권장

## 구현 단계
1. `~/.claude/settings.json`을 열어 `permissions.defaultMode`가 이미 값이 있는지 확인한다(있으면 덮어쓰지 않음).
2. 값이 없다면 `"permissions": { "defaultMode": "plan" }`을 추가해 모든 세션이 기본적으로 계획 승인 후 수정하도록 만든다. 특정 세션만 임시로 쓰려면 `claude --permission-mode plan`으로 실행한다.
3. 중요한 변경(배포 전 코드, 고객 납품용 자동화)을 마친 뒤에는 같은 대화창이 아니라 새 세션 또는 서브에이전트를 열어 "방금 짠 코드를 처음부터 다시 검토해줘"라고 요청한다 — Task/Agent 도구로 별도 컨텍스트를 만들면 원 작성자의 가정을 물려받지 않는다.
4. 관리 중인 프로젝트 루트(예: `ai-info-radar/`, Jev 관련 작업 디렉터리)에 `CLAUDE.md`를 생성한다.
5. 실수를 발견할 때마다 "무엇을 · 왜 · 어기면 어떻게 되는지" 형식으로 한 줄씩 추가한다. 예: `collector.js의 scrapePost는 og:description 파싱이 기본, article h1은 신뢰 불가 - 어기면 캡션이 비어 나옴`.
6. 이번 라우틴에서 이미 알고 있는 함정들(creators maxScroll=0 버그, account 빈 문자열 케이스)을 먼저 CLAUDE.md에 채워 넣어 즉시 효과를 검증한다.
7. 한 주 정도 사용해보며 서브에이전트 검토에서 실제로 잡힌 버그 건수를 기록해, 고객에게 "AI 코드 품질 검증 프로세스"로 설명할 수 있는 근거 자료로 남긴다.

## 예상 공수
- 설정 파일 수정 + CLAUDE.md 초기 작성: 30분~1시간
- 기존 프로젝트(ai-info-radar 등)에 알려진 함정 규칙 이관: 30분
- 서브에이전트 검토 워크플로우를 습관화하는 데: 1~2주 (반복 사용하며 자연스러워짐)
- 난이도: **하** (코딩 불필요, 설정·문서 작업만)

## 리스크/유의점
- plan mode는 매 변경마다 승인 절차가 생겨 속도가 느려짐 — 긴급 수정에는 오히려 방해될 수 있음.
- 버그를 "줄이는" 것이지 "없애는" 것이 아니므로, 이것만 믿고 최종 검수를 생략하면 안 됨(고객 납품 자동화는 특히).
- rebornlabs.ai의 "설치 한 줄" 스크립트는 제3자 제작이며 Anthropic과 무관 — 실행 전 스크립트 내용을 직접 확인할 것.
- CLAUDE.md 규칙이 너무 많아지면 오히려 컨텍스트를 낭비하므로, 주기적으로 더 이상 유효하지 않은 규칙은 정리 필요.
