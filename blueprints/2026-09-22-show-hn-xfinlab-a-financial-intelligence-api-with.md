# Xfinlab MCP 서버 기반 금융 인텔리전스 자동화 — 개인 MacBook 블루프린트

## 개요
Xfinlab은 주가·재무제표·시장 지표 등 금융 데이터를 제공하는 API에 MCP(Model Context Protocol) 서버를 결합해, AI 에이전트가 자연어 질의만으로 종목 분석·리서치·리포트 작성을 수행할 수 있게 하는 오픈소스 프로젝트다. 개인 MacBook 환경에서는 이를 Claude Desktop/Code의 MCP 서버로 등록해 "이 종목의 최근 실적과 밸류에이션을 정리해줘" 같은 요청을 사람이 직접 데이터를 조회하지 않고도 자동으로 처리하는 개인 투자 리서치 보조 도구로 활용할 수 있다.

## 구현 가능성 — 중
- MCP 서버 등록 자체는 표준 절차(`.mcp.json` 편집 후 재시작)라 macOS에서 진입장벽은 낮음.
- 다만 HN 포인트 3점, 댓글 0개로 검증되지 않은 신생 레포이며, 실제 데이터 소스(자체 크롤링인지 외부 API 재판매인지), 인증키 필요 여부, 요청 제한(rate limit)이 README만으로는 불명확해 사전 확인 없이는 신뢰도 있는 리서치 도구로 바로 쓰기 어려움.
- 금융 데이터 API는 통상 무료 티어의 지연 데이터(delayed data) 또는 호출 제한이 있어, 실시간성이 필요한 용도라면 별도 검증이 추가로 필요함.

## 필요 도구
- **Xfinlab MCP 서버** — github.com/lnanology/Xfinlab (오픈소스, 무료·단 내부적으로 유료 금융 데이터 API를 프록시할 가능성 있어 레포 확인 필요)
- **Claude Desktop 또는 Claude Code** — MCP 클라이언트 (이미 보유 중이라 가정)
- **Python 3.10+ 또는 Node.js** — 레포의 실제 구현 언어에 따라 필요 (무료, `brew install python` 또는 `brew install node`)
- **Homebrew** — 런타임 설치용 (무료)
- **(가능성) 금융 데이터 제공사 API 키** — Xfinlab이 자체 데이터가 아닌 외부 API(예: Alpha Vantage, Polygon.io 등)를 감싸는 구조일 경우 별도 키 발급 필요 (무료 티어 존재하나 호출 제한 있음)

## 구현 단계
1. https://github.com/lnanology/Xfinlab 레포의 README를 읽고 (a) 설치 방법(pip/npm/Docker 등), (b) 필요한 API 키 유무, (c) 지원하는 MCP 툴 목록(예: 주가 조회, 재무제표, 뉴스)을 정확히 파악한다.
2. 레포의 라이선스와 최근 커밋 이력을 확인해 유지보수 활성도와 데이터 출처 신뢰성을 점검한다.
3. 로컬에 필요한 런타임(Python 가상환경 또는 Node)을 준비하고, 레포를 클론한 뒤 `pip install -r requirements.txt` 또는 `npm install` 등 명시된 절차로 의존성을 설치한다.
4. 필요한 API 키가 있다면 발급받아 `.env` 파일 등 레포가 요구하는 방식으로 로컬에 설정한다 (키는 절대 git에 커밋하지 않는다).
5. MCP 서버를 단독으로 실행해 정상 기동 및 샘플 요청(예: 특정 종목 조회) 응답을 CLI에서 먼저 검증한다.
6. `~/Library/Application Support/Claude/claude_desktop_config.json` (Claude Desktop) 또는 프로젝트의 `.mcp.json` (Claude Code)에 Xfinlab 서버를 등록한다:
   ```json
   {
     "mcpServers": {
       "xfinlab": {
         "command": "python",
         "args": ["-m", "xfinlab_mcp"]
       }
     }
   }
   ```
   (정확한 command/args는 1단계에서 확인한 실제 실행 명령으로 대체)
7. Claude Desktop/Code를 재시작해 MCP 도구 목록에 Xfinlab 툴이 노출되는지 확인하고, "AAPL 최근 분기 실적 요약해줘" 같은 실제 질의로 end-to-end 테스트를 진행한다.
8. 응답 데이터의 정확성(가격 지연 여부, 데이터 기준일)을 실제 시세와 대조해 검증하고, 신뢰 가능한 범위(예: 참고용 리서치 보조, 실거래 의사결정 제외)를 스스로 정한다.

## 예상 공수
- 레포 조사 및 데이터 출처/API 키 확인: 30분~1시간
- 설치 및 MCP 연동: 1~1.5시간
- 실제 질의 테스트 및 데이터 정확성 검증: 1시간
- **총 예상: 2.5~3.5시간, 난이도: 중** (MCP 연동 자체는 쉽지만, 신생 프로젝트라 설치 중 예상치 못한 의존성/설정 이슈 대응에 시간이 더 들 수 있음)

## 리스크/유의점
- **검증 부족**: HN 포인트 3점, 댓글 0개로 커뮤니티 검증이 전무한 초기 프로젝트라, 데이터 정확성이나 보안 취약점이 아직 드러나지 않았을 가능성이 있음.
- **데이터 신뢰성**: 금융 데이터가 지연(delayed)되거나 특정 출처에 편향될 수 있어, 실제 투자 판단에 그대로 의존하지 않고 참고 자료로만 사용해야 함.
- **API 키/비용 노출**: 외부 금융 데이터 API를 프록시하는 구조라면 무료 티어의 호출 제한을 초과해 예상치 못한 과금이나 서비스 차단이 발생할 수 있음.
- **서드파티 코드 실행 리스크**: 검증되지 않은 오픈소스를 로컬에서 실행하므로, 클론 전 소스코드를 훑어보고 의심스러운 외부 통신이나 자격증명 수집 로직이 없는지 확인 권장.
- **유지보수 중단 가능성**: 초기 단계 개인 프로젝트는 지속적인 관리가 보장되지 않으므로, 핵심 워크플로우의 유일한 데이터 소스로 의존하지 않는 것이 안전.
