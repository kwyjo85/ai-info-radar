# Tenjin: Jev 기반 Claude Code 도구 라우터로 에이전트에 필요한 툴 자동 장착하기

## 쉽게 말하면
Claude Code로 일하다 보면 "지금 웹 검색이 필요한데", "이 사이트를 크롤링해야 하는데" 하는 순간이 자주 옵니다. Tenjin은 옆에서 지켜보다가 "지금은 이 도구가 필요하겠다" 싶으면 그 도구를 알아서 에이전트 손에 쥐여주는 비서 같은 존재입니다. 마치 요리하다가 필요한 도구를 누가 미리 예측해서 슬쩍 건네주는 것과 비슷하며, 도구 사용료는 지갑에서 건당 1~2센트씩 자동으로 빠져나갑니다.

## 이걸로 할 수 있는 것
1. 클라이언트 프로젝트 코드를 분석하다가 최신 문서가 필요할 때, 별도 설정 없이 Context7 도구가 자동으로 붙어 정확한 라이브러리 문서를 즉시 참조한다.
2. 웹 리서치가 필요한 작업(경쟁사 분석, 최신 트렌드 조사)을 맡기면 Exa 검색이 자동 개입해 결과를 더 정확하게 만든다.
3. 고객사 사이트나 경쟁사 페이지를 스크래핑해야 하는 자동화 업무에서 Firecrawl이 자동으로 투입되어 별도 API 키 발급·연동 작업 없이 처리된다.

## 개요
Tenjin은 Claude Code 세션(마스킹된 프롬프트, 세션 컨텍스트, 웹 검색, 서브에이전트 작업)을 Jev 모델이 실시간으로 관찰해 "지금 어떤 외부 도구가 필요한지"를 판단하고, 필요한 순간에 Exa·Firecrawl·Context7 같은 큐레이션된 도구를 에이전트에 동적으로 주입하는 라우터입니다. 핵심 가치는 (1) 도구별 API 키 발급·환경변수 관리를 없애고 (2) x402 프로토콜 기반 종량제 결제(지갑에서 콜당 소액 자동 차감)로 "설정 없는 도구 확장"을 실현한다는 점입니다. 수익화 관점에서는, 이걸 활용해 "고객 요청 시 필요한 리서치·크롤링·문서 조회 도구를 알아서 갖다 쓰는 에이전트"를 상품화하면 셋업 비용을 고객에게 전가하지 않고도 다양한 자동화 서비스를 빠르게 조립해 팔 수 있습니다.

## 구현 가능성: 중
- 근거: GitHub 오픈소스(BackTrackCo/tenjin-agent)로 코드 접근은 쉽지만 "alpha, rough edges 예상"이라고 명시되어 있어 안정성이 낮습니다.
- x402(크립토 마이크로페이먼트) 지갑 설정이 필수라 개인 맥북에서 지갑 생성·소액 충전·네트워크(대부분 Base/Coinbase 계열) 이해가 선행되어야 합니다.
- Jev가 2026-09 출시된 신모델이라 관련 문서·커뮤니티 사례가 아직 적어 트러블슈팅 난이도가 높을 수 있습니다.
- Claude Code의 서브에이전트/도구 주입 훅 구조와 호환되는지 실제 레포를 열어봐야 확정 가능합니다(현재는 HN 소개글 수준 정보).

## 필요 도구
- Tenjin-agent (오픈소스, 무료 — GitHub: BackTrackCo/tenjin-agent)
- Claude Code CLI (무료, 이미 사용 중)
- x402 결제용 크립토 지갑 (지갑 생성 자체는 무료, 도구 호출당 소액 유료 — 콜당 약 $0.01~0.02 예상)
- Exa API (Tenjin 경유 시 x402로 종량 과금, 직접 가입 시 별도 유료 플랜)
- Firecrawl (Tenjin 경유 종량 과금, 직접 사용 시 유료 크레딧제)
- Context7 (Tenjin 경유 종량 과금)
- (선택) Jev API/모델 접근 권한 — Tenjin 내부에서 라우팅 판단에 사용, 별도 직접 호출은 불필요할 가능성 높음

## 구현 단계
1. `git clone https://github.com/BackTrackCo/tenjin-agent`로 레포를 받아 README와 설치 스크립트를 확인한다.
2. 맥북에 x402 호환 크립토 지갑(예: Coinbase Wallet 또는 레포가 지정하는 지갑)을 생성하고 테스트용 소액($5~10 상당)을 충전한다.
3. Tenjin이 요구하는 방식으로 Claude Code 훅/설정(예: settings.json 또는 별도 데몬 프로세스)에 Tenjin 라우터를 연결한다.
4. 샌드박스 프로젝트에서 "웹 검색이 필요한 질문", "문서 크롤링이 필요한 질문", "최신 라이브러리 문서 확인이 필요한 질문"을 각각 던져 Tenjin이 실제로 도구를 자동 주입하는지 검증한다.
5. 지갑에서 실제로 소액이 차감되는지, 호출당 비용이 예상 범위인지 로그로 확인한다.
6. 안정성이 확인되면, 반복 리서치·크롤링이 필요한 실제 업무(예: 경쟁사 모니터링, 클라이언트 리포트 작성)에 한정적으로 적용해 본다.
7. 문제없이 동작하면 "도구 자동 장착형 에이전트 패키지"로 정리해, 소규모 자동화 컨설팅/외주 상품의 차별점(설정 없는 즉시 사용)으로 소개 자료에 반영한다.

## 예상 공수
- 총 4~7시간 (지갑 설정 및 크립토 결제 이해에 익숙하지 않다면 +2~3시간 추가)
- 난이도: 중~상 (크립토 지갑/x402 결제 흐름이 진입장벽이며, alpha 소프트웨어 특성상 디버깅 시간이 예측 어려움)

## 리스크/유의점
- alpha 단계 소프트웨어라 업무용(고객 대면) 환경에는 아직 부적합하며, 개인 실험용으로만 우선 검증 권장.
- x402 지갑에 자금을 충전해야 하므로 소액이라도 실제 금전 리스크 존재 — 테스트는 최소 금액으로 시작.
- Jev가 세션 컨텍스트와 프롬프트를 관찰한다는 점에서, 민감한 고객 데이터가 포함된 세션에서는 데이터 프라이버시·마스킹 정책을 반드시 확인 후 사용.
- 도구 호출 빈도가 예상보다 많아질 경우 종량 과금이 누적되어 비용 통제가 어려울 수 있으므로 초기에는 호출 로그·비용 상한을 모니터링할 것.
