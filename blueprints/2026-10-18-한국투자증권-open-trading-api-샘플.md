# 한국투자증권 Open Trading API로 만드는 개인용 AI 주식 자동매매 시스템

## 쉽게 말하면
한국투자증권이 공식으로 제공하는 "증권사와 대화하는 통로(API)"를 내 맥북에 연결해서, 사람이 일일이 HTS를 클릭하지 않아도 프로그램이 대신 시세를 확인하고 주문을 넣게 만드는 것입니다. 마치 은행 창구 직원에게 직접 가는 대신, 공식 전화 상담 라인을 뚫어서 컴퓨터가 알아서 통화하게 만드는 것과 비슷합니다. 공식 지원 통로라서 비공식 크롤링보다 훨씬 안전하고 꾸준합니다.

## 이걸로 할 수 있는 것
1. 매일 장 시작 전, AI가 관심 종목의 시세·뉴스·재무지표를 자동 수집해 요약 리포트를 메일이나 메모 앱으로 받아본다.
2. 특정 조건(예: 이동평균선 돌파, 거래량 급증)을 코드로 정의해두면 모의투자 계좌에서 자동으로 매수·매도 주문이 실행되는지 테스트해본다.
3. 과거 시세 데이터를 받아와 AI(LLM 또는 간단한 통계 모델)에게 "이 패턴이면 어떻게 대응했을지" 분석시켜 매매 전략 아이디어를 검증한다.

## 개요
이 저장소는 한국투자증권이 직접 관리하는 공식 Python API 샘플 코드 모음으로, 시세 조회·주문 실행·잔고 확인 등 증권 거래의 핵심 기능을 코드로 자동화할 수 있게 해줍니다. 비공식 스크래핑이나 우회 방식과 달리 공식 문서와 모의투자 계좌를 함께 제공해 리스크 고지 없이 바로 실계좌 매매로 넘어가는 위험한 구조를 피할 수 있습니다. 개인 트레이더 입장에서는 반복적인 시세 확인·주문 작업을 코드로 넘기고, AI 분석 로직을 그 위에 얹어 "데이터 수집 → 분석 → 주문"의 파이프라인을 직접 설계할 수 있다는 점에서 가치가 큽니다.

## 구현 가능성
**상** — 공식 저장소이고 Python 기반이라 맥북 환경에서 바로 실행 가능하며, 모의투자 계좌 연동을 지원해 실거래 전 안전한 검증 단계가 마련되어 있습니다. 다만 증권사 API 특성상 사용자 등록(공동인증서/API 키 발급), 접근토큰 발급 절차 등 초기 설정이 필요해 "완전 자동" 설치는 아닙니다.

## 필요 도구
- **한국투자증권 Open API 서비스 신청** (무료, 증권 계좌 개설 필요) — KIS Developers 포털에서 API Key/Secret 발급 [공식 문서 확인 필요]
- **모의투자 계좌** (무료, 실계좌 개설 후 모의투자 서비스 신청)
- **Python 3.x** (무료, 맥북에 [추정] pyenv 또는 공식 설치파일로 설치)
- **한국투자증권 open-trading-api 저장소** (무료, GitHub clone)
- **requests, pandas 등 Python 라이브러리** (무료, pip 설치)
- **크론탭(cron) 또는 launchd** — 정기 실행용 스케줄러 (macOS 기본 제공, 무료)
- **(선택) LLM API** — 뉴스·재무 데이터 요약·분석용 (유료, 토큰당 과금) [추정]
- **(선택) 메모/메일 자동 발송 도구** — Apple Mail 스크립트 또는 Slack/Telegram 봇 (무료~일부 유료)

## 구현 단계
1. 한국투자증권 계좌 개설 후 KIS Developers 포털에서 Open API 서비스 신청 및 API Key/Secret 발급 [공식 문서 확인 필요]
2. 모의투자 계좌를 별도로 신청해 실계좌와 분리된 테스트 환경 확보
3. 맥북에 Python 환경 구축 (`python3 -m venv` 등으로 가상환경 생성)
4. GitHub에서 `koreainvestment/open-trading-api` 저장소를 clone (`git clone https://github.com/koreainvestment/open-trading-api.git`)
5. 저장소 내 공식 문서를 읽고 접근토큰 발급, Rate Limit, 에러 처리 가이드 확인
6. 모의투자 계좌 키로 먼저 시세 조회 샘플 코드를 실행해 연동 확인
7. 관심 종목 리스트를 정의하고, 매일 정해진 시간에 시세·뉴스 데이터를 수집하는 스크립트 작성
8. 수집한 데이터를 LLM 또는 간단한 규칙 기반 로직에 넣어 매매 신호(매수/매도/보류)를 생성하는 모듈 추가
9. 신호에 따라 모의투자 계좌에서 주문을 실행하는 로직을 연결하고 최소 수 주~수 개월 백테스트 및 실전 모의 운영
10. macOS의 launchd 또는 cron으로 스크립트를 매일 자동 실행하도록 스케줄링
11. 충분한 모의 기간을 거친 후에만, 소액으로 실계좌 전환을 신중히 검토

## 예상 공수
- API 신청 및 초기 설정: 2~4시간 (난이도: 하)
- 샘플 코드 실행 및 모의투자 연동 테스트: 4~6시간 (난이도: 중)
- 자동 데이터 수집 + AI 분석 로직 결합: 10~20시간 (난이도: 중~상)
- 자동 주문 로직 및 스케줄링 안정화: 10~15시간 (난이도: 상)
- 총합: 약 26~45시간 (전체 난이도: 중~상, 금융 도메인 지식 필요)

## 리스크/유의점
- 실계좌 자동매매는 금전적 손실 위험이 직접적이므로, 충분한 모의투자 기간과 백테스트 없이 실계좌로 전환하지 않아야 합니다.
- API Rate Limit 초과, 토큰 만료, 네트워크 장애 등으로 주문 누락·중복이 발생할 수 있어 예외 처리와 로깅을 철저히 해야 합니다.
- AI(LLM) 기반 매매 신호는 과거 데이터 편향이나 환각(hallucination) 위험이 있으므로 AI 판단만으로 주문을 실행하지 말고 사람의 최종 승인 단계를 두는 것을 권장합니다.
- 공식 API라도 정책 변경, 점검 시간, 인증 방식 변경 가능성이 있으므로 주기적으로 공식 문서를 재확인해야 합니다 [공식 문서 확인 필요].
- 금융 관련 코드이므로 API Key/Secret 등 민감 정보를 저장소나 코드에 하드코딩하지 말고 환경변수·별도 설정 파일로 분리 관리해야 합니다.
