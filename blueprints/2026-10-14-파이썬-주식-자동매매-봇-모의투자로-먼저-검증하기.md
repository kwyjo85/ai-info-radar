# 파이썬 주식 자동매매 봇: 모의투자로 먼저 검증하고 AI 신호까지 얹어보기

## 쉽게 말하면
자동매매 봇은 "미리 정해둔 규칙과 신호에 따라 대신 주문을 눌러주는 로봇 비서"입니다. 실제 돈으로 바로 연습시키면 로봇이 실수했을 때 내 돈이 날아가므로, 가짜 돈(모의투자)으로 충분히 훈련시킨 뒤에야 진짜 계좌에 연결하는 것이 핵심입니다. 여기에 "지금 사야 할 때인지"를 숫자로 판단해주는 간단한 지표 계산(나중엔 AI 모델)을 더하면, 로봇 비서가 조금 더 똑똑한 판단을 내리게 됩니다.

## 이걸로 할 수 있는 것
1. 매일 아침 특정 종목의 주가 데이터를 자동으로 가져와 이동평균선 등 지표로 매수/매도 신호를 계산해본다.
2. 모의투자 계좌에서 신호에 따라 자동 주문이 나가는지, 로직에 버그는 없는지 몇 주간 안전하게 테스트한다.
3. 나중에 단순 지표 대신 머신러닝 모델(예: 과거 패턴 학습)을 붙여 신호 품질을 개선하는 실험을 해본다.

## 개요
이 블루프린트는 파이썬으로 주식 자동매매 봇을 만들 때, (1) 모의투자 API로 먼저 검증하는 안전 절차와 (2) 단순 규칙을 넘어 AI/통계 기반 신호 생성 요소를 최소한으로 결합하는 방법을 다룹니다. 핵심 가치는 "AI가 신호를 만들어도 그 신호가 실제로 맞는지 실전 투입 전에 가짜 돈으로 검증한다"는 리스크 관리 원칙입니다.

## 구현 가능성
**중**
- 모의투자 API 발급·연결 자체는 증권사 가이드를 따르면 비교적 명확하게 구현 가능합니다.
- 다만 키움증권 Open API+는 전통적으로 Windows 환경(32비트, ActiveX/COM 기반)을 요구하는 것으로 널리 알려져 있어, 특정 운영체제에서의 실제 동작 여부는 [공식 문서 확인 필요]입니다.
- 단순 지표 신호는 난이도가 낮지만, 실제 머신러닝 모델을 붙여 유의미한 성능을 내는 것은 난이도가 높고 성과가 보장되지 않습니다.

## 필요 도구
- **증권사 모의투자 API**: 원문에서 언급된 키움증권 Open API+ (무료, 계좌 개설 및 API 신청 필요) — 운영체제 요구사항은 [공식 문서 확인 필요]
- **파이썬**: 자동매매 로직 작성용 (버전은 [공식 문서 확인 필요], 무료)
- **데이터/지표 계산 라이브러리**: pandas, numpy 등 — 일반적으로 데이터 분석에 많이 쓰이는 선택지이며 원문에는 명시되지 않음 [추정], 무료 오픈소스
- **코드 작성 환경**: VS Code 등 코드 에디터 — 일반적으로 많이 쓰이는 선택지이며 원문에는 명시되지 않음 [추정], 무료
- **(향후 확장) 머신러닝 라이브러리**: scikit-learn 등 — 추후 AI 신호 고도화 시 고려할 수 있는 일반적 선택지 [추정], 무료 오픈소스

## 구현 단계
1. 증권사(키움증권) 계좌 개설 후 모의투자 서비스를 신청하고, 모의투자용 API 키를 별도 발급받는다.
2. API 실행 환경 요구사항(운영체제, 비트 수, 설치 프로그램 등)을 증권사 공식 문서에서 직접 확인한다 — [공식 문서 확인 필요].
3. 파이썬 환경을 세팅하고, API 연결 테스트용 최소 코드(계좌 조회, 잔고 확인)를 작성해 정상 연결되는지 확인한다.
4. 과거 주가 데이터를 가져와 이동평균선 교차 등 단순 지표 기반 매수/매도 신호를 계산하는 로직을 작성한다 [추정: 구체적 지표 종류는 원문에 없음].
5. 신호 로직을 모의투자 주문 함수와 연결해 "신호 발생 → 모의 주문 실행" 흐름을 완성한다.
6. 최소 수 주간 모의투자로 운영하며 로직 오류, 중복 주문, 예외 처리 버그를 점검하고 로그를 기록한다.
7. (선택·향후) 단순 지표 대신 간단한 머신러닝 모델을 학습시켜 신호 생성에 활용하고, 역시 모의투자로 성능을 재검증한다.
8. 충분한 검증 기간과 버그 수정을 거친 후에만 실계좌 연결을 최후 단계로 진행한다.

- 파이썬 API 연결 테스트 코드 작성: [추정] 2~4시간, 난이도 중

- 모의투자 운영 및 버그 검증 기간: [추정] 2~4주 (상시 모니터링 아님), 난이도 중
- 머신러닝 신호 실험(선택): [추정] 10~20시간 이상, 난이도 상

## 리스크/유의점
- 키움 Open API+의 실제 동작 환경(OS, 비트 수 등)은 추측하지 말고 반드시 공식 문서로 확인해야 하며, 확인 전에는 특정 환경에서의 구현을 단정하지 않는다.
- 모의투자에서 잘 작동한다고 실전에서도 동일하게 작동한다는 보장은 없으며, 슬리피지·체결 지연 등 실전 변수는 별도로 검증이 필요하다.
- AI/머신러닝 신호를 추가할 경우 과거 데이터에 과적합되어 실전에서 성능이 떨어질 위험이 있으므로, 백테스트 결과만 믿지 말고 모의투자 기간을 충분히 가져야 한다.
- 실계좌 연결은 반드시 최후 단계로 미루고, 소액으로 시작해 점진적으로 신뢰도를 확인하는 것이 안전하다.
