# Rondoflow: Claude Code AI 에이전트를 시각적으로 조율하기

## 쉽게 말하면
여러 명의 AI 비서(에이전트)를 한 번에 부려서 일을 시켜야 할 때, 그동안은 터미널 창을 여러 개 띄워놓고 누가 뭘 하는지 일일이 확인해야 했습니다. Rondoflow는 이걸 마치 오케스트라 지휘자처럼 화면 하나에서 "누가 무슨 작업 중인지, 다음엔 누구를 투입할지"를 그림(플로우 차트)으로 보면서 조율하게 해주는 도구입니다.

## 이걸로 할 수 있는 것
1. 블로그 글 하나를 "리서치 → 초안 작성 → 교정 → SEO 최적화" 4단계로 나눠 각 단계를 별도 Claude Code 에이전트에 맡기고, 진행 상황을 한 화면에서 지켜본다.
2. 여러 클라이언트의 코드 리뷰 요청을 동시에 처리하는 자동화 파이프라인을 만들어, 리뷰 대행 서비스를 1인 운영으로 확장한다.
3. Jev 같은 로컬 AI 모델과 Claude Code 에이전트를 조합해, 데이터 수집·가공·보고서 생성까지 이어지는 "무인 업무 처리 라인"을 시각적으로 설계하고 재사용한다.

## 개요
Rondoflow는 여러 Claude Code 에이전트의 실행 흐름을 노드 기반 그래프(비주얼 워크플로우)로 정의·모니터링하는 오픈소스 도구입니다. 텍스트 스크립트로만 다루던 멀티에이전트 오케스트레이션을 드래그앤드롭 수준으로 낮춰, 비개발자에 가까운 사람도 복잡한 자동화 파이프라인을 구성·재사용할 수 있게 합니다. 이는 "여러 개의 반복 업무를 패키지화해 서비스로 파는" 수익화 전략과 직결됩니다.

## 구현 가능성: 중
- 근거: GitHub 저장소 기반 오픈소스이므로 설치 자체는 어렵지 않으나, HN 포인트 2점·댓글 0개로 초기 단계 프로젝트라 문서화 수준과 안정성이 검증되지 않았습니다. Claude Code CLI와의 연동 방식(로컬 실행 vs API 키 필요 여부)을 직접 확인해야 하는 단계이며, macOS에서의 의존성 설치(Node/Python 등)가 추가로 필요할 가능성이 높습니다.

## 필요 도구
- Rondoflow (GitHub: rondoflow/rondoflow) — 무료, 오픈소스
- Claude Code CLI — 무료 설치, 사용량 기반 API 과금 (Anthropic API 키 필요)
- Node.js 또는 Python 런타임 (Rondoflow 요구사항에 따라 확인 필요) — 무료
- Docker (선택, 격리 실행용) — 무료
- Jev (사용자 보유 로컬 모델) — 이미 보유, 추가 비용 없음

## 구현 단계
1. `git clone https://github.com/rondoflow/rondoflow` 로 저장소를 받고 README에서 정확한 설치 요구사항(런타임 버전, 의존성)을 확인한다.
2. macOS에 필요한 런타임을 설치하고 (`brew install node` 등) Rondoflow를 로컬에서 빌드/실행해본다.
3. Claude Code CLI가 이미 설치되어 있는지 확인하고, Rondoflow가 Claude Code를 어떤 방식으로 호출하는지(CLI 서브프로세스 방식인지, API 방식인지) 코드를 읽어 파악한다.
4. 간단한 2단계 파이프라인(예: "웹 검색 에이전트 → 요약 에이전트")을 Rondoflow 화면에서 구성해 실제로 동작하는지 테스트한다.
5. 테스트가 성공하면, 실제 수익화 대상 업무(예: 블로그 자동 생성, 코드 리뷰 대행) 하나를 골라 3~4단계 파이프라인으로 확장한다.
6. 안정화되면 동일 파이프라인을 여러 고객/주제에 재사용할 수 있도록 설정값(프롬프트, 입력 소스)을 파라미터화한다.

## 예상 공수
- 설치 및 첫 테스트: 2~3시간
- 실제 업무용 파이프라인 1개 구축: 4~8시간
- 난이도: 중 (Claude Code 사용 경험이 있다면 진입장벽은 낮지만, 신생 오픈소스 특성상 문서 부족으로 디버깅 시간이 늘어날 수 있음)

## 리스크/유의점
- 초기 단계 프로젝트(스타 수·논의 적음)라 유지보수가 중단되거나 기능이 급변할 위험이 있음 — 프로덕션 의존 전에 포크/백업 고려.
- 멀티 에이전트를 동시 실행하면 Claude API 비용이 빠르게 누적될 수 있으므로 사용량 상한 설정이 필요함.
- 로컬 실행 도구이므로 macOS 절전/재부팅 시 파이프라인이 중단될 수 있어, 무인 운영을 원한다면 launchd 등 기존에 사용 중인 상시 실행 체계와의 통합이 추가로 필요함.
