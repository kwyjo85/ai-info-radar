# llm-keys-ui 0.1 — API 키 원격 관리 서버 구축

## 개요
`llm-keys-ui`는 Simon Willison의 `llm` CLI 생태계용 플러그인으로, 로컬 웹 서버를 띄워 브라우저(혹은 Tailscale/로컬 네트워크로 연결된 휴대폰)에서 API 키를 붙여넣고 저장할 수 있게 해줍니다. 저장된 키는 이후 `llm keys get <이름>` 명령으로 셸 스크립트나 코딩 에이전트 세션에서 안전하게 불러올 수 있어, 원격 에이전트 세션에 키를 직접 붙여넣는 위험을 없애줍니다. MacBook을 코딩 에이전트(예: Codex Remote, Claude Code) 실행 머신으로 쓰는 사용자에게 특히 유용합니다.

## 구현 가능성 — 상
- `uvx` 한 줄 명령으로 즉시 실행 가능한 성숙한 CLI 플러그인이며, 별도의 빌드나 배포 과정이 필요 없습니다.
- 이미 `llm` 패키지 생태계(Simon Willison 제작, 활발히 유지보수됨)와 통합되어 있어 macOS 환경에서 바로 동작합니다.
- 유일한 변수는 네트워크 접근 범위(로컬만 vs Tailscale 등 원격 접근) 설정이며, 이는 표준적인 macOS 네트워킹 지식으로 해결 가능합니다.

## 필요 도구
- **uv / uvx** — Python 패키지 실행기, 무료 (https://github.com/astral-sh/uv)
- **llm** CLI (Simon Willison) — 무료, 오픈소스
- **llm-keys-ui** 플러그인 — 무료, 오픈소스 (https://github.com/simonw/llm-keys-ui)
- **Tailscale** (선택) — 휴대폰에서 원격 접근하려면 필요, 개인 사용은 무료 플랜으로 충분
- 각 AI 서비스의 **API 키** — Anthropic, OpenAI, OpenRouter 등 사용하는 서비스에 따라 유료(사용량 과금)

## 구현 단계
1. **uv 설치 확인**: 터미널에서 `uv --version` 실행. 없으면 `brew install uv`로 설치.
2. **llm 설치 확인**: `uvx llm --version`으로 llm CLI가 동작하는지 확인 (별도 설치 없이 uvx로 즉시 실행 가능).
3. **llm-keys-ui 서버 실행**: `uvx --with llm-keys-ui llm keys-ui --all` 명령 실행. `--all` 옵션은 로컬 네트워크/Tailscale IP를 포함한 모든 가능한 접속 URL을 출력.
4. **접속 URL 확인**: 터미널 출력에서 `http://localhost:8010` 및 로컬 IP(예: `192.168.x.x:8010`), Tailscale IP(있는 경우) 목록 확인.
5. **브라우저/휴대폰에서 접속**: 같은 Wi-Fi 네트워크 또는 Tailscale로 연결된 상태에서 해당 URL을 휴대폰 브라우저로 열기.
6. **API 키 저장**: 웹 UI에서 Key name(예: `anthropic`, `openai`)과 New value 입력 후 Save 클릭. 기존 값은 화면에 표시되지 않음(보안 설계).
7. **저장된 키 사용법 확인**: 터미널에서 `llm keys get anthropic` 실행해 값이 정상적으로 출력되는지 테스트.
8. **코딩 에이전트 워크플로우에 통합**: Codex Remote나 Claude Code 세션에서 API 키가 필요할 때 `export ANTHROPIC_API_KEY=$(llm keys get anthropic)`처럼 셸 명령으로 주입하도록 프롬프트/스크립트 작성.
9. **서버 상시 실행 여부 결정**: 필요할 때만 실행할지, `launchd`(macOS의 백그라운드 서비스 관리자)로 등록해 상시 실행할지 결정. 상시 실행 시 접근 제어(아래 리스크 참고)를 반드시 함께 설정.
10. **Tailscale 연동(선택)**: 원격 폰에서 접근하려면 MacBook과 폰 모두 같은 Tailscale 네트워크(tailnet)에 가입되어 있어야 하며, `tailscale ip`로 MacBook의 Tailscale IP 확인.

## 예상 공수
- 기본 로컬 사용(1~6단계): **10~20분**, 난이도 하 (터미널 명령 한 줄 실행 수준)
- Tailscale 연동 및 원격 폰 접근까지 포함: **30분~1시간**, 난이도 중 (Tailscale 계정/기기 등록 필요 시 추가 시간)
- launchd로 상시 서비스화: **1~2시간**, 난이도 중 (plist 파일 작성 및 보안 설정 포함)

## 리스크/유의점
- `--all` 옵션으로 로컬 네트워크 전체에 서버가 노출될 수 있으므로, 신뢰할 수 없는 네트워크(카페 Wi-Fi 등)에서는 사용하지 말 것.
- Tailscale 없이 로컬 IP만으로 접근을 허용하면 동일 네트워크상의 다른 기기도 접근 가능 — 반드시 Tailscale ACL이나 방화벽으로 접근을 제한하는 것을 권장.
- 저장된 API 키는 평문 또는 OS 키체인 수준으로 로컬에 저장되므로, MacBook 디스크 암호화(FileVault) 활성화 여부를 확인할 것.
- 서버를 상시 실행형으로 만들 경우 인증(비밀번호/토큰) 없이는 노출 위험이 커지므로, 신뢰된 네트워크 경계(Tailscale) 밖으로는 절대 노출하지 말 것.
- 아직 0.1 초기 버전이므로 프로덕션 크리덴셜(결제 관련 키 등)보다는 실험/개발용 키 관리에 한정해 사용하는 것이 안전.
