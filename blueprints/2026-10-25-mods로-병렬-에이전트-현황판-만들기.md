# mods로 병렬 에이전트 현황판 만들기 — AI 주식 트레이드 리서치 관제판

## 쉽게 말하면
여러 명의 조사원에게 동시에 일을 시켜놓고, 각자 지금 뭘 하는지 한 장씩 카드로 보여주는 "작업 상황판"을 만드는 것입니다. 식당 주방에서 주문 현황 전광판을 보면 어느 요리사가 뭘 만들고 있는지 한눈에 보이는 것과 같습니다. 주식 분석을 여러 AI에게 나눠 맡겨도 "작업 중"만 보며 기다리지 않게 됩니다.

## 이걸로 할 수 있는 것
1. 관심 종목 3개의 뉴스·공시 요약을 에이전트 3개에게 동시에 맡기고, 카드에서 각자 어떤 자료를 읽는 중인지 확인합니다.
2. 장 마감 후 종목별 과거 데이터 분석 작업을 병렬로 돌리면서, 어느 에이전트가 오래 걸리거나 멈췄는지 경과 시간으로 파악합니다.
3. 중요한 판단(리스크 검토)은 상위 모델로, 단순 정리는 가벼운 모델로 고정해 돌리고 카드에서 모델이 의도대로 찍히는지 점검합니다.

## 개요
원문 사례는 Claude Code의 mods 기능에 원하는 화면을 말로 설명해, 에이전트별 카드(상태·맡은 일·모델·경과 시간·방금 한 일)를 보여주는 workers-board mod를 만든 것입니다. 이를 주식 리서치 병렬 작업에 적용하면 분석 진행 상황이 투명해져 대기 시간과 멈춤 파악 부담이 줄어듭니다. 이 현황판은 **분석 작업의 모니터링용**이며, 매매 판단이나 주문 실행을 자동화하는 것이 아닙니다.

## 구현 가능성
**등급: 상 (현황판 자체) / 중 (주식 분석 워크플로 전체)**

- 근거(원문): 코드 없이 설명만으로 mod를 만든 실사용 사례가 있고, opus 2개 + sonnet 1개 병렬 실행, 터미널과 데스크톱 Code 탭 양쪽 동작이 보고되었습니다. 원문 평가의 난이도는 낮은 편(2)입니다.
- 한계: 원문은 현황판 사례만 다루며, **주식 데이터 수집·분석·매매 관련 내용은 원문에 전혀 없습니다.** 주식 활용 부분(데이터 소스, 분석 방식 등)은 전부 작성자의 추론이므로, 블루프린트에서 추정 비중이 큽니다. mods의 정확한 설치·활성화 방법은 원문에 없어 [공식 문서 확인 필요]입니다.

## 필요 도구
- Claude Code (mods 기능 포함) — 원문 도구. 사용 요금제·비용 조건은 [공식 문서 확인 필요]
- MacBook 터미널 또는 데스크톱 앱 Code 탭 — 원문에서 동작 확인
- 주식 데이터 소스 (시세·공시·뉴스 카테고리) — 무료/유료 여부는 소스에 따라 다름 [추정]
- 생성된 mod 코드를 보관할 저장소(버전 관리) — 원문 첫 단계에서 권장

## 구현 단계
1. Claude Code를 MacBook에서 실행하고 mods 기능을 쓸 수 있는 버전인지 확인합니다 [공식 문서 확인 필요].
2. Claude Code에 원하는 화면을 말로 설명합니다. 예: "에이전트별 카드로 상태·맡은 일·모델·경과 시간·방금 한 일을 보여주는 mod를 만들어줘."
3. 생성된 mod(원문 사례의 이름은 workers-board)가 적용되었는지 확인합니다.
4. 주식 리서치용 병렬 서브에이전트 2~3개를 띄웁니다. 예: 종목별 뉴스 요약, 공시 정리, 과거 데이터 점검. 데이터를 가져오는 방식은 [추정]이며 사용자가 직접 정해야 합니다.
5. 카드에 상태·맡은 일·경과 시간·방금 한 일이 실시간으로 갱신되는지 확인합니다.
6. 모델을 고정하려면 프롬프트에 모델명을 명시합니다. 원문에 따르면 미지정 시 sonnet으로 도는 경우가 있으므로, 카드에 찍힌 모델로 반드시 검증합니다.
7. 만들어진 mod 코드를 직접 검토한 뒤 저장소에 보관합니다.
8. 필요하면 주식 작업에 맞게 카드 항목을 조정해 달라고 다시 말로 요청합니다 [추정].

## 예상 공수
- 현황판 mod 제작 및 동작 확인: 약 1~2시간 [추정], 난이도 낮음
- 주식 리서치 병렬 워크플로 구성(데이터 소스 연결 포함): 약 8~20시간 [추정], 난이도 중
- 전체는 원문 근거가 없는 부분이 많아 편차가 큽니다.

## 리스크/유의점
- **추정 비중 과다**: 원문은 현황판 제작만 다루므로 주식 활용 설계는 대부분 추론입니다. 그대로 따르기보다 작은 규모로 검증하세요.
- **투자 손실 위험**: AI 분석 결과는 틀릴 수 있으며, 현황판은 진행 상황을 보여줄 뿐 결과의 정확성을 보장하지 않습니다. 최종 투자 판단과 책임은 본인에게 있습니다. 자동 주문 연결은 권장하지 않습니다.
- **모델 자동 지정 문제**: 모델 미지정 시 sonnet으로 실행될 수 있으므로 명시적으로 고정하고 카드로 확인하세요.
- **코드 검토 필수**: AI가 생성한 mod는 프로그램 자체를 바꾸므로 반드시 코드를 읽고 검토한 뒤 사용하세요.
- **기능 변동 가능성**: mods는 새 기능이어서 동작이나 제공 조건이 바뀔 수 있습니다 [공식 문서 확인 필요].
- **원문 한계**: 복붙 프롬프트 8개는 댓글 신청 방식으로 제공되어 원문에 포함되지 않았습니다.
- **개인정보·민감정보**: 계좌 정보나 개인 식별 정보는 프롬프트와 저장소에 넣지 마세요.
