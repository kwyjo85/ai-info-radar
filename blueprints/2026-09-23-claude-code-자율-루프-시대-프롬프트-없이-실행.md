# Claude Code '자율 루프' 시대: 프롬프트 없이 실행 — 내 맥북에서 돈 버는 자동화로 만들기

## 쉽게 말하면
지금까지 Claude Code는 "이거 해줘"라고 시킬 때마다 한 번씩 움직이는 직원이었다면, '자율 루프'는 "매일 아침 이 일을 알아서 반복해줘"라고 한 번만 말해두면 스스로 일정을 잡고 계속 실행하는 직원으로 바뀌는 것입니다. 사람이 매번 프롬프트를 입력하지 않아도, AI가 스스로 "다음엔 뭘 할지" 판단하고 루프를 돌립니다. 본 레포에 이미 있는 `/loop`, `ScheduleWakeup` 같은 기능이 바로 이 '자율 루프'의 초기 형태입니다.

## 이걸로 할 수 있는 것
1. 매일 아침 코코베이비 관련 뉴스·트렌드를 스스로 수집해 다이제스트로 정리해두는 "정보 레이더"를 한 번 설정만 하면 이후엔 손대지 않아도 계속 돌아가게 만들 수 있습니다.
2. 인스타 대시보드(`kwyjo85.github.io/ig-dashboard`) 데이터를 주기적으로 가져와 이상 징후(팔로워 급감, 참여율 하락)가 보이면 알아서 텔레그램으로 알려주는 감시 루프를 만들 수 있습니다.
3. "Jev로 업무 자동화 잘하는 법"류 콘텐츠를 자동 리서치→초안 작성→검토까지 스스로 반복하게 해서, 블로그·뉴스레터 발행 주기를 사람 개입 없이 유지하며 광고/제휴 수익을 노릴 수 있습니다.

## 개요
'자율 루프'는 Claude Code가 한 번의 지시 이후 스스로 다음 작업을 계획하고 실행 주기를 정해 반복하는 운영 방식입니다. 사람이 매 턴 프롬프트를 작성하는 병목을 없애, 정보 수집·모니터링·콘텐츠 생성처럼 "꾸준함이 곧 가치"인 업무를 무인화할 수 있다는 점에서 자동화 수익화와 직결됩니다. 특히 1인 운영 체제(코코베이비 AI 정보 레이더 같은)에서는 이 기능이 곧 "직원 한 명을 상시 고용한 효과"를 냅니다.

## 구현 가능성: 상
- 이미 이 레포에 `/loop`(동적 페이싱), `CronCreate`/`ScheduleWakeup` 같은 스케줄링 도구가 존재해 별도 인프라 구축 없이 바로 적용 가능.
- 맥북에서 로컬 크론 또는 Claude Code 클라우드 세션으로 24/7 구동 가능 (맥북을 상시 켜두거나 클라우드 세션 활용).
- 이미 유사 구조(다이제스트 브리핑, 텔레그램 알림)를 최근 커밋에서 구현한 이력이 있어 학습 곡선이 낮음.

## 필요 도구
- **Claude Code** (Sonnet 5 / Opus 5, 이미 사용 중, 유료 API 사용량 과금)
- **`/loop` 스킬 또는 `CronCreate`/`ScheduleWakeup`** — Claude Code 내장, 무료(호출 자체는 세션 사용량에 포함)
- **텔레그램 봇 API** — 무료 (알림 발송용, 기존에 연동돼 있음)
- **맥북 `launchd` 또는 `cron`** — 무료, Claude Code CLI를 백그라운드로 상시 기동시킬 때
- **(선택) Claude Agent SDK** — 무료 SDK, 완전 독립 실행형 자율 에이전트로 확장 시
- **(선택) 클라우드 실행 환경(Remote/EnterWorktree)** — 맥북을 꺼도 루프가 돌아야 한다면 필요, 과금 여부는 플랜에 따라 다름

## 구현 단계
1. 현재 코코베이비 AI 정보 레이더에서 반복 수행 중인 작업(예: 뉴스 수집→요약→다이제스트 발행) 중 "매번 프롬프트 없이도 될 것"을 하나 골라 대상으로 확정한다.
2. 해당 작업을 하나의 완결된 스킬/슬래시 커맨드(`/digest-briefing` 등)로 정리해, 사람 개입 없이 끝까지 실행 가능한지 먼저 수동으로 1회 테스트한다.
3. `/loop <interval> /digest-briefing` 형태로 자율 루프를 등록하고, 자가 페이싱이 필요하면 `ScheduleWakeup`으로 다음 실행 간격을 스스로 정하게 둔다.
4. 실행 결과(성공/실패, 새 정보 유무)를 텔레그램으로 요약 알림 보내도록 붙여, 사람은 알림만 확인하면 되게 만든다.
5. 맥북이 꺼져 있어도 루프가 죽지 않도록 `launchd` 상시 기동 스크립트 또는 클라우드 세션 이관을 설정한다.
6. 1~2주 실전 운영하며 루프가 헛돌거나(중복 실행, 무의미한 반복) 과금이 튀는 구간을 로그로 확인하고 간격/조건을 튜닝한다.
7. 안정화되면 동일 구조를 인스타 대시보드 모니터링, 콘텐츠 자동 발행 등 다른 반복 업무로 복제해 "자율 루프 포트폴리오"를 늘린다.

## 예상 공수
- 최초 파일럿(1개 루프 구축·검증): 3~5시간
- 안정화·튜닝(알림, 예외 처리 포함): 추가 2~3시간
- 난이도: 중 (도구는 이미 갖춰져 있으나, "언제까지/어떤 조건으로 멈출지"를 잘 설계하지 않으면 무한 반복·과금 폭주 위험)

## 리스크/유의점
- 자율 루프는 사람이 매번 확인하지 않는 구조라, 잘못된 판단이 반복 실행되며 증폭될 수 있음 — 텔레그램 알림 등 최소한의 감시 장치는 필수.
- API 호출이 반복되므로 토큰/과금이 눈에 띄지 않게 누적될 수 있어 주기적 비용 점검 필요.
- 외부 발행(SNS 포스팅, 이메일 발송 등) 단계는 자율화하더라도 최종 승인 게이트를 사람에게 남겨두는 것이 안전(오탈자·오정보 리스크).
- 맥북 상시 기동은 전력·발열 부담이 있으므로 장기 운영 시 클라우드 세션 이관을 고려.
