# Claude로 매일 아침 주식 시세 카톡 자동 알림 만들기

## 쉽게 말하면
매일 아침 비서가 신문을 미리 읽고 "오늘 삼성전자 주가는 이래서 올랐어요"라고 카톡으로 요약해주는 것과 같습니다. 컴퓨터를 꺼둬도 클로드가 알아서 시세를 확인하고 카카오톡 나와의 채팅방으로 메시지를 보내주는 자동화입니다.

## 이걸로 할 수 있는 것
1. 출근 준비하며 카톡만 확인해도 관심 종목(삼성전자/현대차/하이닉스)의 등락과 이유를 2줄로 파악할 수 있다.
2. 매일 장 시작 전 여러 사이트를 돌아다니며 시세를 검색하는 습관을 없앨 수 있다.
3. 같은 예약 패턴을 응용해 관심 있는 다른 주제(예: GitHub 트렌드, 특정 산업 뉴스)도 매일 아침 카톡으로 요약받을 수 있다.

## 개요
클로드 데스크탑 앱에 카카오 공식 Play MCP 커넥터를 연결하고, 클로드 내장 스케줄링 기능으로 매일 정해진 시간에 관심 종목 시세와 등락 이유를 자동 조회해 카카오톡(나와의 채팅방)으로 전송하는 자동화입니다. 매매 실행이 아닌 정보 알림 용도라 리스크가 낮고, 매일 반복되는 정보 확인 작업을 완전히 없애준다는 점에서 실용 가치가 높습니다.

## 구현 가능성 — 상
근거: 실제 화면 시연이 있어 재현성이 높고, 카카오 공식 MCP 커넥터를 사용하므로 별도 개발 없이 UI 설정만으로 구현 가능하다. 수익/매매 주장이 없는 단순 정보 알림이라 기술적·법적 리스크도 낮다. 인스타 대시보드 평가에서도 실현 가능성 5/5로 평가되었다.

## 필요 도구
- **Claude 데스크탑 앱** (유료 Pro 플랜, 월 $20 — 유료)
- **Play MCP 커넥터** (카카오 공식, 클로드 설정 > 커넥터에서 탐색/추가 — 무료로 추정 [추정])
- **카카오 계정** (카카오톡 로그인, 무료)
- **카카오톡 "나와의 채팅방"** 기능 (무료, 앱 내 기본 기능)
- (선택 확장) **KIS(한국투자증권) API 또는 키움 API** — 더 정밀한 시세/재무 데이터 연동 시 사용 가능, 신청 및 사용은 무료이나 계좌 개설 필요 [공식 문서 확인 필요]

## 구현 단계
1. Mac에 Claude 데스크탑 앱을 설치하고 Pro 유료 플랜($20/월)에 가입한다.
2. 앱 내 설정(Settings) > 커넥터(Connectors) > 탐색(Browse) 탭으로 이동해 "Play MCP"를 검색 후 추가한다.
3. 카카오 계정으로 로그인해 커넥터 인증을 완료하고, "카카오톡 나와의 채팅방" 도구 접근 권한을 승인한다.
4. 새 대화창에서 다음과 같은 프롬프트를 입력한다: "매일 아침 9시에 삼성전자/현대차/하이닉스 주가와 등락 이유를 2줄 이내로 요약해 카카오톡으로 보내줘."
5. 클로드가 자동으로 예약 작업(스케줄)을 생성하는지 확인하고, 예약 목록에서 등록 여부를 재확인한다.
6. 다음날 아침 실제로 카카오톡 메시지가 오는지 테스트하고, 요약 형식(종목/등락률/이유)이 원하는 대로 나오는지 점검 후 프롬프트를 조정한다.
7. (확장) 동일한 패턴을 개인 대시보드 프로젝트에 적용해 매일 신규 항목 요약을 카카오톡으로 받는 알림을 추가로 검토한다.
8. (확장) 관심 있는 다른 주제(예: 특정 기술 트렌드, GitHub 인기 저장소 등)로 프롬프트를 변형해 추가 예약 작업을 만든다.

## 예상 공수
- 초기 설정(앱 설치~커넥터 연결~프롬프트 등록): 약 15~30분
- 테스트 및 형식 조정: 1~2일간 아침마다 5분씩 확인 (총 10~20분)
- 확장 작업(대시보드 연동, 타 주제 추가): 각 항목당 15~30분 추가
- 난이도: **하** (코딩 불필요, UI 설정과 자연어 프롬프트만으로 완료)

## 리스크/유의점
- 시세 정보의 정확성과 실시간성은 Play MCP 커넥터가 참조하는 데이터 소스에 의존하므로, 실제 매매 판단에는 반드시 공식 증권사 앱/API로 재확인이 필요하다 [공식 문서 확인 필요].
- "등락 이유" 요약은 AI가 생성한 해석이므로 사실과 다르거나 과도하게 단순화될 수 있어 참고용으로만 활용해야 한다.
- 본 자동화는 매수·매도 추천이나 실계좌 자동주문이 아니며, 단순 정보 알림 용도로만 사용해야 한다.
- 유료 플랜(월 $20) 비용이 지속 발생하므로, 다른 무료 알림 대안과 비교해 실사용 빈도에 맞게 유지 여부를 판단할 필요가 있다.
- 클로드 내장 스케줄링 기능의 정확한 동작 주기·안정성(예: 서버 장애 시 알림 누락 여부)은 공식 문서 확인이 필요하다 [공식 문서 확인 필요].
