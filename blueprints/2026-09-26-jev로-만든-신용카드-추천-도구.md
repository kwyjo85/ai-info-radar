# Jev로 만든 신용카드 추천 도구

## 쉽게 말하면
여러 신용카드의 적립률·연회비·혜택을 일일이 비교표로 뒤지는 대신, "이번 달 항공권 결제인데 어떤 카드 쓰는 게 이득이야?"라고 물으면 바로 답해주는 개인 비서 같은 도구입니다. 카드사 약관이라는 복잡한 요리 레시피를 Jev가 대신 읽고 소화해서, 사용자에게는 "이 카드로 결제하세요"라는 한 줄 결론만 건네주는 셈입니다.

## 이걸로 할 수 있는 것
1. 매달 카드 명세서를 정리할 때 "이 지출 카테고리에는 어떤 카드가 최적이었나"를 자동으로 리포트로 받아본다.
2. 이 구조를 그대로 재활용해 "신용카드 추천 챗봇"을 만들고, 제휴 링크(어필리에이트)를 붙여 클라이언트나 블로그 방문자에게 제공하는 수익형 서비스로 전환한다.
3. Claude Code로 카드사별 약관 PDF를 자동 파싱·구조화하는 파이프라인을 만들어, 비슷한 "약관 비교" 자동화 도구를 다른 도메인(보험, 통신 요금제 등)에도 컨설팅 상품으로 판매한다.

## 개요
사용자의 지출 패턴과 카드 혜택 데이터를 Jev 같은 LLM에 입력해, 결제 상황별 최적 카드를 추천하는 도구. 카드 비교 사이트를 일일이 확인하는 수고를 없애고, 자동화된 의사결정 결과물(추천 카드 + 근거)을 즉시 제공하는 데 가치가 있음. 개인 사용을 넘어 어필리에이트 수익이나 비슷한 "규칙 기반 추천" 자동화 상품의 참고 사례로 활용 가능.

## 구현 가능성: 상
근거: 원문이 이미 공개된 웹 서비스(points.chengeric.com)이며 핵심 로직은 "카드 혜택 데이터 + 지출 카테고리 매칭"이라는 비교적 단순한 규칙 기반 + LLM 보조 구조. 카드 혜택 데이터만 확보하면 MacBook에서 Python/Node 스크립트와 Claude Code만으로 개인용 프로토타입을 하루 안에 만들 수 있음.

## 필요 도구
- Claude Code CLI — 무료(기존 구독 내 포함), 파이프라인/스크래퍼 코드 생성
- Jev API (Anthropic 계열) — 유료(토큰 과금), 지출 설명 → 카드 추천 근거 생성
- 카드 혜택 데이터 소스 — 국내는 카드고릴라, 뱅크샐러드 등 공개 비교 데이터 또는 직접 정리한 스프레드시트(무료, 단 저작권/이용약관 확인 필요)
- Python(pandas) 또는 Node.js — 무료, 혜택 데이터 정제·매칭 로직
- SQLite 또는 JSON 파일 — 무료, 카드 혜택 테이블 저장
- Google Sheets API — 선택 사항, 혜택 데이터 협업 관리용, 무료 티어 있음
- Vercel/Netlify — 선택 사항, 챗봇을 웹으로 배포 시 무료 티어

## 구현 단계
1. 국내 카드사 3~5곳을 선정해 연회비·카테고리별 적립률·전월실적 조건을 표(CSV/JSON)로 직접 정리하거나 공개 비교 사이트에서 수동 수집한다(자동 크롤링은 약관 위반 소지가 있으니 우선 수동).
2. Claude Code로 이 데이터를 구조화된 스키마(카드명, 카테고리, 적립률, 조건)로 파싱하는 스크립트를 작성한다.
3. 사용자의 지출 내역(예: "이번 달 온라인쇼핑 30만원, 주유 10만원")을 입력받아 카테고리별로 매칭하는 규칙 기반 로직을 먼저 짠다.
4. 단순 매칭으로 애매한 케이스(복합 혜택, 조건 충돌)는 Jev에게 카드 데이터와 지출 내역을 함께 프롬프트로 넘겨 "이유를 포함한 추천"을 받도록 연결한다.
5. 결과를 CLI 또는 간단한 웹 UI(예: Streamlit)로 출력해 개인적으로 매달 사용해본다.
6. 검증되면 어필리에이트 링크를 붙인 공개 웹앱으로 확장하거나, 동일 구조(데이터 정제+LLM 추천)를 다른 카테고리 추천 도구로 재사용해 컨설팅/템플릿 판매를 검토한다.

## 예상 공수
8~12시간, 난이도 중 (카드 혜택 데이터 정리가 가장 시간이 걸리는 부분이며, Claude Code로 파싱/매칭 로직 자체는 2~4시간 내 가능)

## 리스크/유의점
- 카드 혜택 정보는 자주 변경되므로 데이터 최신성 유지 비용이 지속적으로 발생함.
- 타사 비교 사이트 데이터를 크롤링할 경우 이용약관 위반 소지가 있으므로 직접 정리하거나 공식 API/공개 데이터만 사용할 것.
- 어필리에이트 링크를 붙여 공개 서비스로 전환할 경우 금융상품 추천에 대한 광고성/책임 고지 문구(투자 조언 아님 등)를 반드시 포함해야 함.
- Jev 응답이 최신 카드 프로모션을 모를 수 있으므로, 항상 직접 정리한 데이터를 근거로 답하도록 프롬프트에 강제해야 함(모델 자체 지식에 의존 금지).
