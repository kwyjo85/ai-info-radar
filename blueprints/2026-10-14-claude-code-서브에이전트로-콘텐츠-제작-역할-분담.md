# Claude Code 서브에이전트로 주식 트레이딩 리서치 팀 구성하기

## 쉽게 말하면
Claude Code라는 AI 코딩 도구 안에 "역할별 가상 직원"을 여러 명 만들어 놓는 기능입니다. 비유하자면 혼자 운영하던 1인 투자 리서치실에 "종목 스크리닝 담당", "뉴스 분석 담당", "리스크 점검 담당" 같은 가상 애널리스트를 각각 채용해서 업무를 나눠주는 것과 같습니다. 사람을 고용하는 게 아니라 역할이 적힌 텍스트 파일(.md) 하나씩을 만드는 것뿐이라 비용과 수고가 거의 들지 않습니다.

## 이걸로 할 수 있는 것
1. 매일 아침 "오늘 관심종목 리포트 만들어줘" 한마디로 뉴스 스크래핑·재무지표 분석·리스크 체크가 순서대로 자동 실행된다.
2. 관심종목 발굴 담당과 매매 시그널 분석 담당을 분리해서, 한쪽은 종목 후보를 찾고 다른 쪽은 그 종목의 기술적/펀더멘털 신호를 검증하게 한다.
3. 장 마감 후 "분석 담당" 에이전트가 오늘 매매 성과를 숫자로 요약해 복기 노트를 자동 작성하게 한다.

## 개요
Claude Code의 `.claude/agents` 폴더에 역할별 서브에이전트 파일을 만들어, 주식 트레이딩에 필요한 여러 리서치·분석 작업(종목 조사, 뉴스/공시 분석, 매매 시그널 검증, 성과 리뷰 등)을 하나의 대화 명령으로 순차 호출·분담시키는 구조입니다. 핵심 가치는 "매일 반복되는 리서치 루틴"을 역할별로 표준화해 재사용 가능하게 만들고, 최종 매매 결정(아이디어 선택·실행 직전 확인)은 사용자가 직접 통제하는 데 있습니다.

## 구현 가능성: 상
- 근거: `.claude/agents` 폴더 기반 서브에이전트 기능은 원문에서 "Anthropic 공식 기능과 일치(과거에도 교차 확인됨)"로 명시되어 있으며, 폴더 구조·역할 지정 방식이 구체적으로 설명되어 있습니다.
- 다만 "주식 트레이딩"에 특화된 적용은 원문에 없는 응용이므로, 실제 금융 데이터 연동 부분은 [추정] 및 별도 도구 결합이 필요합니다.

## 필요 도구
- **Claude Code** (Anthropic 공식 CLI 도구) — 유료 구독/API 사용량 기반 과금 [공식 문서 확인 필요]
- macOS 터미널 (zsh) — 무료, 기본 내장
- `.claude/agents/*.md` 파일 작성용 텍스트 에디터 (VS Code 등) — 무료
- (선택) 주식 데이터 API: 예) 한국투자증권 Open API, 키움 Open API, Yahoo Finance API 등 — 실제 연동 가능 여부·비용은 [공식 문서 확인 필요], 원문에는 언급 없음
- (선택) 뉴스/공시 스크래핑용 스크립트(Python requests/BeautifulSoup 등) — 무료, 직접 작성 필요

## 구현 단계
1. 터미널에서 프로젝트 폴더(예: `~/stock-ai-team`)를 만들고 그 안에 `.claude/agents/` 하위 폴더를 생성한다.
2. `.claude/agents/조사담당.md` 파일을 만들어 "이름 / 할 일(관심종목·업종 트렌드·주요 뉴스 조사) / 지킬 규칙(출처 명시, 추측 금지 등)"을 문장으로 적는다.
3. 같은 방식으로 `분석담당.md`(재무/기술적 지표 분석), `리스크담당.md`(손절/포지션 크기 점검), `관리담당.md`(전체 작업 순서 조율) 파일을 각각 작성한다.
4. 관리담당 파일에 "사용자가 '오늘 리서치 돌려줘'라고 말하면 조사→분석→리스크 순으로 호출한다"는 워크플로를 명시한다.
5. Claude Code를 실행해 "오늘 관심종목 리서치 돌려줘" 같은 명령으로 전체 파이프라인이 순서대로 작동하는지 테스트한다.
6. 매매 아이디어 선택과 실제 주문 실행 단계는 반드시 사용자가 직접 최종 확인하도록, 관리담당 파일에 "이 두 지점에서는 자동 진행하지 말고 사용자 승인 대기" 규칙을 명시한다.
7. 외부 주식 데이터가 필요하면 별도 Python 스크립트나 API 호출 로직을 작성해 조사담당/분석담당 에이전트가 참고하도록 연결한다 [추정: 구체적 연동 방법은 사용하는 API 공식 문서 확인 필요].

## 예상 공수
- 기본 서브에이전트 4~5개 구성 및 테스트: 약 1~2시간 (원문 기준 "관리 담당 파일 하나 만드는 데 30분") — 난이도: 쉬움
- 실제 주식 데이터 API 연동 및 자동 리포트 포맷 정교화: 추가 4~8시간 [추정] — 난이도: 중간
- 전체 매매 복기/성과 분석 자동화까지 안정화: 수일에 걸친 반복 튜닝 [추정] — 난이도: 중간~상

## 리스크/유의점
- 서브에이전트는 어디까지나 리서치·정보 정리 보조 도구이며, 매매 판단과 실행 승인은 반드시 사람(본인)이 최종 결정해야 한다(원문에서도 "아이디어 고를 때, 올리기 직전"은 직접 한다고 명시).
- 주식 관련 뉴스·데이터를 AI가 요약·분석할 경우 환각(사실과 다른 수치·근거 생성) 가능성이 있으므로, 숫자와 출처는 교차 검증이 필요하다.
- 실시간 시세·자동 주문 연동은 원문에 없는 응용이며, 증권사 API 이용약관·보안·법적 책임 문제를 사전에 반드시 확인해야 한다 [공식 문서 확인 필요].
- 개인 계좌 정보, API 키 등 민감 정보를 에이전트 프롬프트나 로그 파일에 그대로 노출하지 않도록 주의해야 한다.
