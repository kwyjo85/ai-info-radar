# 단일 함수로 여러 LLM을 부르는 타입세이프 래퍼 (Jev 스타일)

## 쉽게 말하면
여러 나라 식자재상에게 주문할 때마다 나라별로 다른 양식을 써야 했다면, 이제 "표준 주문서 한 장"만 채우면 어디든 그대로 보낼 수 있게 만드는 것과 같습니다. Claude든 GPT든 로컬 모델이든, 함수 하나만 호출하면 같은 방식으로 물어보고, 답도 미리 정해둔 틀(타입)에 맞게 검증된 상태로 돌려받습니다.

## 이걸로 할 수 있는 것
1. 클라이언트 자동화 프로젝트마다 매번 새로 짜던 LLM 호출 코드를 표준 함수 하나로 재사용해 착수 시간을 줄인다.
2. Claude Code로 짠 자동화 스크립트에서 모델을 Claude↔GPT↔로컬 모델로 바꿔가며 비용·품질 테스트를 코드 한 줄 수정으로 끝낸다.
3. 응답 JSON이 깨져서 자동화가 멈추는 사고를 줄여, 고객에게 납품하는 파이프라인의 신뢰도와 유지보수성을 높인다.

## 개요
여러 LLM 제공사(Claude, GPT, 로컬 모델 등)를 하나의 타입 안전한 함수 인터페이스로 감싸는 경량 래퍼 패턴. 무거운 프레임워크 없이 함수 하나 + 타입 정의만으로 구조화된 출력을 받아, 반복되는 AI 업무 자동화 개발 비용을 낮추는 데 가치가 있음. 원문에서 이미 파이썬/타입스크립트 예제 코드를 공개하고 있어 그대로 참고 가능.

## 구현 가능성: 상
근거: 원문 블로그에 구현 코드가 공개돼 있어 개인 MacBook에 Python 또는 Node/TS 환경만 있으면 바로 이식 가능하고, 별도 서버 인프라나 배포 과정이 필요 없음. Claude Code로 하루 이내 프로토타입 가능한 규모.

## 필요 도구
- Python 3.11+ 또는 Node.js/TypeScript — 무료
- Anthropic API (Claude) — 유료(토큰 사용량 과금)
- OpenAI API — 선택 사항, 유료
- Pydantic(Python) 또는 Zod(TypeScript) — 응답 구조 검증, 무료
- Ollama — 로컬 모델 테스트용, 무료
- Claude Code CLI — 무료(기존 구독 내 포함)
- Git/GitHub — 버전 관리 및 재사용 라이브러리 배포, 무료

## 구현 단계
1. 원문 블로그(allanrbo.blogspot.com)의 예제 코드를 Claude Code로 가져와 로컬 저장소(`llm-wrapper` 폴더)에 포팅한다.
2. 함수 시그니처를 `call_llm(prompt, response_schema, model="claude")` 형태로 정의하고, Pydantic/Zod로 응답 스키마를 강제한다.
3. Anthropic API와 OpenAI API 두 곳에 대해 동일 인터페이스로 동작하도록 provider 분기 로직을 추가한다(if/else 또는 딕셔너리 매핑).
4. 재시도 로직(JSON 파싱 실패 시 재요청)과 최대 재시도 횟수를 넣어 안정성을 확보한다.
5. 실제 업무 자동화 샘플(예: 이메일 분류, 인스타 데이터 요약)에 이 래퍼를 연결해 동작을 검증한다.
6. 검증되면 별도 pip/npm 패키지 또는 개인 GitHub 저장소로 정리해, 이후 클라이언트 프로젝트에 재사용하거나 유료 템플릿/스타터킷으로 판매 검토한다.

## 예상 공수
4~6시간, 난이도 중하 (Claude Code로 초안 생성 시 2~3시간 내 단축 가능)

## 리스크/유의점
- API 키를 코드에 하드코딩하지 않고 환경변수로 분리해야 함.
- 벤더마다 구조화 출력(JSON mode/tool use) 지원 방식이 달라 완전한 "단일 함수" 추상화가 어려울 수 있음.
- 여러 모델 테스트 시 API 비용이 누적되므로 사용량 한도를 미리 설정할 것.
