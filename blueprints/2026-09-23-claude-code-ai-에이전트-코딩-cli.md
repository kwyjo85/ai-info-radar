# Claude Code로 "AI 자동화 상품" 만들어 팔기 — 나만의 CLI 워크플로우를 수익화하기

## 쉽게 말하면
Claude Code는 터미널에 앉아있는 개발자 비서라고 생각하면 됩니다. 코드를 읽고, 고치고, 커밋까지 알아서 해주는데, 이걸 "혼자 쓰는 도구"에서 "다른 사람도 쓸 수 있게 포장한 상품"으로 바꾸면 돈이 됩니다. 예를 들어 지금 만들고 있는 이 인스타 대시보드 자동화 파이프라인 자체가 이미 하나의 판매 가능한 템플릿입니다.

## 이걸로 할 수 있는 것
1. 지금 이 ig-dashboard 프로젝트의 "정보 수집 → 요약 → 평가 → 대시보드 배포" 파이프라인을 스킬/커스텀 명령 패키지로 정리해 소상공인·1인 마케터에게 유료 템플릿으로 판매.
2. 회사(코코베이비)나 지인 사업체의 반복 업무(재고 정리, 리뷰 응답 초안, 엑셀 리포트 생성)를 Claude Code 서브에이전트·훅으로 자동화해주는 외주/컨설팅 프로젝트를 수주.
3. Claude Code의 새 기능(스킬, 훅, MCP)을 한국어로 정리한 실전 가이드/뉴스레터를 만들어 크리에이터 수익화(콘텐츠 후원, 강의) 채널로 연결.

## 개요
Claude Code 자체는 무료로 설치 가능한 CLI지만, 진짜 가치는 "이걸 특정 업무에 맞게 조립한 워크플로우"에 있습니다. 사용자는 이미 이 도구로 실제 프로젝트(ig-dashboard)를 운영 중이므로, 그 노하우를 재사용 가능한 패키지·서비스로 전환하는 것이 핵심 자동화/수익화 포인트입니다. 설치 장벽이 없고 이미 익숙하므로 실행 리스크가 가장 낮은 항목입니다.

## 구현 가능성
**상** — 근거: 사용자가 이미 매일 사용 중이며 별도 학습 곡선이 없음(대시보드 평가 10/10, 난이도 1). 신규 설치·인증·API 키 발급 같은 진입장벽이 전혀 없고, 결과물(워크플로우 스크립트, 스킬 파일)은 이미 로컬에 존재.

## 필요 도구
- Claude Code CLI — 이미 설치됨, 갱신만 필요 (Pro/Max 구독 또는 API 종량제, 유료)
- GitHub (anthropics/claude-code 릴리스 노트 확인용) — 무료
- `.claude/skills/`, `.claude/agents/`, hooks 설정 — 무료 (Claude Code 내장 기능)
- Notion/Gumroad 또는 크몽/숨고 — 템플릿·컨설팅 판매용 (수수료 있음)
- 노션·블로그·뉴스레터 툴(예: Substack, 브런치) — 콘텐츠화용 (무료~저가)

## 구현 단계
1. `npm i -g @anthropic-ai/claude-code` 또는 `npm update -g @anthropic-ai/claude-code`로 최신 버전 확인.
2. `anthropics/claude-code/releases`에서 최근 3~5개 릴리스의 변경사항(스킬/훅/MCP/서브에이전트) 훑어보고, 이 프로젝트에 바로 적용 가능한 신기능 목록 뽑기.
3. `/context`, `/doctor`로 현재 세션 상태·설정 점검하고 병목(느린 응답, 권한 프롬프트 과다 등) 파악.
4. ig-dashboard 프로젝트의 수집→요약→평가→배포 흐름을 별도 스킬(`.claude/skills/ig-radar/`)로 추출해 다른 프로젝트에도 재사용 가능하게 일반화.
5. 이 스킬 패키지 + 사용 가이드(한국어)를 Gumroad나 노션 템플릿 형태로 정리해 1차 버전 판매 시작.
6. 지인/소상공인 대상으로 "반복 업무 자동화 진단 30분 무료 상담"을 열어 실제 니즈 파악 후 유료 컨설팅으로 전환.
7. 매주 릴리스 노트 요약 + 적용기를 짧은 콘텐츠(뉴스레터/스레드)로 발행해 신뢰도·리드 확보.

## 예상 공수
- 1~4단계(도구 점검, 신기능 반영): 2~3시간, 난이도 하
- 5단계(스킬 패키지화 및 판매 준비): 6~10시간, 난이도 중
- 6단계(컨설팅 영업·실행): 건당 3~5시간, 난이도 중 (영업력에 좌우)
- 7단계(콘텐츠 발행, 주간): 주당 1~2시간, 난이도 하

## 리스크/유의점
- Claude Code 사용량 기반 비용(API 종량제 시)이 컨설팅 마진을 갉아먹을 수 있음 — Pro/Max 정액제 활용 권장.
- 릴리스 노트 기반 "신기능"이 실제로는 베타/실험적 기능일 수 있어, 고객에게 판매하는 템플릿에는 안정화된 기능만 포함할 것.
- 타인의 코드베이스에 자동화를 적용할 때 민감 정보(고객 데이터, 크리덴셜)가 훅/로그에 노출되지 않도록 권한·훅 설정을 반드시 점검.
- "AI가 다 해준다"는 과장된 마케팅은 지양 — 실제로는 설정·검증 과정이 필요함을 명확히 안내해야 신뢰 유지.
