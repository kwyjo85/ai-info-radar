# RQAlpha로 내 주식 전략을 "실전 투입 전"에 검증하기

## 쉽게 말하면
RQAlpha는 비행 시뮬레이터와 비슷합니다. 실제 비행기를 띄우기 전에 시뮬레이터로 수백 번 이착륙을 연습하듯, 내가 생각한 주식 매매 전략을 실제 돈으로 거래하기 전에 과거 주가 데이터로 먼저 "가상 비행"을 시켜보는 도구입니다. "이 전략대로 1년 전부터 매매했다면 얼마를 벌거나 잃었을까?"를 숫자로 미리 확인할 수 있습니다.

## 이걸로 할 수 있는 것
1. "이동평균선이 골든크로스 나면 매수"처럼 내가 생각한 규칙을 코드로 짜서 지난 몇 년치 데이터로 승률과 수익률을 테스트해본다.
2. 여러 전략(단타형 vs 장기보유형)을 같은 과거 구간에 돌려보고 어느 쪽이 더 안정적이었는지 비교한다.
3. 전략이 2020년 코로나 폭락 같은 급락장에서 얼마나 손실이 났는지(MDD, 최대낙폭) 확인해서 실전 투입 전 위험도를 가늠한다.

## 개요
RQAlpha는 매매 전략을 코드로 작성하면 과거 시세 데이터를 가지고 가상으로 매매를 재현해 수익률·승률·낙폭 등 성과 지표를 계산해주는 백테스트 프레임워크입니다. 실제 증권사 계좌와 연동해 자동매매를 하는 도구가 아니라, "이 전략을 믿고 돈을 넣어도 되는가"를 데이터로 검증하는 사전 검증 단계에 집중합니다. 개인이 감(느낌)이 아닌 과거 데이터 기반 근거를 가지고 매매 전략을 다듬을 수 있다는 점에서 가치가 있습니다.

## 구현 단계
1. 맥북에 Python 3.x가 설치되어 있는지 터미널에서 `python3 --version`으로 확인하고, 없으면 공식 홈페이지 또는 Homebrew로 설치한다.
2. 가상환경을 만든다: `python3 -m venv rqalpha-env` 후 `source rqalpha-env/bin/activate`로 격리된 환경에서 작업한다.
3. RQAlpha 공식 GitHub 저장소(README)를 열어 공식 설치 명령과 요구 Python 버전, 지원 운영체제(특히 macOS 호환 여부)를 직접 확인한다 [공식 문서 확인 필요].
4. 안내된 방식(pip 설치 또는 소스 클론 후 설치)대로 RQAlpha를 설치한다.
5. 공식 예제 전략(튜토리얼)을 그대로 한 번 실행해보며 환경이 정상 동작하는지 확인한다.
6. 본인이 관심 있는 한국 주식 종목에 대한 과거 가격 데이터를 어떻게 불러올지 조사한다 — RQAlpha 기본 제공 데이터가 어느 시장(중국/미국 등)을 대상으로 하는지 먼저 확인 후, 한국 주식용 데이터는 별도 API 연동이 필요할 수 있다 [공식 문서 확인 필요].
7. 간단한 전략(예: 특정 이동평균 교차 시 매수/매도) 코드를 작성해 백테스트를 실행한다.
8. 결과로 나온 수익률, 승률, 최대낙폭(MDD) 등 지표를 기록하고 여러 전략 버전과 비교한다.
9. 안정적인 결과를 얻은 전략만 모의투자(실제 돈 없이 거래 연습) 단계로 넘기고, 바로 실계좌에 적용하지 않는다.

- 첫 번째 전략 작성 및 백테스트 반복: 4~10시간 [추정]
- 난이도: **중~상** (Python 기초 지식 필수, 금융 데이터/지표 이해도 요구)

## 리스크/유의점
- RQAlpha는 백테스트 전용 도구이며 실계좌 자동매매 기능을 포함하는지는 원문에 명시되지 않았으므로, 자동매매로 바로 확장 가능하다고 오해해서는 안 된다 [공식 문서 확인 필요].
- 과거 데이터로 좋은 성과가 나왔다고 미래에도 동일하게 작동한다는 보장은 없다(과최적화/오버피팅 위험).
- 한국 주식 시장 데이터 지원 여부가 불확실하므로, 실제 활용 전 데이터 소스 확보 가능성을 먼저 검증해야 한다.
- 백테스트 결과만 믿고 실계좌에 바로 투입하지 말고, 반드시 모의투자 단계를 거쳐야 한다.
- 설치 중 Python 패키지 버전 충돌 등 환경 문제가 발생할 수 있으므로 가상환경 사용을 권장한다.
