# AI Automation Without the Hype — 실전형 비즈니스 AI 에이전트 자동화

## 개요
소개된 콘텐츠는 "실무에 바로 배포 가능한 AI 에이전트 코드 100여 페이지"를 표방하는 유료 전자책(Gumroad/Selar 판매)으로, HN 게시물 자체에는 구체적인 기술 스펙이나 코드가 공개되어 있지 않습니다. 가치가 있다면 "과대광고 없이 실제 업무(이메일 분류, 문서 요약, 고객 응대 등)에 AI 에이전트를 적용하는 실전 패턴"이라는 컨셉이며, 이를 개인 MacBook에서 재현 가능한 범용 자동화 파이프라인으로 구현하는 것이 실질적 목표가 됩니다.

## 구현 가능성 — 하 (근거 포함)
- 원본 자료가 유료 페이월 뒤에 있고, HN 반응이 4포인트/댓글 1개로 검증된 신뢰도가 매우 낮습니다.
- "100+ pages of code"라는 주장만 있을 뿐 어떤 업무를, 어떤 API로, 어떤 아키텍처로 자동화하는지 구체적 기술 스펙이 전혀 없어 그대로 재현이 불가능합니다.
- 다만 "비즈니스 문제에 특화된 실용적 AI 에이전트"라는 **개념** 자체는 범용 패턴(LLM 호출 + 도구 실행 + 스케줄링)으로 개인 환경에서 독립적으로 구현 가능하므로, 원본을 구매하지 않고도 유사한 실전 자동화는 중~상 수준으로 구현 가능합니다. 이 블루프린트는 원본 재현이 아닌 "동일 목적의 자체 구현"을 다룹니다.

## 필요 도구
- **Claude API 또는 OpenAI API** (유료, 사용량 과금) — 에이전트 두뇌
- **Python 3.11+** (무료) — 실행 환경
- **uv 또는 venv** (무료) — 패키지 관리
- **LangChain / LlamaIndex 또는 Anthropic SDK 단독 사용** (무료, 오픈소스) — 툴콜링·오케스트레이션
- **macOS launchd** (무료, OS 내장) — 정기 실행 스케줄러
- **SQLite** (무료, 내장) — 실행 로그/상태 저장
- **Zapier/Make 대체용 자체 스크립트** (무료) — 이메일·캘린더·Slack 연동은 각 서비스 공식 API 사용 (Gmail API 무료 쿼터 있음, Slack API 무료)
- **ngrok 또는 Cloudflare Tunnel** (무료 티어) — 웹훅 수신 필요 시

## 구현 단계
1. **목표 업무 1개 선정**: 범용 "AI 에이전트"가 아니라 구체적 페인포인트 하나(예: 수신 이메일 자동 분류·요약, 고객 문의 초안 작성) 선정. 스코프를 좁혀야 재현 가능성이 높아짐.
2. **개발 환경 구성**: `uv init ai-agent && uv add anthropic python-dotenv` 로 프로젝트 생성, `.env`에 API 키 저장.
3. **최소 에이전트 스크립트 작성**: Anthropic SDK의 tool use 기능으로 "입력 수집 → LLM 판단 → 도구 실행(파일 쓰기/이메일 발송/DB 기록)" 구조의 단일 파일 스크립트 작성. 프레임워크 없이 순수 SDK로 시작해 필요할 때만 LangChain 등 도입.
4. **로컬 데이터 소스 연동**: Gmail API 또는 IMAP으로 이메일 읽기 권한 설정, OAuth 토큰을 macOS Keychain 또는 `.env`에 안전하게 보관.
5. **실행 로직 검증**: 샘플 데이터 10~20건으로 수동 실행 후 결과 정확도 확인, 프롬프트 반복 튜닝.
6. **에러 처리 및 로깅 추가**: 실패 시 재시도 로직, SQLite에 실행 이력 기록(성공/실패/비용).
7. **launchd로 스케줄링**: `~/Library/LaunchAgents/`에 plist 작성하여 5~30분 간격으로 스크립트 자동 실행, `launchctl load`로 등록.
8. **알림 채널 연결**: 결과를 Slack webhook 또는 macOS 알림센터(`osascript -e 'display notification'`)로 전송.
9. **비용/한도 모니터링**: API 호출 횟수와 토큰 비용을 로그로 추적, 월별 상한선 설정.
10. **1~2주 실사용 후 개선**: 오탐/누락 케이스 수집해 프롬프트 및 도구 정의 리팩터링.

## 예상 공수
- 최소 기능(MVP, 단일 업무 자동화): **8~14시간**, 난이도 **중**
- launchd 스케줄링 + 알림 + 로깅까지 포함한 안정화: 추가 **6~10시간**, 난이도 **중**
- 원본 전자책 수준의 "100+페이지, 다중 업무 커버"를 목표로 확장: **40시간 이상**, 난이도 **상** (스코프가 넓어질수록 유지보수 부담 급증)

## 리스크/유의점
- 원본 콘텐츠는 검증되지 않은 유료 마케팅 자료이므로, **구매 전 환불 정책·후기·목차 미리보기 확인** 필요 (HN 반응 자체가 미미해 품질 보증이 없음).
- API 키를 코드/저장소에 하드코딩하지 말 것 — `.env` + `.gitignore` 필수.
- 이메일/캘린더 자동화는 실수 시 비가역적 영향(오발송, 삭제)이 있으므로 초기에는 **드라이런 모드(실제 발송 없이 로그만)**로 충분히 검증 후 실행 전환.
- launchd 상시 구동 시 예상 외 API 호출 급증으로 비용이 누적될 수 있어 호출 빈도·토큰 사용량에 상한을 반드시 설정.
- "노하이프(no hype)"를 표방하는 자료일수록 실제로는 검증 안 된 경우가 많으므로, 이 블루프린트는 원본을 신뢰 기반으로 재현한 것이 아니라 동일 목적의 독자적 구현안임을 유의.
