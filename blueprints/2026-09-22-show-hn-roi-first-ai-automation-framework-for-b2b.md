# B2B용 ROI 중심 AI 자동화 프레임워크 (CRM 자동화 + AI 세일즈 어시스턴트) 개인 구현 블루프린트

## 개요
CRM 데이터와 영업 프로세스를 AI로 연결해 리드 스코어링, 자동 팔로업, 상담 요약·다음 액션 제안까지 자동화하는 개인용 경량 프레임워크를 구축한다. 핵심 가치는 "AI 도입 → 실제 매출/시간 절감으로 이어지는 지표"를 처음부터 설계에 포함시켜, 막연한 AI 실험이 아니라 측정 가능한 ROI(응답 시간 단축, 전환율 개선, 반복 업무 시간 절감)를 즉시 확인할 수 있다는 점이다.

## 구현 가능성 — 중
- 개인 MacBook 환경에서 CRM API(HubSpot/Pipedrive 무료 티어), Claude API, n8n/Make 등을 조합하면 핵심 자동화(리드 스코어링, 이메일 초안, 요약)는 충분히 구현 가능.
- 다만 "B2B 프레임워크"라는 원문 자체가 상세 스펙 없는 랜딩페이지 수준(HN 포인트 1점, 댓글 1개)이라 참고할 구체적 아키텍처가 없어, 직접 설계해야 하는 부분이 많음.
- 실시간 통화 분석, 멀티 CRM 통합, 조직 규모 배포는 개인 환경에서 난이도가 높아짐 → 개인용 미니 버전으로 스코프를 좁혀야 현실적.

## 필요 도구
- **CRM**: HubSpot Free CRM 또는 Pipedrive (무료/저가 티어, API 제공) — 무료~유료
- **워크플로 오케스트레이션**: n8n (셀프호스팅, 무료) 또는 Make.com (유료, 월 $9~) — 선택
- **LLM API**: Anthropic Claude API (Sonnet 5) — 종량제, 요약/스코어링/이메일 초안용
- **이메일 연동**: Gmail API 또는 IMAP/SMTP — 무료
- **데이터 저장**: SQLite 또는 Airtable (리드 스코어/로그 기록) — 무료~저가
- **알림**: Slack Webhook 또는 텔레그램 봇 API — 무료
- **로컬 스케줄러**: launchd (macOS 내장) 또는 cron — 무료
- **선택: 통화/미팅 요약**: Whisper API 또는 로컬 whisper.cpp — 무료(로컬)/종량제(API)

## 구현 단계
1. CRM 선정 및 계정 생성 (HubSpot Free 또는 Pipedrive), API 키 발급 후 로컬에서 리드/딜 데이터 read 테스트.
2. n8n을 로컬 Docker 또는 macOS 네이티브로 설치, CRM 웹훅(신규 리드 생성 시 트리거) 연동 확인.
3. Claude API 연동 워크플로 작성: 신규 리드 유입 시 회사 정보·이메일 본문을 Claude에 전달해 "리드 스코어(1~100) + 우선순위 태그" 반환받아 CRM 커스텀 필드에 기록.
4. 영업 이메일 초안 자동화: 리드 스코어가 임계치 이상이면 Claude가 개인화된 첫 접촉 이메일 초안을 생성, Gmail 초안함에 저장(자동 발송은 1차로 금지, 사람 확인 후 발송).
5. 상담/통화 요약 자동화: Zoom/Google Meet 녹음 파일 또는 텍스트 메모를 whisper.cpp로 텍스트화 → Claude로 "요약 + 다음 액션 3가지" 생성해 CRM 딜 노트에 자동 추가.
6. ROI 대시보드 구축: SQLite에 (자동화 전/후) 응답 시간, 전환율, 처리 건수를 기록하고 Streamlit 또는 Airtable 뷰로 시각화.
7. launchd로 파이프라인을 30분~1시간 주기로 실행하도록 스케줄링, Slack/텔레그램으로 일일 요약 브리핑 발송.
8. 2주간 파일럿 운영 후 스코어링 정확도, 이메일 초안 채택률, 실제 응답 시간 개선폭을 측정해 임계치·프롬프트 튜닝.

## 예상 공수
- 총 20~30시간 (1~2주, 주말 위주 작업 시)
  - CRM/API 연동 및 테스트: 4~6시간
  - n8n 워크플로 구성: 5~7시간
  - Claude 프롬프트 설계 및 튜닝(스코어링/이메일/요약): 5~7시간
  - ROI 대시보드: 3~5시간
  - 파일럿 운영 및 튜닝: 3~5시간
- 난이도: 중 (API 연동과 워크플로 도구 사용 경험이 있으면 무리 없음, 프롬프트 튜닝에 반복 시간 필요)

## 리스크/유의점
- 원문 소스가 자체 홍보성 랜딩페이지이고 신뢰 지표(포인트 1, 댓글 1)가 낮아 검증된 아키텍처가 아님 — 참고용으로만 활용하고 직접 설계 필요.
- CRM 고객 데이터를 외부 LLM API로 전송하므로 개인정보/영업기밀 처리에 유의, 가능하면 익명화 또는 로컬 LLM(whisper.cpp, 로컬 모델) 병행 검토.
- 이메일 자동 발송은 초기에는 반드시 사람 검수 단계를 두어 오발송·부적절한 콘텐츠 리스크 방지.
- ROI 측정을 프로젝트 초반부터 설계하지 않으면 "AI는 썼지만 효과는 불명확"한 흔한 실패 패턴 반복 우려 — 4단계 이전에 베이스라인 지표(현재 응답 시간, 전환율)부터 먼저 기록할 것.
- CRM 무료 티어의 API 호출 제한/필드 커스터마이징 제약을 사전에 확인해야 워크플로 설계 중 재작업을 피할 수 있음.
