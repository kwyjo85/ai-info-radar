# Claude Code 턴 종료 시 "선택지 카드" 플러그인 (What's Next)

## 쉽게 말하면
Claude Code가 작업을 마칠 때마다 긴 설명글 대신 "다음에 뭘 할까요? A) B) C) D)" 같은 카드를 보여주는 확장 기능입니다. 식당에서 웨이터가 장황하게 설명하는 대신 메뉴판을 딱 보여주는 것과 비슷합니다. 선택하는 것은 사람도 AI도 글을 읽고 이해하는 것보다 훨씬 빠릅니다.

## 이걸로 할 수 있는 것
1. 고객사 코드 작업을 대신 해줄 때, 매 턴마다 "다음엔 이 버그 고칠까요 / 테스트 추가할까요 / 배포 준비할까요?" 카드로 빠르게 방향을 정하고 작업 속도를 올려 더 많은 외주 건을 소화합니다.
2. Jev나 다른 LLM 자동화 파이프라인을 만들 때, 같은 "타입드 초이스" 패턴을 적용해 결과를 프로세싱하는 후속 로직(다음 AI 호출, 분기 처리)을 더 빠르고 저렴하게 만듭니다.
3. 이 플러그인을 응용해 "내 업무용 맞춤 선택지 카드" 버전을 만들어 다른 프리랜서/1인 개발자에게 유료 템플릿이나 컨설팅 상품으로 판매합니다.

## 개요
Claude Code가 한 턴을 마칠 때 자유 서술형 프로세 대신 구조화된(typed) 선택지 목록을 제시하도록 바꾸는 플러그인입니다. 사람이 다음 지시를 고민하는 시간을 줄이고, 반복 작업의 처리 속도(및 체감 생산성)를 높여준다는 점에서 "시간당 처리량 증가 = 수익 증가"로 바로 연결되는 실용적 도구입니다.

## 구현 가능성: 상
- 이미 공개된 오픈소스 플러그인(`kvit-plugins`)이 존재하고 GitHub에서 바로 설치 가능합니다.
- Claude Code 플러그인 시스템(마켓플레이스/로컬 설치)이 이미 지원되므로 별도 인프라 구축이 불필요합니다.
- 개인 MacBook에서 설치·테스트·커스터마이징까지 전부 로컬로 완결됩니다.

## 필요 도구
- Claude Code CLI (이미 사용 중, 무료 사용 범위 내)
- `kvitapp/kvit-plugins` 저장소의 `whats-next@kvit` 플러그인 (무료, MIT/오픈소스 라이선스 확인 필요)
- Git (플러그인 클론/설치용, 무료)
- (선택) 자체 커스터마이징 시 Node.js/TypeScript 환경 — 플러그인 구조 분석 및 수정용 (무료)
- (선택) 블로그 원문 정독용 브라우저: `blog.kvit.app/posts/ending-a-turn-with-a-choice`

## 구현 단계
1. `blog.kvit.app`의 "before/after" 글을 먼저 읽고 실제 카드 UX가 자신의 작업 스타일(외주 코딩, Jev 연동 자동화)에 맞는지 판단합니다.
2. GitHub에서 `kvitapp/kvit-plugins` 저장소를 클론하거나, Claude Code 플러그인 마켓플레이스 기능으로 `whats-next@kvit`를 직접 설치합니다.
3. 개인 프로젝트(예: `ai-info-radar` 저장소) 하나에 먼저 적용해 1~2일간 실제 작업에 써보며 선택지 카드가 방해가 되는 구간과 도움이 되는 구간을 기록합니다.
4. 플러그인 소스(hook/skill 정의 부분)를 열어, 자신의 반복 작업 패턴(예: "리뷰/커밋/PR/배포" 4택)에 맞춘 프리셋 선택지 템플릿으로 커스터마이징합니다.
5. 외주·고객 프로젝트에도 확대 적용해 턴당 왕복 시간이 실제로 줄어드는지 체감 비교(정성적)를 합니다.
6. 효과가 확인되면, 커스터마이징한 버전을 정리해 "Claude Code 생산성 셋업" 패키지의 일부로 블로그/뉴스레터/유료 컨설팅 자료에 포함시켜 수익화 콘텐츠로 재활용합니다.

## 예상 공수
- 설치 및 1차 체험: 30분~1시간 (난이도: 하)
- 실사용 테스트 및 워크플로 적용: 1~2일 (난이도: 하)
- 커스텀 프리셋 제작 및 외주 워크플로 통합: 반나절~1일 (난이도: 중, 플러그인 내부 구조 학습 필요)
- 콘텐츠/상품화까지: 추가 반나절 (난이도: 중)

## 리스크/유의점
- 별점 2점, 코멘트 1개로 검증 사례가 매우 적어 실제 안정성·유지보수 여부가 불확실합니다.
- 선택지 카드가 오히려 자유로운 지시를 방해해 복잡한 커스텀 작업에는 비효율적일 수 있으므로, 반복적/정형화된 작업에만 선별 적용하는 것이 안전합니다.
- 서드파티 플러그인이므로 설치 전 소스 코드를 직접 훑어보고, 외부로 데이터를 전송하는 코드가 없는지 확인 후 사용해야 합니다.
- 수익화(콘텐츠·상품)로 연결하려면 단순 사용 후기가 아니라 자신만의 커스터마이징·워크플로 사례가 있어야 차별화됩니다.
