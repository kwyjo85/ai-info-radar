# BoxHaven: 클라우드 VM에서 Claude Code 운영

## 쉽게 말하면
BoxHaven은 내 맥북을 켜두지 않아도 어딘가에 있는 가상의 컴퓨터(클라우드 VM) 안에서 Claude Code가 계속 일하게 만들어주는 도구입니다. 비유하자면 사무실 직원을 집이 아니라 24시간 돌아가는 별도 사무실에 출근시켜 놓고, 나는 스마트폰으로 결과만 확인하는 것과 같습니다.

## 이걸로 할 수 있는 것
1. 저녁에 노트북을 덮고 나가도, 클라우드 VM 위 Claude Code가 밤새 코드 리뷰·버그 수정·블로그 초안 작성 같은 작업을 계속 돌립니다.
2. Jev 파일럿 고객사마다 별도 VM을 하나씩 띄워서, 각 고객의 코드베이스를 격리된 환경에서 자동화 작업(문서 생성, 리팩터링, 테스트 작성)을 병렬로 처리할 수 있습니다.
3. 여러 개의 사이드 프로젝트(예: ai-info-radar 확장 기능들)를 각각 VM에 올려두고, 하나의 맥북에서 동시에 여러 작업을 관리·모니터링합니다.

## 개요
BoxHaven은 Claude Code를 로컬 맥북이 아니라 클라우드 VM(예: AWS/GCP/Hetzner 등) 위에서 실행되도록 프로비저닝하고 관리하는 도구입니다. 로컬 자원과 전원 상태에 종속되지 않고 "AI 노동자"를 상시 가동시킬 수 있다는 점에서, 자동화 작업량을 늘려 수익화(다중 고객 파일럿, 다중 프로젝트 병렬 운영)로 확장하는 데 직접적인 가치가 있습니다.

## 구현 가능성: 중
- 근거: GitHub 저장소가 존재하고 Star/Point가 낮아(신생/저인지도 프로젝트) 문서화 수준과 안정성을 직접 검증해야 함. Claude Code 자체는 이미 사용 중이므로 통합 난이도는 낮지만, VM 프로비저닝·네트워크·보안(SSH 키, 방화벽) 설정에 추가 학습이 필요해 "상"이 아닌 "중"으로 평가.

## 필요 도구
- BoxHaven (GitHub: finbarr/boxhaven) — 무료, 오픈소스 (라이선스 확인 필요)
- 클라우드 VM 계정 — 유료 (예: Hetzner Cloud 시간당 과금, AWS EC2, DigitalOcean Droplet 등)
- Claude Code CLI + Anthropic API 키 또는 Claude 구독 — 유료 (기존 보유)
- SSH 키 페어 / Tailscale 또는 VPN(선택) — 무료~소액
- tmux 또는 유사 세션 관리 도구 — 무료 (VM 내 장시간 세션 유지용)
- (선택) 모니터링용 알림 도구 — 기존 launchd/알림 인프라 재사용 가능

## 구현 단계
1. BoxHaven 저장소를 로컬에 클론하고 README/설치 스크립트를 읽어 지원 클라우드 프로바이더 목록 확인.
2. 테스트용 소규모 VM(가장 저렴한 티어)을 하나 생성해 BoxHaven으로 Claude Code 환경이 정상 부트스트랩되는지 검증.
3. VM 내 SSH 접근, Claude Code 인증(API 키 또는 로그인 세션 유지 방식) 설정.
4. 기존 ai-info-radar 저장소 중 하나를 VM에 clone하고, 동일한 launchd 스타일 작업(정보 수집·채점) 하나를 VM에서 재현해 로컬과 동일하게 동작하는지 비교.
5. 비용/성능 확인 후, Jev 파일럿 고객용으로 VM 템플릿화(스크립트로 VM 생성→환경설정→과제 투입 자동화).
6. 종료/재시작/스냅샷 정책을 정해 불필요한 과금을 막는 자동 종료 크론 설정.

## 예상 공수
- 초기 검증(1~5단계): 4~6시간, 난이도 중
- 파일럿 고객용 템플릿화(6단계): 추가 4~8시간, 난이도 중~상 (VM 자동화 스크립트 작성 포함)

## 리스크/유의점
- 신생 프로젝트라 유지보수 중단 가능성 있음 — 핵심 로직만 참고하고 자체 스크립트로 대체할 여지 남겨둘 것.
- 클라우드 VM 상시 가동 시 비용이 눈에 띄지 않게 누적될 수 있어, 자동 종료/알림 장치 필수.
- 고객 코드가 올라가는 VM이므로 SSH 키 관리, 디스크 암호화, 데이터 격리(고객별 VM 분리) 등 보안 설계를 먼저 확정한 뒤 파일럿에 투입해야 함.
