# 기존 Claude Code 에이전트를 Jev로 자동 마이그레이션하는 스킬 (jevify)

## 쉽게 말하면
지금 Claude Code로 만든 에이전트 안에는 "이 텍스트에서 이름·날짜·금액만 뽑아줘" 같은 정형화된 작업이 곳곳에 숨어 있습니다. 이런 작업은 비싸고 느린 범용 모델 대신, 빠르고 저렴한 전용 모델(Jev)로 바꿔도 결과가 똑같습니다. `jevify`는 코드를 스캔해서 "이 부분은 Jev로 바꿔도 된다"를 자동으로 찾아내고, 원하면 실제로 교체까지 해주는 도구입니다.

## 이걸로 할 수 있는 것
1. 코코베이비 AI 인포 레이더의 "채점" 단계(주제 적합도 판정, 카테고리 분류 등 정형 출력을 쓰는 LLM 호출)를 스캔해서 Jev로 옮길 수 있는 부분을 찾아낸다.
2. 마이그레이션 전, `/jevify` 스캔 결과만으로 "이 프로젝트에 Jev API 키 없이도" 비용 절감 가능 지점 리포트를 클라이언트에게 보여주고 컨설팅 영업 자료로 쓴다.
3. 여러 고객사의 기존 에이전트/파이프라인 저장소에 이 스킬을 돌려 "Jev 전환 진단"을 빠르게 뽑아주는 유료 서비스 상품을 만든다.

## 개요
`jevify`는 Claude Code 스킬(`/jevify` 슬래시 명령)로, 리포지토리를 스캔해 구조화된 데이터를 반환하는 LLM 호출 지점을 식별하고, 이를 TypeSafe/OpenRouter/Vercel 경유 Jev 호출로 자동 변환합니다. 핵심 가치는 (1) 비용·속도 최적화 자동 진단, (2) 실제 코드 변환까지 원스톱 처리, (3) 이 과정을 "AI 자동화 컨설팅" 산출물로 재판매할 수 있다는 점입니다.

## 구현 가능성
**상** — 근거: 이미 공개된 GitHub 리포지토리(Kevin-Zhouu/jevify)와 Claude Code 스킬 형태로 배포되어 있어 설치·실행 장벽이 낮음. 스캔 기능은 Jev 키 없이도 동작해 초기 테스트 비용이 0원. 본인이 이미 Claude Code를 실제 프로젝트(ai-info-radar)에서 운영 중이라 바로 실험 가능.

## 필요 도구
- Claude Code (이미 사용 중, 무료/구독)
- `jevify` 스킬 — GitHub: https://github.com/Kevin-Zhouu/jevify/ (무료, 오픈소스)
- Jev API 키 — TypeSafe 발급 (유료, 실제 변환·호출 테스트 시 필요. 스캔만 할 땐 불필요)
- 테스트용 리포지토리 — ai-info-radar 자체 또는 별도 샘플 에이전트 프로젝트
- (선택) OpenRouter 계정 — Jev를 OpenRouter 경유로 쓸 경우 필요 (사용량 과금)

## 구현 단계
1. `git clone https://github.com/Kevin-Zhouu/jevify/`로 리포지토리를 받아 README의 스킬 설치 방법(보통 `.claude/skills/` 복사 또는 marketplace add)을 확인한다.
2. 스킬을 자신의 Claude Code 환경에 설치하고, ai-info-radar 프로젝트 루트에서 `/jevify --scan`(키 없이) 실행해 어떤 LLM 호출이 Jev 후보로 표시되는지 확인한다.
3. 스캔 리포트를 검토해 실제로 정형 데이터(카테고리, 점수, boolean 등)만 뽑는 호출인지, 자유서술형 텍스트 생성인지 구분하고 잘못 분류된 항목이 있는지 검증한다.
4. TypeSafe에서 Jev API 키를 발급받아(무료 크레딧/저가 티어 확인) 테스트 전용 브랜치에서 `/jevify --apply` 또는 동등 명령으로 실제 변환을 실행한다.
5. 변환 전/후로 동일 입력에 대한 출력 정확도·응답속도·비용을 비교하는 간단한 벤치마크 스크립트를 짜서 채점 로직이 깨지지 않았는지 확인한다.
6. 문제 없으면 ai-info-radar의 채점/분류 관련 호출 중 일부를 실제로 Jev로 전환하고, 절감된 비용·속도 수치를 기록한다.
7. 위 과정을 "Jev 전환 진단 리포트" 템플릿으로 정리해, 다른 고객사 코드베이스에 돌려주는 유료 컨설팅 패키지(진단 1회 + 전환 지원)로 상품화한다.

## 예상 공수
- 설치·스캔 테스트: 1~2시간
- 실제 변환·검증(1개 프로젝트): 3~5시간
- 컨설팅 상품용 리포트 템플릿화: 2~3시간
- 난이도: 중 (도구 자체는 간단하나, 변환 후 출력 품질 검증과 고객사 코드 이해에 시간이 필요)

## 리스크/유의점
- 스캔 도구가 "정형 데이터 반환"을 오탐지해 실제로는 문맥 이해가 중요한 호출을 Jev로 잘못 옮기면 품질 저하 발생 가능 — 반드시 변환 후 A/B 비교 필수.
- Jev는 출시 1주밖에 안 된 신모델이라 안정성·요금 정책이 유동적일 수 있음(모델 자체는 학습 컷오프 이후 정보라 공식 문서로 재확인 필요).
- `jevify`는 TypeSafe 비공식 서드파티 도구이므로 업데이트 중단·보안 이슈 가능성 — 프로덕션 코드에 바로 적용하지 말고 브랜치에서 검증 후 병합.
- 고객사 코드에 이 스킬을 돌릴 경우, 코드가 외부(스킬 실행 환경)로 전송되는지 여부를 확인하고 NDA/보안 정책 위반이 없는지 사전 점검 필요.
