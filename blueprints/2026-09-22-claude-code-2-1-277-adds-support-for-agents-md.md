# Claude Code 2.1.277의 AGENTS.md 지원 도입 블루프린트

## 개요
Claude Code 2.1.277부터 프로젝트 루트의 `AGENTS.md` 파일을 자동 인식해 에이전트 동작 지침(코딩 규칙, 빌드/테스트 명령, 아키텍처 컨벤션 등)으로 활용할 수 있게 되었습니다. 이는 OpenAI Codex, Cursor 등 여러 도구가 공유하는 `AGENTS.md` 표준과 호환되어, 하나의 지침 파일로 여러 AI 코딩 도구를 동시에 운영할 수 있게 해줍니다. 개인 개발 환경에서는 반복 설명하던 프로젝트 컨텍스트를 한 번만 문서화하면 모든 작업에 자동 적용되는 효과가 있습니다.

## 구현 가능성 — 상
Claude Code CLI를 업데이트하고 텍스트 파일 하나를 작성하는 수준의 작업으로, 별도 인프라나 API 연동이 필요 없습니다. macOS에서 `claude` CLI만 설치되어 있으면 즉시 적용 가능합니다.

## 필요 도구
- **Claude Code CLI** (2.1.277 이상) — 무료(Claude 구독/API 사용량 기반 과금)
- **Homebrew 또는 npm** — CLI 설치/업데이트용, 무료
- **텍스트 에디터** (VS Code 등) — 무료
- (선택) **git** — 여러 프로젝트에 걸쳐 `AGENTS.md` 템플릿을 버전 관리하고 재사용하기 위함, 무료

## 구현 단계
1. 터미널에서 `claude --version`으로 현재 버전 확인 후, `npm install -g @anthropic-ai/claude-code@latest` 또는 Homebrew 업데이트 명령으로 2.1.277 이상으로 업그레이드한다.
2. 관리 중인 프로젝트 루트 디렉터리로 이동해 `AGENTS.md` 파일이 이미 있는지 확인한다 (`ls AGENTS.md`).
3. 기존에 `CLAUDE.md`를 쓰고 있었다면 두 파일의 관계를 확인한다 — 현재 버전에서는 `AGENTS.md`가 있으면 이를 읽고, `CLAUDE.md`도 병행 지원되는지 릴리스 노트로 재확인한 뒤 중복 내용을 정리한다.
4. `AGENTS.md`에 다음 항목을 섹션별로 작성한다: 프로젝트 개요, 빌드/실행/테스트 명령어, 코드 스타일 규칙, 디렉터리 구조 설명, 커밋/PR 컨벤션.
5. 여러 도구(Codex, Cursor 등)를 함께 쓰는 경우, 도구별 특수 지침이 필요하면 `AGENTS.md`는 공통 규칙만 담고 `CLAUDE.md`에 Claude Code 전용 세부사항(권한 설정, MCP 서버 등)을 분리해 관리한다.
6. `claude` 실행 후 실제로 프로젝트 컨텍스트를 올바르게 인식하는지 간단한 질문("이 프로젝트 빌드 명령이 뭐야?")으로 검증한다.
7. 자주 사용하는 프로젝트 템플릿이 있다면 `~/dotfiles` 등 개인 설정 저장소에 `AGENTS.md` 템플릿을 보관해 새 프로젝트마다 복사해 쓴다.

## 예상 공수
약 30분~1시간, 난이도 하. CLI 업데이트 5분, `AGENTS.md` 작성 및 검증 20~40분 내외.

## 리스크/유의점
- `AGENTS.md`와 기존 `CLAUDE.md`가 공존할 경우 우선순위/병합 규칙이 버전마다 바뀔 수 있으므로 공식 릴리스 노트를 반드시 확인해야 한다.
- 민감한 내부 정보(인증 정보, 인프라 세부사항)를 `AGENTS.md`에 적으면 다른 AI 도구나 협업자에게도 노출될 수 있으므로 공개 저장소에서는 내용에 주의한다.
- 표준화된 파일이라도 도구마다 파싱 방식이 조금씩 다를 수 있어, 여러 도구를 동시에 쓸 경우 실제 동작을 각각 검증해야 한다.
