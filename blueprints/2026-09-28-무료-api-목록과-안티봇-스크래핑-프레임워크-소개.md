# 무료 API 목록과 안티봇 스크래핑 프레임워크로 AI 주식 트레이딩 데이터 파이프라인 구축하기

## 쉽게 말하면
주식 자동매매 AI를 만들려면 시세·뉴스·공시 데이터가 끊임없이 필요한데, 이걸 유료 데이터 벤더에 맡기면 매달 구독료가 나갑니다. 이 블루프린트는 이미 검증된 오픈소스 목록(free-for-dev, public-apis)에서 무료 데이터 소스를 골라내고, 막힌 페이지는 Scrapling으로 직접 긁어와서 "무료 데이터 파이프라인"을 나만의 트레이딩 봇에 연결하는 방법입니다. 마치 유료 정보지 대신 도서관·공공 게시판·공개 자료실을 직접 뒤져서 투자 정보를 모으는 것과 비슷합니다.

## 이걸로 할 수 있는 것
1. public-apis 목록에서 무료 시세/금융 API를 찾아 내 MacBook에서 돌아가는 주가 모니터링 스크립트에 연결한다.
2. free-for-dev에서 무료 클라우드/DB 티어를 찾아 트레이딩 봇의 데이터 저장소나 24시간 실행 서버를 비용 없이 구성한다.
3. Scrapling으로 API가 없는 종목 뉴스·공시·커뮤니티 심리 데이터를 긁어와 AI 매매 신호에 반영한다.

## 개요
이 항목은 "데이터 수집"이라는 트레이딩 봇의 첫 단계를 자동화합니다. free-for-dev·public-apis에서 검증된 무료 소스를 선별하고, Scrapling으로 API가 없는 사이트까지 커버하면, 유료 데이터 구독 없이도 AI 매매 판단에 필요한 시세·뉴스·심리 데이터를 지속적으로 확보할 수 있습니다. 개인 투자자 입장에서는 데이터 비용을 줄이면서 신호의 다양성을 높이는 것이 핵심 가치입니다.

## 구현 가능성 — 중
- 오픈소스 3개(free-for-dev, public-apis, Scrapling)는 실제 존재하며 설치 방법도 원문에 구체적으로 명시되어 있어 기술적 진입장벽은 낮음.
- 다만 "주식 트레이딩용 무료 API가 public-apis에 있는지, 어떤 항목인지"는 원문에 명시되지 않아 [추정]이며, 실제 사용 가능한 금융 데이터 API인지·요율 제한이 트레이딩에 충분한지는 직접 확인이 필요함.
- Scrapling으로 금융 사이트를 긁는 것은 이용약관 위반 소지가 있어 "권한 있는 페이지만" 사용하라는 원문 경고를 그대로 지켜야 함.

## 필요 도구
- **free-for-dev** (ripienaar, 오픈소스/무료) — 무료 티어 클라우드·DB·호스팅 목록
- **public-apis** (MIT 라이선스, 무료) — 무료 공개 API 목록 (금융 카테고리 포함 여부는 [공식 문서 확인 필요])
- **Scrapling** (D4Vinci, BSD-3-Clause, 무료) — `pip install scrapling` + `scrapling install`
- **Python 3.10+** [추정] (Scrapling 요구사항, 정확한 버전은 [공식 문서 확인 필요])
- **Claude Code** (원문에서 언급된 플러그인 활용 도구, 유료 구독 필요할 수 있음)
- (선택) 무료 금융 데이터 API 예: Alpha Vantage, Yahoo Finance 비공식 라이브러리 등 — public-apis 확인 후 채택 [추정]
- 자동 실행용 **cron** 또는 **launchd** (macOS 기본 제공, 무료)

## 구현 단계
1. GitHub에서 `ripienaar/free-for-dev`, `public-apis/public-apis`, `D4Vinci/Scrapling` 저장소를 방문해 별 개수·업데이트 일자를 확인한다.
2. public-apis 목록에서 Finance/Business 카테고리를 검색해 인증 방식(API 키 필요 여부)과 CORS 지원 여부를 표에서 확인하고, 매매 신호에 쓸 만한 무료 시세/뉴스 API 2~3개를 선정한다.
3. 선정한 API가 죽은 엔드포인트인지 `curl` 또는 Postman으로 직접 호출해 응답을 확인한다.
4. free-for-dev에서 무료 DB(예: 시계열 데이터 저장)와 무료 서버리스/호스팅 티어를 찾아 트레이딩 봇을 상시 구동할 환경을 구성한다.
5. 터미널에서 `pip install scrapling` 실행 후 `scrapling install`로 브라우저 의존성까지 설치한다.
6. Scrapling으로 API가 없는 종목 뉴스/공시 페이지(자신이 접근 권한이 있는 공개 페이지)를 대상으로 스크래핑 스크립트를 작성한다.
7. CORS가 No로 표시된 API는 브라우저(프론트엔드)가 아닌 Python 서버 사이드 스크립트에서 호출하도록 설계한다.
8. 수집된 시세·뉴스·스크래핑 데이터를 하나의 CSV/DB로 통합해 AI 모델(예: Claude API 또는 로컬 LLM)에 프롬프트로 넣어 매매 신호를 생성하도록 파이프라인을 연결한다.
9. cron/launchd로 위 파이프라인을 일 1~여러 회 자동 실행하도록 스케줄링한다.

## 예상 공수
- 저장소 확인 및 API 선정: 1~2시간 (난이도 하)
- Scrapling 설치 및 테스트 스크래핑: 2~4시간 (난이도 중, 안티봇 대응 세부 설정 필요 시 증가)
- 데이터 통합 및 AI 신호 연결: 4~8시간 (난이도 중~상, AI 프롬프트 설계와 백테스트 포함 시 늘어남)
- 전체 파이프라인 자동화(cron 연동): 1~2시간 (난이도 하)
- **총 예상: 8~16시간, 난이도 중**

## 리스크/유의점
- free-for-dev의 "무료"는 무료 티어가 있다는 뜻이지 완전 무료를 보장하지 않으므로, 트레이딩 봇을 상시 실행할 경우 사용량 초과로 과금될 수 있어 요금제를 정기 점검해야 한다.
- public-apis의 엔드포인트는 죽어 있을 수 있어 사용 전 반드시 직접 호출 테스트가 필요하며, 실거래 신호에 사용하기 전 데이터 신뢰성 검증이 필수다.
- Scrapling은 안티봇 우회 도구이므로 이용약관을 위반하는 사이트(예: 증권사 유료 데이터, 로그인 필요 페이지)에 사용하면 법적·계정 정지 리스크가 있다 — 본인이 접근 권한을 가진 공개 페이지에만 한정해야 한다.
- 무료 데이터만으로 만든 AI 매매 신호는 지연·누락 가능성이 있어, 실거래 적용 전 반드시 페이퍼 트레이딩(모의투자)으로 충분히 검증해야 한다.
- 원문은 이 3개 도구를 "주식 트레이딩용"으로 소개한 것이 아니라 일반 개발자 도구로 소개한 것이므로, 금융 도메인 적용 부분은 전적으로 [추정]이며 실제 활용 전 각 API의 금융 데이터 제공 여부를 공식 문서에서 재확인해야 한다.
