# Claude+Cursor+한국투자증권 API로 실계좌 자동매매 시스템 구축

## 쉽게 말하면
AI에게 "이럴 때 사고, 저럴 때 팔아라"는 규칙을 미리 정해주고, 과거 6년치 주식 데이터로 그 규칙이 실제로 통했는지 시험해본 뒤, 통과한 규칙만 증권사 API를 통해 소액으로 실제 계좌에서 자동 실행시키는 방식입니다. 마치 자율주행 전에 시뮬레이터에서 수천 번 연습시킨 뒤 실제 도로에 내보내는 것과 비슷합니다.

## 이걸로 할 수 있는 것
1. 퇴근 후 틈틈이 만든 매수·매도 전략을 매번 차트를 들여다보지 않고도 자동으로 실행되게 할 수 있다.
2. 과거 시세 데이터로 전략을 먼저 검증한 뒤에만 실제 돈을 투입해 감정적 매매(고점 추격매수 등)를 줄일 수 있다.
3. 실제 매매가 체결될 때마다 텔레그램으로 실시간 알림을 받아 외출 중에도 상황을 파악할 수 있다.

## 개요
Claude와 Cursor로 전략 코드를 작성·백테스트하고, 한국투자증권 오픈API로 실제 주문을 실행하며, 텔레그램으로 매매 알림을 받는 개인용 소액 자동매매 파이프라인을 구축하는 것입니다. 핵심 가치는 "AI 활용 주식 트레이드"에서 감정 개입 없이 사전 검증된 규칙만 기계적으로 실행되도록 만들어, 변동성 장세에서의 충동적 판단(고점 매수·패닉 매도)을 줄이는 데 있습니다.

## 구현 가능성: 중
- 근거: 한국투자증권이 공식 오픈API(GitHub 공개)를 제공하고 모의투자 계좌를 지원하므로 개인이 연동 자체는 가능합니다. 다만 실계좌 자동매매는 전략 로직 설계·백테스트 신뢰도(과최적화 방지)·리스크 관리(스탑로스) 구현에 상당한 반복 검증이 필요하고, 증권사 API 사용 약관(개인 목적 한정, 시세 재배포 금지)을 준수해야 하므로 완전 자동화까지는 시간이 걸립니다.

## 필요 도구
- **Claude** (전략 로직 설계·코드 생성 보조) — 유료(API 사용량 과금) 또는 Claude.ai 구독[추정]
- **Cursor** (AI 코드 에디터, 백테스트/자동매매 코드 작성) — 무료 티어 있음, 고급 기능은 유료
- **한국투자증권 오픈API** (github.com/koreainvestment/open-trading-api) — 무료(계좌 개설 및 API 신청 필요), 모의투자 계좌 지원
- **텔레그램 봇 API** — 무료
- **Python** (pandas, requests 등 백테스트/API 연동용 라이브러리) — 무료
- **과거 시세 데이터** (한투 API 또는 별도 데이터 소스) — 무료~일부 유료[추정]

## 구현 단계
1. 한국투자증권 계좌 개설 후 오픈API 앱 등록(App Key/Secret 발급) 및 모의투자 계좌부터 연동한다.
2. GitHub(koreainvestment/open-trading-api)의 예제 코드를 참고해 Cursor에서 API 인증·시세 조회·주문 실행 기본 코드를 작성한다.
3. Claude에게 2020~2026.6 기간의 과거 시세 데이터를 기반으로 매수/매도 조건(예: 이동평균선 교차, 손절 기준 등)을 설계하도록 프롬프트를 작성하고, 아웃오브샘플 구간(전략을 만들 때 쓰지 않은 별도 기간)을 반드시 확보해 검증한다.
4. 백테스트 결과를 바탕으로 스탑로스(예: -5% 자동 손절) 로직을 코드에 필수로 포함시킨다.
5. 텔레그램 봇을 생성해 API 토큰을 발급받고, 주문 체결/오류 발생 시 실시간 알림이 전송되도록 코드를 연동한다.
6. 모의투자 계좌에서 최소 1~2개월 이상 전략을 실행하며 안정성을 관찰한다.
7. 모의투자 결과가 안정적일 때만 소액(예: 50만원 이내)으로 실계좌 전환한다.
8. 한국투자증권 API 이용약관(개인 목적 사용 한정, 시세 재배포 금지)을 재확인하고 준수한다.

## 예상 공수
- API 연동 및 기본 코드 작성: 8~15시간[추정]
- 전략 설계 및 백테스트 반복 검증: 15~30시간[추정] (전략 복잡도에 따라 증가)
- 텔레그램 알림 연동: 2~4시간[추정]
- 모의투자 운영 및 관찰: 실작업 시간 외 1~2개월 대기
- 난이도: 중~상 (프로그래밍 기초 지식과 금융 데이터 해석 능력 필요)

## 리스크/유의점
- 실계좌 자동매매는 실제 금전 손실로 직결되므로 모의투자 없이 바로 적용해서는 안 된다.
- 백테스트 성과가 좋아도 미래 시장에서 동일하게 재현된다는 보장은 없다(과최적화 위험).
- 증권사 API 약관상 개인 목적 사용만 허용되며 시세 재배포는 금지되어 있어, 상업적 활용이나 데이터 공유 시 약관 위반 소지가 있다.
- API 인증키, 계좌 정보 등 민감 정보는 코드에 하드코딩하지 말고 환경변수 등으로 분리 관리해야 한다.
- 자동매매 중 시스템 오류나 네트워크 장애 발생 시 의도치 않은 매매가 실행될 수 있으므로 예외 처리와 모니터링(텔레그램 알림)이 필수다.
