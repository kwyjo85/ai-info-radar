# Claude Code 11개 명령어와 3개 에이전트 실전 워크플로우

## 쉽게 말하면
Claude Code는 원하는 대로 "단축키 명령어"(슬래시 커맨드)와 "전담 조수"(서브에이전트)를 직접 만들어 쓸 수 있는 도구입니다. 예를 들어 매번 "이 코드 리뷰해줘, 이 형식으로, 이 기준으로"라고 길게 설명하는 대신 `/review-pr`이라는 단어 하나만 치면 되고, "리서치 담당", "코드 검토 담당" 처럼 역할이 나뉜 조수들이 각자 맡은 일을 하는 셈입니다. 이 게시물은 그런 명령어 11개와 에이전트 3개를 실제 업무에 배치해 쓴 사례입니다.

## 이걸로 할 수 있는 것
1. 지금 이 저장소(ai-info-radar)의 "HN 기사 수집 → 블루프린트 생성 → 커밋"을 슬래시 커맨드 `/radar-cycle` 하나로 묶어 매일 반복 실행하기
2. Jev 관련 블루프린트 초안 작성, 사실 검증, 포맷 정리를 각각 담당하는 에이전트 3개(작성/검증/편집)로 나눠 품질을 자동으로 교차 점검하기
3. 클라이언트에게 납품할 "AI 자동화 컨설팅 패키지"에 커스텀 명령어·에이전트 세트를 포함시켜, 반복 설치형 상품으로 판매하기

## 개요
Claude Code의 커스텀 슬래시 커맨드(`.claude/commands/`)와 서브에이전트(`.claude/agents/`)를 조합해, 여러 단계로 이뤄진 반복 업무를 명령어 한 줄로 실행되는 파이프라인으로 만드는 자동화입니다. 프롬프트를 매번 새로 쓰는 비용을 없애고, 역할 분리를 통해 결과물 일관성과 품질을 높여, 개인 업무 효율화뿐 아니라 동일한 구조를 컨설팅 상품으로 재판매할 수 있다는 데 가치가 있습니다.

## 구현 가능성: 상
슬래시 커맨드와 서브에이전트는 Claude Code에 이미 내장된 정식 기능이며, 별도 설치나 외부 API 연동 없이 로컬 설정 파일(`.claude/commands/*.md`, `.claude/agents/*.md`) 작성만으로 즉시 동작합니다. 현재 저장소에도 이미 `run`, `init` 같은 프로젝트 스킬과 반복 블루프린트 생성 워크플로우가 존재해, 기존 구조에 명령어·에이전트를 추가하는 형태로 오늘 바로 확장 가능합니다.

## 필요 도구
- Claude Code CLI (이미 사용 중, Pro/Max 구독 내 포함, 추가 비용 없음)
- 텍스트 에디터 (`.claude/commands/`, `.claude/agents/` 파일 작성용, 무료)
- 기존 저장소의 blueprint 생성 스크립트/프롬프트 (이미 보유, 추가 비용 없음)
- (선택) `anthropics/claude-code` 공식 문서의 Slash Commands / Subagents 섹션 — 문법 참고용, 무료

## 구현 단계
1. 현재 반복하고 있는 "정보 항목 → 블루프린트 마크다운 생성" 프롬프트를 슬래시 커맨드로 분리한다: `.claude/commands/blueprint.md`에 이 프롬프트 전문을 저장하고 `$ARGUMENTS`로 정보 항목을 주입받게 만든다.
2. 역할별 서브에이전트 3개를 설계한다 — 예) `researcher`(기사 원문·배경 조사), `writer`(블루프린트 초안 작성), `reviewer`(과장·오류 검증 및 톤 통일).
3. `.claude/agents/researcher.md`, `writer.md`, `reviewer.md`를 작성하고 각각의 tools 권한과 역할 프롬프트를 명시한다 (writer는 이 대화의 구성 순서를, reviewer는 "리스크/유의점" 섹션 검증에 집중하도록 지시).
4. 파이프라인 명령어 `/radar-cycle`을 만들어 "정보 항목 목록 읽기 → researcher 호출 → writer로 블루프린트 생성 → reviewer로 검토 → blueprints/ 폴더에 파일 저장" 순서를 자동화한다.
5. 기존에 쌓인 blueprints/ 파일 5~10개를 대상으로 새 파이프라인을 시험 실행해, 기존 방식과 품질·형식 차이를 비교한다.
6. 차이가 발견되면 reviewer 에이전트 프롬프트에 "나쁜 예/좋은 예"를 추가해 형식 이탈을 보정한다.
7. (수익화 관점) 안정화된 명령어+에이전트 세트를 "AI 리서치 자동화 패키지"로 문서화해, 유사 업무(뉴스 큐레이션, 리포트 생성)를 하는 클라이언트에게 셋업 대행 상품으로 제안한다.

## 예상 공수
- 슬래시 커맨드 1개 분리·작성: 1~2시간 (난이도 하)
- 에이전트 3개 설계 및 프롬프트 작성: 3~4시간 (난이도 중, 역할 경계 설계가 관건)
- 파이프라인 명령어 연결 및 시험 실행: 2~3시간 (난이도 중)
- 기존 산출물 대비 품질 보정 사이클: 반나절~1일 (난이도 중)
- 총 초기 투입: 1~2일, 이후 유지보수는 프롬프트 미세조정 수준

## 리스크/유의점
- 원문 게시물이 좋아요 1개, 댓글 0개로 실제 워크플로우 내용이 거의 공개되지 않았으므로, 위 구현안은 "커스텀 명령어+서브에이전트"라는 Claude Code 공식 기능을 일반화한 것이며 원문의 구체적 11개 명령어 목록을 그대로 재현한 것은 아니다.
- 에이전트를 지나치게 잘게 쪼개면(3개 이상) 에이전트 간 컨텍스트 전달 손실과 실행 시간 증가가 발생할 수 있으므로, 처음엔 2개(작성/검증)로 시작해 필요할 때만 늘리는 것이 안전하다.
- 자동 커밋·파일 생성 단계를 포함시킬 경우, 사람 검토 없이 blueprints/에 잘못된 내용이 대량으로 쌓일 위험이 있으므로 최소 초기 몇 주간은 커밋 전 수동 확인 단계를 유지한다.
