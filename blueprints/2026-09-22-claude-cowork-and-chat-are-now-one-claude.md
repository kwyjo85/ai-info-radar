# Claude Cowork·Chat 통합 활용 블루프린트

## 개요
Anthropic이 Claude Cowork와 일반 Claude 채팅을 하나의 "Claude"로 통합하면서, 짧은 질문부터 장시간 백그라운드 작업(보고서 작성 등)까지 노트북을 닫아도 이어서 처리하는 단일 에이전트 인터페이스가 됨. 개인 MacBook 환경에서는 이를 "정보 수집→가공→보고" 같은 비동기 장기 작업을 웹/모바일에서 위임하고 로컬 Claude Code와 역할을 분담하는 방식으로 활용 가능.

## 구현 가능성 — 중
- 이 항목 자체는 Anthropic 제품(Claude 웹/데스크톱/모바일 앱)의 UX 변경 소식으로, Pro/Max 플랜 사용자에게 순차 롤아웃 중이며 별도 개발 없이 즉시 사용 가능하다는 점에서는 "상"에 가까움.
- 다만 "구현"이라는 관점에서 볼 때 로컬 자동화 파이프라인에 편입시키려면 (1) 아직 API/CLI로 노출되지 않은 Cowork 통합 기능의 실제 경계가 불명확하고, (2) 현재 이 저장소(ai-info-radar)의 SQLite 수집 파이프라인과 연동할 공식 API가 없어 "중"으로 평가.

## 필요 도구
- **Claude 앱 (web/desktop/mobile)** — Pro($20/월) 또는 Max($100~200/월) 플랜 필요 (유료)
- **Claude Code CLI** — 로컬 개발/코드 작업용, Pro/Max 플랜에 포함 또는 API 키 과금 (유료, 이미 보유)
- **claude.ai 계정 알림 설정** — 백그라운드 작업 완료 시 모바일 푸시 확인용 (무료, 계정 설정)
- (선택) **Anthropic API** — 추후 Cowork 유사 기능이 API로 열릴 경우 자동화 연동 대비 (사용량 기반 유료)

## 구현 단계
1. Claude 계정이 Pro 또는 Max 플랜인지 확인하고, 웹(claude.ai)·데스크톱 앱·모바일 앱을 최신 버전으로 업데이트하여 통합된 "Claude" UI가 노출되는지 확인한다.
2. 통합 UI에서 짧은 채팅 질의와 장시간 작업(예: 리서치 보고서, 다중 파일 분석)을 같은 대화창에서 실행해보고, 백그라운드로 전환되는 조건(작업 규모, 예상 소요 시간)을 직접 테스트하며 기록한다.
3. 본 프로젝트(ai-info-radar)의 SQLite 수집 결과를 요약/가공하는 작업 중 시간이 오래 걸리는 것(예: 주간 트렌드 리포트 생성)을 골라 Claude 앱에 위임하고, 노트북을 닫은 뒤 모바일에서 완료 알림을 받는 흐름을 검증한다.
4. Claude Code(로컬 CLI)는 파이프라인 코드 수정·디버깅 등 즉각적 상호작용이 필요한 작업에, 통합 Claude 앱은 비동기 리서치/문서 작성 작업에 쓰도록 역할을 문서화(예: `pipeline/README.md`에 워크플로 분담 메모 추가).
5. Cowork 관련 기능이 API/CLI로 확장되는지 Anthropic 공식 블로그(claude.com/blog)를 주기적으로 모니터링하여, 향후 ai-info-radar 파이프라인에 자동 위임 단계를 추가할지 재검토한다.

## 예상 공수
- 초기 탐색 및 UI 테스트: 1~2시간 (난이도: 하)
- 워크플로 분담 문서화 및 실제 프로젝트 작업 위임 1회 테스트: 2~3시간 (난이도: 중)
- 향후 API 연동 검토는 기능 공개 전까지 대기 상태 (0시간, 모니터링만)

## 리스크/유의점
- 롤아웃이 "Pro/Max 플랜, 수 주에 걸쳐 순차 적용"이므로 현재 계정에 기능이 보이지 않을 수 있음 — 원문 작성자(Simon Willison)조차 "기능·표면의 실제 경계를 파악하는 데 상당한 작업이 필요할 것"이라고 언급한 만큼 문서화 이전에 직접 검증 필수.
- Cowork/채팅 통합은 Anthropic 측 UX 변경이며 안정적인 공개 API 계약이 아니므로, 이를 전제로 한 자동화 스크립트를 만들면 UI 변경 시 깨질 위험이 있음.
- 민감한 프로젝트 데이터(수집된 SQLite 콘텐츠)를 백그라운드 위임 작업에 올릴 경우 클라우드 처리 범위와 데이터 보존 정책을 사전 확인할 것.
