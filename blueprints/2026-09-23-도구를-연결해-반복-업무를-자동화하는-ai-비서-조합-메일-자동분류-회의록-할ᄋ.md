# 도구를 연결해 반복 업무를 자동화하는 "AI 비서 조합" — 메일 자동분류, 회의록→할일, 웹자료→노션, 영상→노트, 주간리포트→시트

## 개요
Gmail, 회의 녹음, 웹 자료, 영상, 스프레드시트 등 여러 도구를 Aside 루틴/n8n/Make로 연결해, 사람이 매번 손대던 반복 업무(분류·요약·정리·기록)를 자동 파이프라인으로 대체합니다. 핵심은 "30개 다 만들기"가 아니라 지금 제일 귀찮은 업무 1개를 먼저 자동화하고, 안정화되면 다음 조합을 추가하는 것입니다. 이 원리 자체가 이미 이 프로젝트의 "웹자료→노션(인스타 대시보드)" 조합으로 검증되었고, 다음 확장 지점은 메일 자동분류이며 여기에 Jev 같은 경량 결정 모델을 붙이면 비용·속도를 더 줄일 수 있습니다.

## 구현 가능성 — 상
- 각 조합(메일 분류, 회의록→할일, 웹자료→노션, 영상→노트, 리포트→시트)은 이미 검증된 개별 기술 요소(Gmail API, LLM 요약, Notion API, Whisper/영상 STT, Google Sheets API)의 조합일 뿐, 새로운 미검증 기술이 없음.
- "웹자료→노션" 조합은 이 저장소의 인스타 대시보드(암호화 데이터 수집·정리 자동화)로 이미 실제 작동 중 — 나머지 조합도 동일한 패턴(수집 → LLM 정리 → 목적지 저장)을 재사용하면 됨.
- Aside 루틴이나 n8n 같은 노코드/로코드 오케스트레이션 도구가 이미 성숙해 있어, 코드를 거의 안 쓰고도 v1을 만들 수 있음.

## 필요 도구
- **Gmail API / Google Workspace 계정** — 무료(기존 계정), API 호출량에 따라 무료 한도 내 운용 가능
- **Aside 루틴** 또는 **n8n**(셀프호스팅 무료 / 클라우드 유료 $20~) 또는 **Make**(무료 티어 있음, 유료 $9~) — 워크플로우 오케스트레이션
- **Claude API** (claude-sonnet-5 또는 claude-haiku-4-5) — 메일 요약/분류, 회의록 정리, 영상 노트 생성 등 LLM 처리, 사용량 기반 과금
- **Jev (TypeSafe AI System One)** — 구조화된 분류 결정(예: 메일 카테고리 판정)에 특화된 경량 모델, LLM 대비 비용·속도 개선용 (유료, 별도 API 키 필요)
- **Notion API** — 무료(개인 워크스페이스), 웹자료·영상 노트 저장용
- **Google Sheets API** — 무료, 주간 리포트 저장용
- **회의 녹음/전사 도구** (예: Otter.ai 유료, 또는 Whisper API 저비용 자체 구현) — 회의록→할일 조합에 필요
- **영상 자막/전사 API** (YouTube 자막 API 무료, 또는 Whisper API 저비용) — 영상→노트 조합에 필요

## 구현 단계
1. 지금 가장 귀찮은 업무 1개를 확정 (제안: 받은 메일 업무별 분류 + 아침 요약).
2. Aside 루틴(또는 n8n) 계정 생성 후 Gmail 트리거 설정 — 매일 08:30, 지난 24시간 미읽음 메일 목록 가져오기.
3. 가져온 메일 본문을 Claude API에 전달해 4개 카테고리(요청/정보/결제/스팸)로 분류하고 각 메일 1줄 요약을 생성하는 프롬프트 작성.
4. 분류 결과를 Gmail 라벨로 자동 적용하고, 카테고리별 요약을 모아 하나의 "아침 브리핑" 이메일 또는 Notion 페이지로 발송/저장.
5. 1~2주간 v1을 운영하며 분류 정확도와 요약 품질을 확인, 오분류 패턴을 프롬프트에 반영해 규칙 안정화.
6. 분류 규칙이 안정되면 동일 입력(메일 제목+본문 요약)을 Jev API로도 병렬 실행해 분류 정확도·응답속도·비용을 Claude API와 비교.
7. Jev가 충분히 정확하면 분류 단계를 Jev로 교체하고 Claude는 요약 생성 등 자연어 생성 작업에만 남겨 비용 구조 최적화.
8. 2주 뒤 두 번째 조합(회의록→할일)을 동일 패턴(전사 → LLM 정리 → Notion/할일 도구 저장)으로 추가.
9. 이후 웹자료→노션(기존 인스타 대시보드 파이프라인 재사용), 영상→노트, 주간리포트→시트 순으로 순차 확장.
10. 안정화된 조합 중 재사용성이 높은 것(특히 메일 분류, 회의록 정리)을 템플릿화해, 소규모 팀/1인 사업자 대상 "AI 비서 세팅 대행" 유료 서비스로 패키징.

## 예상 공수
- 조합 1(메일 자동분류 v1): 4~6시간 (난이도: 중, Gmail API 인증 및 프롬프트 튜닝 포함)
- Jev 교체 실험 및 비교: 3~4시간 (난이도: 중, 병렬 실행 및 정확도 비교 로직 필요)
- 조합 2(회의록→할일): 4~6시간 (난이도: 중, 전사 도구 연동 포함)
- 조합 3~5(웹자료→노션 재사용, 영상→노트, 주간리포트→시트): 각 3~5시간 (난이도: 하~중, 기존 패턴 재사용)
- **총 예상: 조합당 3~6시간, 5개 전체 20~30시간(단계적 진행 전제)**

## 리스크/유의점
- 30개 조합을 동시에 벌이면 유지보수 부담이 커짐 — 반드시 1개씩 순차 적용하고 안정화 후 확장할 것(캡션의 핵심 조언과 동일).
- 메일 자동분류는 오분류 시 중요 메일을 놓칠 위험이 있으므로, 초기에는 자동 삭제/보관 없이 라벨링과 알림까지만 자동화하고 사람이 최종 확인하는 구조로 시작.
- Jev로 교체할 때는 Claude 대비 판단 기준이 다를 수 있어, 교체 직후 최소 1~2주는 두 모델의 결과를 병행 비교하며 검증.
- Gmail/Notion/Sheets API는 민감한 업무 데이터를 다루므로, 워크플로우 도구(n8n/Make/Aside)의 인증 토큰과 로그 저장 위치를 확인하고 외부 서비스에 원문 그대로 장기 보관되지 않도록 주의.
- 유료 서비스로 패키징 시 고객사 메일/회의 데이터를 다루게 되므로, 데이터 처리 위탁 계약 및 보안 책임 범위를 사전에 명확히 할 것.
