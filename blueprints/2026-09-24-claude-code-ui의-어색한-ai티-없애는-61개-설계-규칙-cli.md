# Claude Code UI의 '어색한 AI티' 없애는 61개 설계 규칙 CLI

## 쉽게 말하면
AI한테 "홈페이지 디자인해줘"라고 하면 늘 비슷비슷한 보라색 그라데이션, 어색한 그림자, 뻔한 레이아웃이 나오는 것을 다들 알아챕니다. 이 도구는 "이런 티 나는 습관 61가지"를 체크리스트로 만들어놓고, Claude Code가 화면을 만들 때마다 그 체크리스트로 자동 검수·수정하게 만드는 설치형 스킬입니다. 즉 AI 코딩 도구에게 "디자인 눈치"를 심어주는 옵션 패키지입니다.

## 이걸로 할 수 있는 것
1. 클라이언트에게 납품할 대시보드(dashboard.html)를 Claude Code로 만들 때 "AI가 만든 티"를 줄여서 완성도 높은 결과물로 보이게 한다.
2. Claude Code로 랜딩페이지·SaaS UI를 대신 만들어주는 외주·프리랜서 작업에서 결과물 품질을 높여 재작업 요청을 줄인다.
3. "AI 티 안 나는 디자인" 자체를 세일즈 포인트로 삼아, 노코드/AI 웹사이트 제작 대행 서비스의 차별화 요소로 광고한다.

## 개요
프론트엔드 코드 생성 시 색상·간격·타이포그래피·레이아웃 등에서 반복적으로 튀어나오는 "AI스러운" 패턴을 61개 결정론적 규칙으로 정의하고, 브라우저에서 실시간으로 렌더링 결과를 규칙에 대조해 자동으로 고쳐나갑니다. Anthropic 공식 frontend-design 스킬의 확장판이라 Claude Code와의 통합이 매끄럽고, 결과물의 시각적 완성도(=클라이언트 눈에 보이는 신뢰도)를 자동으로 끌어올려주는 게 핵심 가치입니다.

## 구현 가능성 — 상
설치 명령(`npx impeccable install`, `/impeccable init`)이 구체적이고 검증 가능하며, ★70,325의 활발한 오픈소스 프로젝트라 문서화·유지보수 신뢰도가 높습니다. 이미 보유한 대시보드(dashboard.html)에 바로 적용해볼 수 있어 테스트 장벽도 낮습니다.

## 필요 도구
- Node.js / npm — 무료 (이미 설치되어 있을 가능성 높음)
- Claude Code (본인 사용 중) — 유료(구독)
- impeccable CLI (`npx impeccable install`) — 무료, 오픈소스
- 로컬 브라우저(Chrome 등, 실시간 미리보기용) — 무료

## 구현 단계
1. `ai-info-radar` 또는 별도 테스트용 프로젝트 루트에서 `npx impeccable install` 실행해 CLI를 설치한다.
2. Claude Code 세션 안에서 `/impeccable init`을 실행해 61개 검출 규칙을 활성화하고, 어떤 규칙들이 적용되는지 목록을 훑어본다(색상 규칙, 간격 규칙, 그림자 규칙 등 카테고리 확인).
3. 기존 `dashboard.html`(인스타 대시보드 UI)을 대상으로 impeccable 리뷰를 돌려, "AI 티" 요소가 몇 개 잡히는지, 어떤 지적이 나오는지 기록한다.
4. 지적된 항목 중 실제로 개선이 되는지 Before/After 스크린샷을 찍어 비교한다(효과 검증).
5. 효과가 확인되면, 앞으로 Claude Code로 새 UI 작업(외주·개인 프로젝트 포함)을 할 때 작업 시작 시 `/impeccable init`을 표준 루틴으로 채택한다.
6. 외주·대행 서비스를 고려한다면, "AI 티 안 나는 UI 품질 보증"을 포트폴리오/제안서 문구로 활용해 차별화 포인트로 제시한다.

## 예상 공수
설치·초기 테스트: 30분~1시간, 난이도 하(설치형 CLI라 코드 수정 불필요). 실제 프로젝트에 정착시켜 습관화하는 데는 몇 차례 사용 경험이 필요하므로 1~2주 정도 체감 적응 기간 예상.

## 리스크/유의점
- 61개 규칙이 특정 디자인 취향(미니멀/모던 계열)에 치우쳐 있을 수 있어, 브랜드 톤이 다른 프로젝트에는 과도한 수정이 들어갈 위험이 있음.
- 오픈소스 프로젝트 특성상 업데이트에 따라 규칙 세트가 바뀔 수 있으므로, 배포 전 결과물은 항상 수동으로 최종 확인 필요.
- "AI 티 제거"가 실제 클라이언트 만족도로 직결되는지는 별도 검증 필요 — 과장(3/5) 평가된 점을 감안해 효과를 과신하지 말고 소규모 테스트로 먼저 검증할 것.
