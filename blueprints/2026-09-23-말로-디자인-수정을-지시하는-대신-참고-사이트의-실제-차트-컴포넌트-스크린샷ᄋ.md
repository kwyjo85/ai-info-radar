# 이미지 기반 디자인 워크플로우 — 레퍼런스 스크린샷을 Claude Code에 그대로 넘기는 습관

## 개요
"예쁘게 해줘" 식의 말로 된 지시 대신, 마음에 드는 사이트의 차트/카드/컴포넌트를 캡처해 Claude Code에 이미지로 첨부하고 "이 스타일로 바꿔줘"라고 요청하는 워크플로우입니다. 텍스트로는 전달하기 어려운 여백·타이포·컬러·인터랙션 뉘앙스가 이미지 한 장으로 압축 전달되어, 디자인 수정 왕복 횟수가 줄고 결과물 품질이 레퍼런스에 근접합니다. 별도 설치 없이 오늘부터 습관만 바꾸면 되므로, Jev·Claude Code 기반 자동화 서비스를 외주/컨설팅 형태로 제공할 때 "빠르고 정확한 UI 개선" 역량으로 바로 수익화에 연결할 수 있습니다.

## 구현 가능성 — 상
- Claude Code는 이미 이미지 첨부 + 멀티모달 이해를 기본 지원하므로 신규 도구나 API 연동이 전혀 필요 없음.
- "레퍼런스 이미지 + 짧은 지시문" 조합은 검증된 프롬프트 엔지니어링 패턴(설명보다 예시가 모호성을 줄임)으로, 실패 가능성이 낮음.
- 이 저장소의 `dashboard.html` 카드 UI 개선처럼 이미 진행 중인 작업에 즉시 적용해 효과를 바로 확인할 수 있음.

## 필요 도구
- **Claude Code** (이미 사용 중) — 무료(구독 내 포함)
- **macOS 스크린샷 캡처** (Cmd+Shift+4, 또는 Cmd+Shift+5로 창 단위 캡처) — 무료, 기본 내장
- (선택) **CleanShot X / Shottr** 같은 캡처 도구 — 즉시 주석·크롭 편집 가능, 유료(약 $8~30, 없어도 무방)
- (선택) **브라우저 개발자 도구** — 특정 컴포넌트만 정확히 캡처하고 싶을 때 요소 단위 스크린샷용, 무료

## 구현 단계
1. 참고할 만한 UI를 발견하면 즉시 캡처하는 습관화: 인스타/트위터/디자인 레퍼런스 사이트(Mobbin, Dribbble, 실제 서비스 화면 등)에서 마음에 드는 차트나 카드 컴포넌트를 볼 때마다 스크린샷으로 저장(예: `~/Desktop/design-refs/` 폴더에 날짜별 정리).
2. Claude Code 대화창에 해당 이미지를 드래그 앤 드롭 또는 첨부.
3. 프롬프트는 "이 이미지의 [차트/카드/버튼] 스타일로 [파일명/컴포넌트명]을 바꿔줘"처럼 대상 파일과 대상 요소를 명시해 모호성을 줄임. 필요시 "색상만/레이아웃만/타이포만 참고" 식으로 반영 범위를 한정.
4. 이 프로젝트의 `dashboard.html` 카드 UI에 바로 시험 적용: 마음에 드는 대시보드/차트 스크린샷 1~2개를 준비해 "이 카드 스타일로 dashboard.html의 항목 카드를 개선해줘" 요청 후 결과 비교.
5. 결과가 만족스러우면 Before/After 스크린샷을 남겨두고, 이 워크플로우를 팀/클라이언트용 가이드 한 장으로 정리.
6. 외주·컨설팅 맥락에서는 클라이언트에게 "레퍼런스 이미지만 보내주시면 Claude Code로 반영해드립니다" 형태의 서비스 문구로 제안, 왕복 커뮤니케이션 비용을 줄인 것을 차별점으로 제시.
7. 반복되는 디자인 개선 요청이 많다면 자주 쓰는 레퍼런스 이미지를 카테고리별(차트/폼/네비게이션 등)로 라이브러리화해 다음 프로젝트에 재사용.

## 예상 공수
- 습관 적용 및 첫 시도(대시보드 카드 UI 개선): 30분~1시간 (난이도: 하)
- 결과 비교 및 프롬프트 문구 다듬기: 30분 (난이도: 하)
- 서비스/가이드 문서화: 1시간 (난이도: 하)
- **총 예상: 2~2.5시간** — 오늘 바로 완료 가능한 수준

## 리스크/유의점
- 레퍼런스 이미지의 디자인이 저작권 보호 대상일 수 있으므로, 완전히 동일한 픽셀 단위 복제가 아니라 "스타일 참고" 수준으로만 활용하고 클라이언트 납품물에는 독자적 변형을 가할 것.
- 이미지 하나만으로는 반응형/다크모드 등 상태 변화를 전달하기 어려우므로, 필요한 경우 여러 상태의 스크린샷을 함께 제공해야 함.
- 과도한 기대(과장 점수 1점)를 감안할 때, 이 워크플로우는 "왕복 커뮤니케이션 감소"라는 생산성 개선 효과이지 완전 자동화나 새로운 수익원 자체는 아님 — 컨설팅 서비스 차별화 요소로 포지셔닝하는 것이 적절.
- 캡처 이미지에 클라이언트의 민감 데이터(실제 고객 이름, 수치 등)가 노출된 화면이 포함되지 않도록 캡처 전 마스킹 확인.
