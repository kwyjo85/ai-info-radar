# Anthropic 공식 "환각 줄이기" 지침을 시스템 프롬프트에 반영

## 개요
Anthropic 공식 문서(docs.anthropic.com > Prompt engineering > Reduce hallucinations)의 지침을 Claude Code 프로젝트 지침(CLAUDE.md)과 Jev 기반 자동화 파이프라인의 시스템 프롬프트에 규칙 3~4줄로 이식하는 작업입니다. "모르면 모른다고 말하기", "인용 먼저 뽑고 그 인용만으로 답하기", "답변 후 사실 주장 자가 검증"을 강제하면, 리서치·요약·고객 응대 등 신뢰도가 곧 상품 가치인 자동화 서비스에서 환각으로 인한 재작업·신뢰 손상 비용을 줄일 수 있습니다.

## 구현 가능성 — 상
- 실제 존재하는 공식 문서 기반이라 근거가 명확하고, 적용은 텍스트 파일(CLAUDE.md, 시스템 프롬프트) 수정만으로 끝나 코드 변경이나 외부 의존성이 전혀 없음.
- 이미 운영 중인 `ai-info-radar` 수집 루틴(summary 생성 단계)에 바로 끼워 넣을 수 있는 구조.

## 필요 도구
- **Anthropic 공식 문서** (docs.anthropic.com, 무료, 원문 읽기용)
- **Claude Code** (이미 보유, CLAUDE.md/프로젝트 지침 편집 대상) — 무료(구독 내 포함)
- **Jev 시스템 프롬프트 설정 파일** (자동화 파이프라인에서 사용 중인 프롬프트 템플릿) — 무료(자체 보유 자산)
- 텍스트 에디터 (VS Code 등, 이미 보유) — 무료

## 구현 단계
1. Anthropic 공식 문서 "Reduce hallucinations"(Prompt engineering 섹션) 원문을 10분간 읽고 핵심 기법(모른다고 말하기 허용, 인용 우선 추출, 자가 검증 단계, 출처 요구)을 메모.
2. 현재 `ai-info-radar` 저장소의 시스템 프롬프트/CLAUDE.md에 아래 3줄을 추가:
   - "확실하지 않으면 추측하지 말고 모른다고 답해라."
   - "문서나 근거 기반으로 답할 때는 먼저 관련 인용문을 뽑아 제시하고, 그 인용문 범위 안에서만 답변을 구성해라."
   - "답변을 작성한 뒤, 답변에 포함된 사실 주장(수치·고유명사·URL 등)을 스스로 재검토해 근거가 없으면 삭제하거나 '불확실' 표시를 해라."
3. 중요 리서치/블루프린트 작성 작업(현재 이 블루프린트 생성 루틴 포함)에는 "출처 URL 필수" 규칙을 별도 항목으로 추가.
4. 인스타 대시보드 수집 루틴의 summary 생성 프롬프트(현재 easy/use_cases 생성 로직이 있는 부분)에도 동일한 3줄 규칙을 삽입해, 원본 캡션에 없는 내용을 지어내지 않도록 제한.
5. 규칙 적용 전/후로 동일한 인스타 게시물 5~10건을 재처리해, 요약문에 원문에 없는 수치·주장이 섞여 나오는지 육안 비교(간이 A/B 테스트).
6. 문제 없으면 커밋 후 상시 적용, Jev 연동 자동화(예: 이승현의 AI 네이티브 IT조선류 콘텐츠 자동 요약)에도 동일 프롬프트 규칙 이식.

## 예상 공수
- 원문 문서 정독 및 핵심 규칙 정리: 10~20분 (난이도: 하)
- CLAUDE.md/시스템 프롬프트 수정: 20~30분 (난이도: 하)
- summary 생성 로직에 규칙 삽입 및 반영 확인: 30분~1시간 (난이도: 하)
- 전/후 비교 검증(5~10건 재처리): 30분~1시간 (난이도: 중)
- **총 예상: 1.5~2.5시간**

## 리스크/유의점
- "모르면 모른다"를 과하게 강제하면 응답이 지나치게 방어적이 되어 자동화 파이프라인의 완결성(모든 게시물에 summary/easy/use_cases 채우기)을 해칠 수 있음 — 필수 출력 필드가 있는 자동화 단계에서는 "불확실 표시 후 최선의 추정 제공" 절충안 필요.
- 인용 우선 추출 규칙은 원문이 짧은 인스타 캡션류 콘텐츠에는 과한 오버헤드가 될 수 있어, 문서 기반 리서치 작업과 짧은 SNS 요약 작업을 구분해 적용 범위를 다르게 가져가야 함.
- 규칙 추가만으로 환각이 완전히 사라지지 않으므로, 정기적으로(예: 월 1회) 실제 출력 샘플을 재검토하는 습관이 병행되어야 효과가 유지됨.
