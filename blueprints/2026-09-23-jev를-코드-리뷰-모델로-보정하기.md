# Jev를 코드 리뷰 모델로 보정하기

## 쉽게 말하면
Jev라는 AI 모델이 "이 코드 이상해요!"라고 너무 자주, 혹은 너무 뜨문뜨문 경고를 날리는 걸 훈련시켜서, 실제로 위험한 버그만 콕 집어 말하도록 감을 잡아주는 작업입니다. 마치 신입 리뷰어에게 "이건 진짜 문제, 이건 그냥 취향 차이"를 계속 알려줘서 점점 베테랑 리뷰어처럼 만드는 것과 비슷합니다.

## 이걸로 할 수 있는 것
1. 클라이언트의 GitHub 저장소 PR을 자동으로 리뷰해주는 유료 봇 서비스를 만들 때, Jev의 오탐(false positive)을 줄여 신뢰도 높은 결과물로 판매할 수 있습니다.
2. Claude Code의 `code-review` 스킬과 Jev를 나란히 돌려서 결과를 비교·검증하는 "2중 검수" 상품을 소규모 개발팀에 컨설팅으로 제공할 수 있습니다.
3. 사내(또는 코코베이비) 반복 코드 리뷰 업무를 자동화 스킬로 만들어, 매번 사람이 놓치던 보안/타입 이슈를 일관되게 잡아내는 사이드 프로젝트로 확장할 수 있습니다.

## 개요
Jev(TypeSafe AI System One, 2026-09 출시)를 코드 리뷰 용도로 쓸 때 나타나는 과잉/과소 경고 문제를 보정(calibration)하는 방법론입니다. 리뷰 결과의 정밀도(precision)를 높여 "돈 받고 파는 자동 리뷰 서비스"의 신뢰성을 확보하는 데 직접적인 가치가 있습니다.

## 구현 가능성: 중
근거: 저장소 자체는 특정 모델(Jev)에 특화된 보정 스크립트/데이터셋일 가능성이 높아 접근·API 사용법을 먼저 파악해야 합니다. Claude Code의 기존 `code-review` 스킬 구조(confidence 레벨, PR 코멘트 게시 등)와 개념적으로 유사해 통합은 어렵지 않으나, Jev API 자체의 가용성·요금제·레이트리밋을 확인하는 선행 조사가 필요합니다.

## 필요 도구
- GitHub 저장소 `Selmar/typesafe-jev-calibrate-for-code-review` 클론 (무료)
- Jev API 키 (TypeSafe AI System One, 유료 예상 — 요금제 확인 필요)
- Claude Code `code-review` 스킬 (무료, 이미 설치됨)
- Python 또는 Node.js 환경 (보정 스크립트 실행용, 무료)
- GitHub API / `gh` CLI (PR 코멘트 자동 게시용, 무료)
- 검증용 샘플 PR 데이터셋 (직접 수집 또는 오픈소스 PR 이력 활용, 무료)

## 구현 단계
1. `git clone https://github.com/Selmar/typesafe-jev-calibrate-for-code-review`로 저장소를 받아 README와 스크립트 구조를 파악한다.
2. Jev API 키를 발급받고, 저장소에 포함된 보정 스크립트를 실행해 기본 baseline 정확도(오탐/누락률)를 측정한다.
3. 실제 검증용으로 우리 팀(또는 코코베이비) 저장소의 과거 PR 20~30개를 골라 "실제 문제였던 코멘트 vs 봇이 낸 코멘트"를 라벨링한 소규모 데이터셋을 만든다.
4. 이 데이터셋으로 Jev의 confidence threshold를 조정하고, 반복 실행하며 precision/recall을 비교한다.
5. 보정된 Jev를 Claude Code `code-review` 스킬과 나란히 붙여, 동일 PR에 대해 두 모델 결과를 diff해 겹치는 부분(고신뢰)과 갈리는 부분(재검토 필요)을 구분하는 파이프라인을 만든다.
6. 이 파이프라인을 GitHub Actions 또는 간단한 로컬 스크립트로 감싸 "PR 올리면 자동 리뷰 코멘트"가 달리도록 연결한다.
7. 결과물을 1~2개 소규모 팀에 무료 체험으로 제공해 실사용 피드백을 받고, 유료 상품(월 구독형 리뷰 봇 컨설팅)으로 전환 여부를 판단한다.

## 예상 공수
- 저장소 파악 + Jev API 연동: 2~3시간 (난이도: 하)
- 보정 데이터셋 구축 + threshold 튜닝: 4~6시간 (난이도: 중)
- Claude Code와의 이중 검수 파이프라인 구성: 3~5시간 (난이도: 중)
- 총 예상: 9~14시간, 난이도 중

## 리스크/유의점
- Jev는 2026-09 출시된 신규 모델로 Claude의 학습 컷오프 이후 정보라, API 스펙·요금·안정성을 직접 문서에서 재확인해야 한다.
- 오픈소스 저장소의 보정 기법이 특정 코드베이스(언어/프레임워크)에 편향되어 있을 수 있어, 우리 환경에 그대로 적용하면 재보정이 필요할 수 있다.
- 자동 리뷰 봇을 실제 서비스로 판매할 경우, 클라이언트 코드가 외부 API(Jev)로 전송되므로 보안/기밀유지 계약 검토가 선행되어야 한다.
