# 기술·심리·뉴스·펀더멘털 담당 AI 4명 토론으로 주식 분석 리포트 생성

## 쉽게 말하면
회사 회의실에 네 명의 애널리스트—차트 보는 사람, 투자자 심리 읽는 사람, 뉴스 담당, 재무제표 담당—를 앉혀놓고 서로 토론시킨 뒤 결론만 받아보는 것과 같습니다. 다만 이 네 명이 전부 AI이고, 회의는 내 맥북 안에서 열리며, 회의 한 번 여는 비용이 커피 한 잔보다 쌉니다.

## 이걸로 할 수 있는 것
1. 아침에 관심 종목 5~10개를 넣고 자기 전에 "기술적으로는 상승, 심리는 과열" 같은 4각도 요약 리포트를 받아본다.
2. 특정 가격·거래량 조건을 걸어두고 조건 충족 시 텔레그램으로 알림을 받아 뉴스를 놓치지 않는다.
3. 여러 증권사 계좌의 손익을 한 화면에 모아, 갈아타던 앱을 매번 열지 않고도 전체 포트폴리오 상태를 확인한다.

## 개요
이 시스템은 종목 분석 과정(기술·심리·뉴스·펀더멘털 각 관점의 데이터 수집·해석·토론·요약)을 자동화합니다. 매번 수작업으로 차트·뉴스·재무제표를 뒤지는 대신, AI 4개가 각자 맡은 영역을 분석하고 서로 반박·조율한 결과를 리서치 노트 형태로 받는다는 데 가치가 있습니다. 단, 이 결과는 "매매 신호"가 아니라 "여러 관점을 빠르게 정리한 참고 자료"로 취급해야 합니다.

## 구현 가능성: 상
근거: GitHub 오픈소스(TNT-Likely/PanWatch)와 Docker 이미지가 이미 공개되어 있고, 설치 명령어가 원문에 구체적으로 제시되어 있습니다(`docker run` 한 줄). OpenAI 호환 API만 있으면 붙는 구조라 개인 맥북에서 별도 서버 없이 로컬 실행이 가능합니다. 다만 토론 로직의 품질·안정성은 실제 사용해보기 전에는 검증되지 않았고, 인스타 대시보드 평가 자체도 6.3/10(효과 3, 과장 3)으로 낮은 편이라는 점은 감안해야 합니다.

## 필요 도구
- Docker Desktop for Mac — 무료 (Apple Silicon 지원 확인 필요 [공식 문서 확인 필요])
- PanWatch 이미지 (`sunxiao0721/panwatch:latest`) — 무료(오픈소스)
- OpenAI 호환 API 키 (OpenAI GPT, 또는 저비용 호환 API) — 사용량 종속 유료, 분석 1회 약 0.05달러 [원문 근거]
- 텔레그램 봇 토큰(알림용) — 무료
- (선택) 증권사 API 연동 모듈 — 국내 계좌 연동 시 별도 구현 필요 [추정, 원문에는 계좌 연동 방식 상세 없음]

## 구현 단계
1. Docker Desktop을 맥북에 설치하고 실행 상태를 확인한다.
2. 터미널에서 `docker run -d -p 8000:8000 -v panwatch_data:/app/data sunxiao0721/panwatch:latest`를 실행한다.
3. 브라우저에서 `localhost:8000`에 접속해 대시보드 초기 설정 화면을 연다.
4. 설정 메뉴에서 OpenAI 호환 API 키를 입력해 4개 AI 애널리스트가 사용할 모델을 연결한다.
5. 관심 종목 1개를 등록하고 "딥 분석"을 3회 반복 실행해 결론(매수/매도/중립)이 매번 일관되는지, 근거가 바뀌는지 비교한다.
6. 결론이 흔들리는 경우, 이 리포트를 매매 신호가 아닌 리서치 참고자료로만 활용하기로 내부 규칙을 정한다.
7. 가격·등락률·거래량 조건(AND/OR)을 설정하고 텔레그램 봇 연동을 테스트한다.
8. 안정성이 확인되면 관심 종목 수를 늘리고, 필요 시 여러 증권 계좌 통합 뷰 기능을 설정한다.
9. 매주 실제 시장 움직임과 리포트 결론을 비교해 신뢰도를 스스로 기록·검증한다.

## 예상 공수
- 초기 설치·연동: 1~2시간 (난이도: 하)
- API 키 발급 및 비용 설정: 30분 (난이도: 하)
- 종목 1개 반복 테스트 및 신뢰도 검증: 2~3시간 (난이도: 중)
- 알림 조건 설정 및 텔레그램 연동: 1시간 (난이도: 중)
- 전체 안정화 및 운영 루틴 정착: 추가 1주 정도의 관찰 기간 [추정]

## 리스크/유의점
- AI 4명의 "토론 결론"은 실제 애널리스트 합의가 아니라 언어모델의 패턴 생성 결과이므로, 최종 포지션을 그대로 매매에 반영하면 안 됩니다(원문에서도 명시).
- 대시보드 자체 평가 점수가 높지 않음(6.3/10, 과장 3) — 마케팅 문구보다 실제 리포트 품질을 직접 검증해야 합니다.
- API 비용은 분석 빈도·종목 수에 비례해 누적되므로 월간 예산 상한을 미리 정해두는 것이 안전합니다.
- 개인정보·계좌 데이터를 다루는 만큼, 셀프 호스팅이라도 API 키·데이터 백업 관리에 주의가 필요합니다.
- 증권사 계좌 실시간 연동 기능은 국가별 지원 여부가 다를 수 있어 사전 확인이 필요합니다 [공식 문서 확인 필요].
