# Anthropic 공식 지식근로자 플러그인 모음(knowledge-work-plugins) Claude Code/Cowork 도입

## 개요
anthropics/knowledge-work-plugins는 Anthropic이 직접 공개한 플러그인 모음으로, 리서치·문서 작성·데이터 정리·영업/마케팅 워크플로우 등 "개발이 아닌 업무"를 Claude Cowork/Claude Code 안에서 표준화된 절차로 처리하게 해준다. 공식 저장소라 품질과 유지보수가 상대적으로 안정적이며, 사용자의 반복 업무(인스타 대시보드 리서치·요약, 주간 리포트 등)에 바로 적용해 자동화 파이프라인의 한 단계를 대체하거나 강화할 수 있다는 점에서 "AI 업무 자동화로 수익 창출" 방향과 직접 맞닿아 있다.

## 구현 가능성 — 상
근거: (1) Anthropic 공식 저장소로 별점 25,407·주간 +1,350의 활발한 채택이 확인되어 신뢰도와 커뮤니티 검증이 충분하다. (2) Claude Code에는 이미 `/plugin` 마켓플레이스 설치 명령이 내장돼 있어 별도 빌드나 프록시 설정 없이 바로 추가할 수 있다. (3) 플러그인은 "지식노동" 프롬프트/워크플로우 패키지 형태로, 코드 통합이 아니라 명령어 설치 수준이라 개인 macOS 환경에서 진입 장벽이 낮다.

## 필요 도구
- **Claude Code CLI** (이미 사용 중) — 무료, API 사용량만 과금
- **Claude Cowork** 계정/접근 권한 — 플랜에 따라 과금 여부 상이, 계정 확인 필요
- **anthropics/knowledge-work-plugins** GitHub 저장소 — 무료, 오픈소스(Python)
- **`/plugin` 마켓플레이스 명령** (Claude Code 내장 기능) — 무료
- 기존 반복 업무 산출물(예: 인스타 대시보드 주간 리포트, summary/analysis 단계 프롬프트) — 비교 테스트용 자료

## 구현 단계
1. `https://github.com/anthropics/knowledge-work-plugins` 저장소의 README와 플러그인 목록을 확인해 research·writing·data 계열 플러그인부터 이름과 용도를 정리한다.
2. Claude Code에서 `/plugin marketplace add anthropics/knowledge-work-plugins` (또는 README에 명시된 정확한 마켓플레이스 추가 명령)를 실행해 저장소를 마켓플레이스로 등록한다.
3. `/plugin install`로 research 계열 1개, writing 또는 data 계열 1개, 총 2개 플러그인을 설치한다.
4. 기존에 수동으로 하던 반복 업무 중 하나(예: 인스타 대시보드 수집 루틴의 summary/analysis 단계, 혹은 주간 업무 리포트 작성)를 골라, 설치한 플러그인을 사용해 동일 작업을 한 번 더 처리해본다.
5. 플러그인 사용 전/후 결과물을 비교한다 — 출력 품질, 소요 시간(프롬프트 왕복 횟수), 토큰/비용 차이를 체크리스트로 기록한다.
6. 결과가 만족스러우면 `ai-info-radar` 저장소의 데이터 수집·요약 파이프라인(cron/스크립트) 중 리서치·요약 단계에 해당 플러그인의 워크플로우를 프롬프트 템플릿으로 이식할지 검토한다.
7. 영업/마케팅 계열 플러그인 중 사용자의 코코베이비/외주 업무에 적용 가능한 것이 있는지 목록에서 추가로 스캔하고, 있으면 3번째 플러그인으로 별도 설치·검증한다.

## 예상 공수
- 저장소 스캔 및 플러그인 선정: 30분~1시간
- 마켓플레이스 등록 및 설치: 15~30분
- 반복 업무 1건 비교 테스트: 1~2시간
- 파이프라인 이식 검토(선택): 2~3시간
- 총 예상: 2~4시간 (파이프라인 이식까지 포함 시 최대 6시간)
- 난이도: 하 (공식 도구 + 내장 설치 명령이라 시행착오 적음)

## 리스크/유의점
- Claude Cowork 접근 권한이나 플랜 제약이 있을 수 있으므로, 설치 전 현재 계정으로 Cowork 기능 사용이 가능한지 먼저 확인한다.
- 플러그인이 다루는 업무 프롬프트가 영어 중심으로 설계되었을 가능성이 있어, 한국어 업무(인스타 리서치·리포트)에 그대로 적용 시 톤/형식 조정이 필요할 수 있다.
- 공식 저장소도 활발히 업데이트 중(+1,350/주)이므로 플러그인 인터페이스나 명령어가 변경될 수 있어, 도입 후에도 주기적으로 CHANGELOG 확인이 필요하다.
- "인스타에서 유료로 파는 정보"라는 평가와 달리 저장소 자체는 무료 공개이므로, 유료 강의/템플릿 구매 없이 원본 저장소만으로 충분히 재현 가능하다는 점을 확인하고 불필요한 지출을 피할 것.
- 플러그인을 파이프라인에 자동 통합하기 전에는 반드시 수동 비교 단계(4~5단계)를 거쳐, 기존 요약 품질보다 떨어지지 않는지 검증 후 교체할 것.
