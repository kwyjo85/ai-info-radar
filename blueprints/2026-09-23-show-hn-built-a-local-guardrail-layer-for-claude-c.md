# Claude Code용 로컬 가드레일 레이어 "Mati"로 팀 지식 자동 주입하기

## 개요
Mati는 엔지니어/PM 머릿속에만 있던 "이건 하지 마라" 류의 암묵적 제약을 Claude Code·Codex에 로컬로 강제 주입하는 오픈소스 가드레일 도구다. Jev 등 다른 AI 자동화 파이프라인 위에 얹으면, 고객사별 배포마다 반복되는 "이 API는 건드리지 마세요", "이 테이블은 읽기 전용" 같은 규칙을 코드 리뷰 없이도 실행 전에 차단할 수 있어 컨설팅형 Claude Code 도입 서비스의 신뢰도와 판매 포인트가 된다.

## 구현 가능성 — 중
- Apache-2.0 오픈소스, MCP + CLI 인터페이스 제공 → 설치·통합 자체는 난이도 낮음
- 다만 저장소가 신생(HN 포인트 2, 코멘트 0)이라 문서화 수준·안정성 미검증, 실제 팀 규칙을 룰셋으로 옮기는 초기 설계 작업에 시간이 듦
- "본인 워크플로우"라기보다 "고객에게 패키징해서 파는 부가 서비스"로 가치가 더 큼 → 구현 자체보다 상품화 설계가 병목

## 필요 도구
- **Mati** (무료, Apache-2.0) — https://github.com/ioni-dev/mati
- **Claude Code** (기존 사용 중, 유료 API 크레딧)
- **MCP 서버 설정 파일** (claude_desktop_config.json 또는 프로젝트 `.claude/settings.json`) — 무료
- (선택) **Codex CLI** — Mati가 함께 지원, 크로스 에이전트 데모용
- (선택) **1Password/Vault류 시크릿 매니저** — 가드레일 룰에 민감정보 접근 규칙 포함 시

## 구현 단계
1. `git clone https://github.com/ioni-dev/mati` 후 로컬 빌드/설치 스크립트 실행, README 기준으로 CLI 단독 실행부터 확인
2. 본인 회사(cocobaby/adtek) 리포 중 하나에 시범 적용 — 예: `scripts/cycle.py`나 인스타 대시보드 수집기처럼 민감한 스크립트에 "이 파일의 API 키 로직은 수정 금지", "data/ 폴더 삭제 금지" 같은 규칙 2~3개를 Mati 룰 포맷으로 작성
3. Claude Code의 MCP 설정에 Mati 서버 등록, 실제로 Claude Code에게 해당 스크립트 수정을 시켜보며 가드레일이 실행 전 차단하는지 검증 (성공/실패 로그 캡처 — 데모 자료용)
4. 검증 로그와 룰셋 작성 과정을 블로그/노션 문서로 정리 → "Claude Code 도입 시 숨은 제약을 코드화하는 법" 컨설팅 자료로 패키징
5. 잠재 고객(개발팀 리드, 1인 스타트업)에게 "우리 팀의 도메인 규칙을 Mati 룰셋으로 이관해드립니다" 형태의 소규모 유료 세팅 서비스 제안 — 반나절 세션 + 룰셋 5~10개 작성 패키지
6. 여유가 되면 업종별(이커머스 재고 API 금지, 헬스케어 PII 마스킹 등) 룰셋 템플릿을 미리 만들어 재판매 가능한 형태로 축적

## 예상 공수
- 1단계(설치·시범 적용): 2~3시간, 난이도 하
- 2~3단계(검증·문서화): 3~4시간, 난이도 중
- 4~6단계(상품화·영업 자료): 4~6시간, 난이도 중 (반복 시 단축)
- 총 1차 사이클: 약 10~13시간

## 리스크/유의점
- 신생 도구라 프로덕션 신뢰성 미검증 — 고객 환경에 적용 전 반드시 사이드 리포에서 충분히 테스트
- MCP 인터페이스가 Claude Code 버전 업데이트에 따라 깨질 수 있음 → 통합 코드에 대한 버전 고정 필요
- "가드레일 우회 방법"을 함께 공개하면 악용 소지가 있으므로, 데모/문서에는 방어 관점만 노출
- 실제 수익화는 도구 자체가 아니라 "룰셋 설계·컨설팅" 서비스에서 나오므로, 개발 시간보다 영업/케이스스터디 작성에 더 많은 비중을 둘 것
