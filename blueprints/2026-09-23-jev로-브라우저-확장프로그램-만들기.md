# Jev로 브라우저 확장프로그램 만들기

## 쉽게 말하면
Jev는 질문에 긴 글로 답하는 대신 "예/아니오, 87% 확신" 같은 즉답만 초고속으로 내놓는 AI입니다. 브라우저 확장프로그램(크롬 확장 같은 것)에 이 즉답 AI를 붙이면, 웹페이지를 볼 때마다 "이 리뷰는 가짜일 확률 92%", "이 이메일은 스팸일 확률 95%" 같은 판단을 눈 깜짝할 사이에 화면에 띄워줄 수 있습니다.

## 이걸로 할 수 있는 것
1. 쇼핑몰 페이지를 열면 리뷰 옆에 "가짜 리뷰 의심도" 배지를 실시간으로 표시하는 확장프로그램을 만들어 판매한다.
2. 지메일/아웃룩 위에 얹어 메일을 열기 전에 "피싱 위험도"를 즉시 판정해주는 보안 확장프로그램을 만든다.
3. 채용 사이트(사람인, 링크드인)에서 공고를 볼 때 "이 공고가 실제 채용일 확률"을 즉시 뱃지로 보여주는 도구를 부업으로 배포한다.

## 개요
이 항목은 Jev(초고속 판정형 AI)의 API를 브라우저 확장프로그램에 내장해, 사용자가 웹페이지를 보는 즉시 텍스트/이미지에 대한 신뢰도·위험도 판정을 실시간으로 표시하는 기법을 다룹니다. LLM 기반 판정은 응답이 느리고 비용이 커서 "페이지 스크롤할 때마다 판정"하는 UX엔 부적합했는데, Jev는 여기에 특화되어 있어 실시간 판정형 확장프로그램이라는 새로운 제품 카테고리를 열어줍니다. Claude Code를 이용하면 확장프로그램의 UI/로직 코드 생성부터 Chrome Web Store 배포 패키징까지 하루~이틀 만에 프로토타입을 만들 수 있어, 부업형 마이크로 SaaS 아이템으로 적합합니다.

## 구현 가능성: 중
- 근거(가능한 부분): 크롬 확장프로그램 구조(manifest.json, content script, background script)는 표준화되어 있고 Claude Code가 매우 잘 생성함. Jev API는 원문 기사 기준 REST 호출 방식으로 추정되며 단순 텍스트 입력 → 타입 값 반환 구조라 통합이 단순함.
- 근거(불확실한 부분): Jev는 2026-09-15 출시된 지 얼마 안 된 서비스라 SDK/문서 성숙도, 요금제, rate limit이 아직 검증되지 않음. 또한 "가짜 리뷰 판정" 같은 실사용 정확도는 실제 붙여봐야 알 수 있음. 이 때문에 상(上)이 아닌 중(中)으로 평가.

## 필요 도구
- **TypeSafe API 키** (`TYPESAFE_API_KEY`) — Jev 호출용, 유료(요금제 미확인, early access 단계라 변동 가능)
- **Claude Code** — manifest.json, content script, popup UI 코드 생성 (기존 구독으로 무료 활용)
- **Chrome Extension 개발 환경** — Manifest V3, 무료
- **Chrome Web Store 개발자 계정** — 최초 등록비 $5 (1회, 배포 시 필요)
- **Node.js / esbuild 또는 Vite** — 확장프로그램 번들링, 무료
- (선택) **Stripe** — 유료 구독 모델로 판매 시 결제 연동, 거래 수수료만 발생

## 구현 단계
1. TypeSafe 홈페이지(typesafe.ai)에서 Jev API 문서와 early access 신청 절차를 확인하고 API 키를 발급받는다.
2. Claude Code로 "Chrome Manifest V3 확장프로그램 뼈대"를 생성 요청 — manifest.json, content_script.js, background service worker 기본 틀 확보.
3. 타겟 시나리오 하나를 확정한다 (예: 쿠팡/네이버 쇼핑 리뷰 페이지의 가짜 리뷰 판정). content script가 페이지의 리뷰 텍스트를 DOM에서 추출하도록 Claude Code로 구현.
4. 추출한 텍스트를 background script에서 Jev API로 전송 → 확신도(confidence) 값을 받아오는 fetch 로직을 Claude Code로 작성 (CORS 회피를 위해 background에서 호출).
5. 판정 결과를 원본 페이지 위에 배지(badge) UI로 오버레이하는 CSS/DOM 삽입 코드를 작성한다.
6. 로컬에서 `chrome://extensions` 개발자 모드로 unpacked 로드해 실제 쇼핑몰 페이지에서 테스트, Jev 응답 지연·정확도를 체감 확인한다.
7. API 키를 사용자별로 발급/과금하는 구조가 필요하면 간단한 백엔드 프록시(예: Cloudflare Workers)를 하나 세워 요청을 중계하고 사용량을 계측한다.
8. Chrome Web Store에 초안 등록(스크린샷, 설명, 개인정보처리방침 페이지 필요) 후 심사 제출.
9. 무료 체험 + 유료 구독(예: 월 $3~5) 형태로 Stripe 결제를 연동해 수익화한다.

## 예상 공수
- 프로토타입(1~6단계): 8~14시간 — 난이도 중
- 배포·과금 연동(7~9단계): 6~10시간 — 난이도 중상 (백엔드 프록시, 스토어 심사 대응 포함)
- 총합: 약 2~3일 집중 작업 (풀타임 기준), 부업 페이스면 1~2주

## 리스크/유의점
- Jev가 early access 단계라 API 안정성·요금 정책이 바뀔 수 있음 — 초기엔 무료 API 사용량이 갑자기 유료 전환될 위험을 감안해야 함.
- 웹페이지 DOM에서 텍스트를 긁어 외부(Jev) 서버로 전송하는 구조이므로, 사용자 개인정보(이메일 본문 등)를 다루는 시나리오라면 개인정보처리방침 명시와 최소 수집 원칙이 필수 (특히 피싱 탐지용 이메일 확장은 민감도 높음).
- 판정 정확도가 광고만큼 높지 않을 경우("가짜 리뷰 92%" 표시가 틀리면) 사용자 신뢰를 잃고 스토어 리뷰 평점에 타격을 줄 수 있음 — 출시 전 정확도 검증이 중요.
- Chrome Web Store 심사에서 "원격 코드 실행"이나 "과도한 권한 요청"으로 반려될 수 있으니 최소 권한(activeTab 등)으로 설계할 것.
