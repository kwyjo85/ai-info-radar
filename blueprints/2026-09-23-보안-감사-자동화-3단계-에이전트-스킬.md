# 보안 감사 자동화: 3단계 에이전트 스킬

## 쉽게 말하면
내가 만든 코드를 AI 에이전트가 "취약점을 찾고 → 그게 진짜 문제인지 다시 한번 검증하고 → 사람이 읽기 쉬운 리포트로 정리"까지 3단계로 알아서 해주는 스킬입니다. 비유하자면 집을 짓고 나서 검사관이 한 번 훑어보는 게 아니라, 한 사람이 문제를 지적하면 다른 사람이 "진짜 그런지" 다시 확인해주는 이중 검수 시스템을 코드에 붙이는 것과 같습니다.

## 이걸로 할 수 있는 것
1. `ig-dashboard`의 `server.js`, `deploy.js`에 토큰이나 API 키가 평문으로 박혀있지는 않은지, 서버 경로 처리에 구멍은 없는지 한 번의 명령으로 점검한다.
2. 고객사에 납품하는 Claude Code 자동화 스크립트를 넘기기 전에 이 스킬로 감사를 돌려, "보안 점검 완료" 리포트를 첨부해 신뢰도를 높인 유료 납품물로 만든다.
3. 매번 새 자동화 스크립트(디이제스트 브리핑, 사이클 산출 등)를 만들 때마다 커밋 전 습관적으로 1회 감사를 돌려, 실수로 민감정보를 커밋하거나 안전하지 않은 패턴을 쓰는 것을 미리 막는다.

## 개요
Cloudflare가 공개한 코딩 에이전트용 스킬로, 단순히 "취약점 찾아줘"에 그치지 않고 발견 → 독립 검증 → 기계가 읽을 수 있는(JSON 등) 리포트 생성까지 3단계 파이프라인으로 오탐(false positive)을 줄이는 것이 핵심 가치입니다. 설치만 하면 되는 스킬 형태라 별도 인프라 없이 Claude Code에 바로 추가해 쓸 수 있고, 개인 프로젝트뿐 아니라 고객 납품물의 "보안 점검필" 마크로도 활용 가능합니다.

## 구현 가능성: 상
- 근거: Cloudflare라는 신뢰할 수 있는 조직이 만들었고 이번 주 +1.5만 스타로 검증된 인기 프로젝트임. README 안내대로 설치만 하면 되는 표준 Claude Code 스킬 형태라 커스텀 개발이 필요 없고, 비용도 거의 들지 않아 개인 맥북 환경에서 바로 실행 가능.

## 필요 도구
- Claude Code (이미 보유, 무료 — 스킬 실행 환경)
- `cloudflare/security-audit-skill` 저장소 (무료, GitHub 공개)
- git (무료, macOS 기본 내장 또는 Homebrew)
- (선택) Cursor — 대안 실행 환경으로도 지원됨 (도구 자체는 이미 사용 중이면 추가 비용 없음)

## 구현 단계
1. `git clone https://github.com/cloudflare/security-audit-skill` 로 저장소를 받고 README의 Claude Code 설치 명령을 그대로 실행해 스킬을 등록한다.
2. `ai-info-radar` 저장소(특히 `server.js`, `deploy.js`가 있는 ig-dashboard 관련 폴더)를 대상으로 스킬을 실행해 1차 감사를 돌린다.
3. 리포트에서 토큰/시크릿 저장 방식, 서버 경로 처리(path traversal 등), 인증 없는 엔드포인트 여부를 중점적으로 확인한다.
4. High 이상 등급 항목만 우선 수정하고, Medium/Low는 리포트에 기록만 해두고 별도 백로그로 관리한다.
5. 앞으로 새 자동화 스크립트를 작성할 때마다 커밋 전 1회 이 스킬을 실행하는 것을 루틴으로 만든다 (필요하면 git pre-commit hook으로 연결 고려).
6. 고객 납품용 자동화 스크립트가 있다면, 감사 리포트를 정리해 "보안 검증 완료" 첨부 문서로 패키징해 납품물 신뢰도를 높인다.

## 예상 공수
- 스킬 설치 및 첫 실행: 30분~1시간
- ig-dashboard 대상 첫 감사 + High 항목 수정: 2~4시간 (발견 항목 수에 따라 변동)
- 루틴화(pre-commit hook 연결 등, 선택사항): 1~2시간
- 난이도: 하 (설치형 스킬이라 별도 개발 없이 바로 사용 가능)

## 리스크/유의점
- 스킬이 코드를 읽고 분석하는 과정에서 Claude Code 세션에 코드 내용이 노출되므로, 정말 민감한 시크릿이 이미 코드에 박혀 있다면 감사 전에 먼저 눈으로 훑어 제거부터 하는 것이 안전.
- "독립 검증" 단계가 있어도 오탐이 완전히 0은 아니므로, 리포트의 Low/Medium 항목까지 전부 맹신하지 말고 우선순위 판단은 사람이 최종적으로 내릴 것.
- 이번 주 +1.5만 스타로 급상승한 신규 인기 프로젝트라 버전업이 잦을 수 있음 — 정기적으로 저장소를 업데이트해 최신 감사 룰을 반영할 것.
