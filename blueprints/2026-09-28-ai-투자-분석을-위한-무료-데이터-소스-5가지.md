# AI 투자 분석을 위한 무료 데이터 소스 5가지 연결하기

## 쉽게 말하면
투자 분석용 AI를 "혼자 아는 척하는 조언가"가 아니라 "재무제표, 공시, 임상시험, 논문까지 실시간으로 찾아보는 리서치 어시스턴트"로 바꾸는 작업입니다. 증권사 API로 시세를, SEC EDGAR로 미국 기업 공시를, ROIC AI로 재무비율을, ClinicalTrials.gov와 PubMed로 바이오 종목의 임상·논문 데이터를 무료로 가져와 AI에게 연결해주는 것이라고 보면 됩니다.

## 이걸로 할 수 있는 것
1. 관심 종목의 최근 공시와 재무비율을 매일 아침 자동으로 요약받아 출근길에 확인한다.
2. 바이오 종목을 볼 때 임상시험 진행 단계와 관련 논문을 AI가 자동으로 찾아 투자 판단 근거로 제시받는다.
3. 국내 보유 종목의 시세·잔고를 증권사 API로 가져와 AI가 매수·매도 시그널이나 리밸런싱 제안을 생성하게 한다.

## 개요
5개의 무료 데이터 소스(증권사 API, SEC EDGAR, ROIC AI, ClinicalTrials.gov, PubMed)를 개인 MacBook에서 스크립트로 수집·정리한 뒤 AI(로컬 LLM 또는 Claude/ChatGPT API)에 연결해, "재무 → 공시 → 임상 → 논문"을 아우르는 입체적 기업 분석 파이프라인을 구축하는 것입니다. 비용 없이 데이터 인프라를 구축할 수 있어 개인 투자자도 기관 수준의 리서치 워크플로에 근접할 수 있다는 가치가 있습니다.

## 구현 가능성
**상** — 5개 소스 모두 무료 API 또는 무료 접근이 가능하다고 원문에 명시되어 있고, SEC EDGAR·PubMed·ClinicalTrials.gov는 공식 정부/기관 API로 안정성이 높습니다. 다만 국내 증권사 API는 계좌 개설·인증서 발급 등 진입 절차가 있어 초기 세팅에 시간이 소요됩니다.

## 필요 도구
- **한국투자증권 KIS Developers API** — 무료(계좌 필요, 인증키 발급) [공식 문서 확인 필요]
- **키움 Open API+** — 무료(계좌 필요, Windows 전용 가능성 있음 [공식 문서 확인 필요], MacBook에서는 REST 방식 API 또는 클라우드 중계 필요)
- **SEC EDGAR API** (sec.gov/edgar) — 무료, 가입 불필요
- **ROIC AI** — 무료 기준 존재(범위 제한 가능성) [공식 문서 확인 필요]
- **ClinicalTrials.gov API** — 무료, 가입 불필요
- **PubMed E-utilities (NCBI API)** — 무료, 가입 불필요(대량 호출 시 API 키 권장 [공식 문서 확인 필요])
- **Python 3.x** — 무료, 데이터 수집·가공 스크립트용
- **requests, pandas** 라이브러리 — 무료
- **Claude API 또는 ChatGPT API** — 유료(사용량 과금), 데이터 요약·분석용
- **cron 또는 macOS launchd** — 무료, 정기 자동 실행용
- **Notion API 또는 로컬 Markdown/CSV 저장** — 무료, 결과 아카이빙용

## 구현 단계
1. 한국투자증권 또는 키움 등 증권사에서 모의/실전 계좌를 개설하고 Open API 사용 신청 후 App Key·Secret을 발급받는다.
2. MacBook에 Python 가상환경을 만들고 requests, pandas 라이브러리를 설치한다.
3. 증권사 API 공식 문서를 참고해 인증 토큰 발급 → 보유종목·시세 조회 스크립트를 작성한다.
4. SEC EDGAR API(전체 텍스트 검색/재무 데이터 엔드포인트)를 호출해 관심 미국 상장사의 최근 공시 목록을 가져오는 스크립트를 추가한다.
5. ROIC AI 사이트의 무료 접근 범위를 확인하고, API가 있다면 재무비율 데이터를, 없다면 웹 스크래핑 대신 수동 확인 절차를 설계한다 [공식 문서 확인 필요].
6. 바이오 종목이 관심사라면 ClinicalTrials.gov API로 임상 단계·완료 예정일을, PubMed E-utilities로 관련 논문 초록을 가져오는 함수를 작성한다.
7. 수집된 데이터(시세, 공시, 재무비율, 임상, 논문)를 하나의 JSON/Markdown 문서로 종목별 정리한다.
8. 이 정리본을 Claude API 또는 ChatGPT API에 프롬프트로 전달해 "재무-공시-임상-논문 종합 분석" 요약을 받는 로직을 작성한다.
9. macOS launchd 또는 cron으로 매일/매주 정해진 시간에 스크립트를 자동 실행하도록 등록한다.
10. 결과를 로컬 Markdown 파일이나 Notion 등에 누적 저장해 히스토리를 관리한다.

## 예상 공수
- 증권사 API 연동(계좌 개설, 인증, 시세 조회): 3~5시간 [추정]
- SEC EDGAR / PubMed / ClinicalTrials.gov 스크립트 작성: 각 1~2시간, 총 4~6시간 [추정]
- ROIC AI 연동 방식 확인 및 구현: 1~3시간 (API 유무에 따라 변동) [추정]
- AI 요약 파이프라인 구축(프롬프트 설계 포함): 2~4시간 [추정]
- 자동화(cron/launchd) 및 저장 로직: 1~2시간 [추정]
- **총 예상 공수: 11~20시간** [추정], **난이도: 중** (프로그래밍 기초 필요, API 인증 절차가 번거로울 수 있음)

## 리스크/유의점
- 증권사 API는 실거래와 연동되므로 자동 매매 로직을 추가할 경우 반드시 모의투자로 충분히 검증한 뒤 실전 적용해야 하며, 손실 책임은 전적으로 본인에게 있습니다.
- ROIC AI의 "무료" 범위(최근 2분기 등)는 원문 캡션에 언급된 수준이며, 정확한 API 제공 여부와 요청 제한은 공식 문서 확인이 필요합니다 [공식 문서 확인 필요].
- PubMed·SEC EDGAR 등은 대량 요청 시 API 키 등록이나 호출 제한(rate limit)이 있을 수 있어 공식 문서를 반드시 확인해야 합니다 [공식 문서 확인 필요].
- AI 요약은 참고용 정보일 뿐 투자 자문이 아니므로, 최종 투자 판단은 반드시 본인의 검토와 책임 하에 이루어져야 합니다.
- 개인 계좌 인증키·API 키는 외부에 노출되지 않도록 로컬 환경변수나 macOS Keychain 등에 안전하게 보관해야 합니다.
