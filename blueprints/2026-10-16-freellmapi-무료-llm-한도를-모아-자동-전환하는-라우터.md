# FreeLLMAPI로 주식 트레이드 분석 작업, 클로드 한도 걱정 없이 돌리기

## 쉽게 말하면
여러 AI 회사가 공짜로 풀어둔 사용량 한도를 하나의 버스 정류장처럼 모아놓고, 타고 있던 버스(모델)가 만차(한도 소진)가 되면 자동으로 다음 버스로 갈아태워주는 도구입니다. 클로드 코드로 트레이딩 분석 코드를 짜다가 한도가 차서 멈추는 대신, 알아서 다른 무료 모델로 넘어가 작업을 이어갑니다.

## 이걸로 할 수 있는 것
1. 매일 장 마감 후 보유 종목 뉴스·공시를 요약하는 클로드 코드 스크립트를 한도 걱정 없이 매일 반복 실행한다.
2. 백테스트 전략 코드를 클로드 코드로 작성시키다 한도가 끝나면 자동으로 다른 무료 모델이 이어받아 작업을 완성한다.
3. 여러 종목을 동시에 훑는 스크리닝 스크립트를 디버깅하는 긴 세션 작업을 중간에 끊김 없이 진행한다.

## 개요
Claude Code(또는 Codex, Cursor)의 API 한도가 소진되면 여러 회사의 무료 LLM(약 470여 종으로 안내됨)으로 자동 전환해주는 라우터입니다. 주식 트레이드 관점에서는 "실매매 신호 생성"이 아니라 데이터 분석·백테스트 코드 작성 같은 **코딩 보조 작업**을 끊김 없이 지속시켜주는 가치가 있습니다. 다만 제작자가 직접 "개인 실험·학습용, 프런티어 모델 아님"이라고 명시했으므로 실제 매매 판단에 쓰는 용도로는 부적합합니다.

## 구현 가능성: 중
- 실존 저장소가 웹서치로 확인되었고(MIT 라이선스, 약 3.4만 스타, 2026-10-16 기준 출처는 10월 14일 집계), Claude Code/Codex/Cursor 연동이 명시되어 있음.
- 다만 각 제공사 무료 키 발급은 사용자가 직접 해야 하고, 무료 티어 정책이 외부 요인으로 바뀔 수 있어 "설치 후 바로 완성형"은 아님.

## 필요 도구
- Node.js / npm (npx 실행용, 무료) [공식 문서 확인 필요: 요구 버전]
- GitHub 계정 (무료, 저장소 확인용)
- Claude Code CLI (Anthropic, Pro/Max 구독 또는 API 과금 필요 — 유료)
- 각 LLM 제공사 무료 API 키 — 예: Google AI Studio(Gemini), Mistral, Moonshot(Kimi), Zhipu(GLM), Alibaba(Qwen) 등 (대부분 무료 티어, 가입 필요) [공식 문서 확인 필요: 지원 제공사 전체 목록]
- (선택) Cursor, Codex — 해당 도구를 이미 쓰고 있다면 추가 설치 불요

## 구현 단계
1. github.com/tashfeenahmed/freellmapi 저장소를 직접 방문해 README를 읽는다 (댓글을 남기거나 DM을 받을 필요 없음).
2. 터미널에서 `node -v`로 Node.js 설치 여부를 확인한다 [추정: 버전 요구사항은 README 확인 필요].
3. Google AI Studio, Mistral, Moonshot 등 사용하려는 제공사 사이트에 본인 이메일로 가입해 무료 API 키를 각각 발급받는다.
4. `npx freellmapi setup-claude` 명령으로 Claude Code에 라우터를 연결한다(원문 명시 명령어).
5. 발급받은 API 키들을 설정 파일 또는 환경변수에 등록한다 [공식 문서 확인 필요: 정확한 입력 방식].
6. 설정에서 "작업 메모 이어받기" 옵션을 켠다(원문에 "한 줄 설정으로 작동"이라 언급됨).
7. 가벼운 테스트부터 시작한다 — 예: 특정 종목 OHLCV 데이터를 불러와 이동평균을 계산하는 스크립트 작성을 클로드 코드에 요청해 정상 전환되는지 확인한다.
8. 문제없으면 일일 뉴스 요약, 백테스트 코드 생성 등 반복 작업에 투입하되, 폴백 모델로 전환된 결과물은 매번 사람이 직접 검수한다.

## 예상 공수
- 초기 설치 및 Claude Code 연결: 약 1~2시간
- 제공사별 무료 키 발급: 종목당 10~20분, 3~4곳 가입 시 약 1시간 추가
- 총 2~3시간 소요 [추정]
- 난이도: 중 (CLI 사용 경험 필요, 여러 서비스 가입 절차 수반)

## 리스크/유의점
- 제작자가 "개인 실험·학습용이며 프런티어 모델이 아니다"라고 명시 — 실매매 자동화나 금전적 의사결정에 직접 연결하는 용도로는 쓰지 말 것.
- 한도 소진 후 전환되는 폴백 모델은 품질이 떨어질 수 있어, 트레이딩 전략 코드에 버그가 섞일 위험이 있음 — 반드시 사람이 결과를 검수.
- 월 74억 토큰 수치는 제작자의 계산치일 뿐 보장된 값이 아님(원문 언급).
- 여러 제공사 API 키를 발급·보관해야 하므로 키 유출 등 보안 관리에 유의.
- 각 제공사의 무료 티어 정책은 예고 없이 변경될 수 있어, 구성이 어느 시점에 깨질 수 있음.
- 개인 오픈소스 프로젝트이므로 유지보수 중단 가능성 존재.
