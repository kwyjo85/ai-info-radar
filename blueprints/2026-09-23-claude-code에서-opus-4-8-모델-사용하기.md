# Claude Code에서 Opus 4.8 모델 사용하기

## 쉽게 말하면
Claude Code는 기본적으로 "가장 최신 모델"을 자동으로 골라 쓰지만, 사실은 메뉴에서 예전 버전의 오�스(Opus) 모델을 직접 골라 쓸 수도 있습니다. 마치 스마트폰 앱을 자동 업데이트하지 않고 "이전 버전이 더 안정적이었으니 그걸로 돌아가겠다"고 선택하는 것과 같습니다. 이걸 알면, 용도에 따라 "최신·비싼 모델"과 "구형·저렴하거나 더 안정적인 모델"을 작업별로 골라 쓸 수 있습니다.

## 이걸로 할 수 있는 것
1. Jev 관련 자동화 스크립트에서 비용이 중요한 반복 작업(예: 정보 레이더 요약 생성)은 구형 Opus로 돌리고, 중요한 최종 검수만 최신 모델로 돌려 API 비용을 절감한다.
2. 특정 프로젝트에서 최신 모델이 예상과 다르게 동작할 때, 이전에 검증됐던 Opus 4.8로 되돌려 코드 리뷰나 블루프린트 생성 품질을 다시 안정화한다.
3. 고객사(예: 코코베이비, adtek)에 "모델 버전 고정으로 결과 재현성을 보장하는 자동화 파이프라인"을 판매 포인트로 제시할 때, 실제로 모델 버전을 고정하는 방법을 시연한다.

## 개요
이 항목은 Claude Code의 모델 선택 UI(`/model` 또는 설정)에서 기본 목록에 없는 구형 Opus 버전을 수동으로 지정하는 방법을 다룹니다. 자동화 파이프라인을 만들 때 "어떤 모델을 언제 쓸지"는 비용과 품질을 동시에 잡는 핵심 레버이므로, 이 정보를 알면 Jev 기반 자동화나 Claude Code 활용 컨설팅에서 실질적인 최적화·차별화 포인트가 됩니다.

## 구현 가능성
**상** — 근거: Claude Code는 이미 모델 선택 기능(`/model`)을 공식 제공하고, 이 글은 그 안에서 목록에 노출되지 않는 구형 버전을 선택하는 방법(모델 ID 직접 입력 또는 설정 파일 수정)을 설명하는 수준의 팁입니다. 별도 개발 없이 설정만으로 개인 맥북에서 바로 적용 가능합니다.

## 필요 도구
- Claude Code CLI (이미 사용 중, 무료 설치·유료는 API 사용량 기준)
- Anthropic API 키 또는 Claude 구독 (기존 보유, 추가 비용 없음)
- `claude-api` 스킬 문서 (모델 ID 확인용, 무료·내장)
- 텍스트 에디터로 `settings.json` 편집 (무료, 기존 환경)

## 구현 단계
1. `claude-api` 스킬을 열어 현재 사용 가능한 Opus 계열 모델 ID 목록(구형 포함)을 확인한다.
2. 터미널에서 Claude Code 실행 후 `/model` 명령으로 현재 모델 선택 UI를 확인하고, 목록에 원하는 구형 Opus가 보이는지 확인한다.
3. 안 보이면 원문 아티클(osr.im 노트)에 나온 방법대로 `~/.claude/settings.json` 또는 프로젝트 `.claude/settings.json`에 `model` 필드를 구형 Opus의 정확한 모델 ID로 직접 지정한다.
4. `ai-info-radar` 저장소의 자동화 스크립트(예: 다이제스트 생성, 블루프린트 생성 로직)에서 작업 성격별로 모델을 분기하도록 설정 — 예: 요약/1차 초안은 구형 Opus, 최종 검수·고객 제출본은 최신 모델.
5. 동일 입력에 대해 신·구 모델 결과물을 비교(비용, 응답 품질, 속도)하여 실제로 구형 모델을 쓸 가치가 있는 작업을 표로 정리한다.
6. 검증된 모델 분기 규칙을 `blueprints/` 문서로 남겨, 향후 Jev나 다른 자동화에 재사용·판매 자료로 활용한다.

## 예상 공수
- 설정 적용: 15~30분 (난이도: 하)
- 신·구 모델 비교 실험 및 문서화: 1~2시간 (난이도: 중)

## 리스크/유의점
- 구형 모델은 언젠가 지원 종료(deprecation)될 수 있어 자동화에 하드코딩 시 갑자기 실패할 위험이 있음 — 모델 ID를 설정 파일 한 곳에서만 관리하도록 구조화 필요.
- 구형 Opus가 최신 모델 대비 특정 작업(코딩, 한국어 생성 등)에서 품질이 떨어질 수 있으므로, 고객 대상 산출물에는 반드시 최신 모델로 최종 검수하는 절차를 병행해야 함.
- 이 정보의 출처가 비공식 개인 블로그(osr.im)이므로, 설정 필드명이나 방법이 실제 Claude Code 최신 버전과 다를 수 있어 적용 전 반드시 현재 버전에서 직접 확인 필요.
