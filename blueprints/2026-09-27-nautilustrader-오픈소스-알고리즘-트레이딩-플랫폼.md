# NautilusTrader: 오픈소스 알고리즘 트레이딩 플랫폼

## 쉽게 말하면
NautilusTrader는 "주식·코인 자동매매 로봇을 만드는 공장 설비"라고 생각하면 됩니다. 과거 데이터로 전략을 실험(백테스트)하고, 검증되면 같은 코드로 실제 계좌에서 자동으로 사고팔게 만들어주는 무료 오픈소스 엔진입니다. 핵심 엔진은 Rust로 빨라서, 전략 로직만 파이썬으로 짜면 되는 구조입니다.

## 이걸로 할 수 있는 것
1. 매일 밤 잠들기 전, 내가 짠 매매 전략을 지난 몇 년치 데이터로 자동 재검증해서 다음날 아침 결과 리포트를 받아본다.
2. AI(LLM)가 뉴스·공시를 분석해 만든 매수/매도 신호를 이 엔진에 연결해, 사람이 화면을 안 봐도 자동으로 소액 주문이 나가게 한다.
3. 여러 개의 전략(모멘텀, 평균회귀, 뉴스기반 등)을 동시에 백테스트해서 어떤 조합이 내 계좌 성향에 맞는지 비교 분석한다.

## 개요
이 도구는 "전략 아이디어 → 과거 데이터 검증 → 실전 자동매매"까지 한 코드베이스로 이어주는 자동화 파이프라인입니다. 리서치와 실거래 사이의 괴리(백테스트 따로, 실전 따로 짜야 하는 문제)를 없애주는 것이 핵심 가치이며, AI가 생성한 신호를 실제 주문 실행으로 연결하는 "마지막 단계" 인프라 역할을 합니다.

## 구현 가능성 — 중
- 근거: 엔진 자체는 무료·오픈소스이고 문서화가 잘 되어 있어 설치·백테스트까지는 개인 맥북에서 무리 없이 가능합니다.
- 다만 국내 증권사(키움, 한투 등)는 Nautilus 공식 어댑터가 없어 직접 커스텀 어댑터를 만들어야 하며, 이 부분이 진입장벽입니다. 해외 거래소(Binance, Interactive Brokers 등)는 어댑터가 이미 있어 상대적으로 쉽습니다.

## 필요 도구
- **NautilusTrader** (오픈소스, 무료) — pip install nautilus_trader
- **Python 3.11+** (무료)
- **Rust 툴체인** — 일부 성능 컴포넌트 빌드용 (무료, 선택적)
- **시장 데이터 소스**: 해외 주식/코인은 Interactive Brokers API, Binance API(무료 티어), Polygon.io(유료 플랜 권장) 등
- **국내 증권 연동 시**: 한국투자증권 Open API(무료, 신청 필요) — 단, 별도 어댑터 직접 구현 필요
- **AI 신호 생성**: Claude API 또는 로컬 LLM (뉴스 요약 → 매매신호 변환용, 유료 API 호출 비용 발생)
- **백테스트용 과거 데이터**: 무료(Binance 공개 데이터) 또는 유료(Polygon, Tiingo 등)
- **Docker** (선택, 배포 격리용, 무료)

## 구현 단계
1. 맥북에 Python 가상환경을 만들고 `pip install nautilus_trader`로 설치, 공식 예제 백테스트 스크립트를 그대로 돌려 정상 동작 확인.
2. 관심 있는 자산(예: 미국 ETF, 비트코인)의 과거 데이터를 Parquet 형식으로 Nautilus 카탈로그에 적재.
3. 간단한 전략(이동평균 교차 등)을 파이썬으로 작성해 1~2년치 데이터로 백테스트하고 손익 곡선을 확인.
4. 기존 AI 정보수집(ai-info-radar) 파이프라인에서 생성되는 뉴스 요약/스코어를 신호로 변환하는 어댑터 함수를 추가로 작성(뉴스 감성 → buy/sell/hold 신호).
5. 이 신호를 Nautilus 전략의 입력으로 연결해 백테스트 재실행 — AI 신호 유무에 따른 성과 차이 비교.
6. 결과가 유의미하면 Interactive Brokers 또는 Binance 테스트넷(paper trading)에 연결해 모의 실거래로 2~4주 검증.
7. 문제없으면 소액 실계좌로 전환하되, 반드시 일일 손실 한도(kill switch)를 코드에 하드코딩.
8. 국내 종목 매매가 필요하면 이 시점에 한투 Open API용 커스텀 어댑터를 별도 프로젝트로 개발.

## 예상 공수
- 설치 및 기본 백테스트 실행: 4~6시간 (난이도: 하)
- 간단 전략 작성·검증: 8~15시간 (난이도: 중)
- AI 신호 파이프라인 연동: 15~25시간 (난이도: 중~상)
- 실거래(해외) 연결 및 모의 검증: 10~20시간 (난이도: 상)
- 국내 증권사 커스텀 어댑터 개발: 40시간+ (난이도: 상, 별도 프로젝트급)

## 리스크/유의점
- 자동매매는 코드 버그가 곧 실제 금전 손실로 직결되므로, 반드시 페이퍼 트레이딩/모의계좌 검증을 충분히 거쳐야 합니다.
- 백테스트 성과가 좋아도 과최적화(overfitting)일 가능성이 높아, out-of-sample 검증과 소액 실전 테스트가 필수입니다.
- 국내 규제상 알고리즘 매매는 증권사 신고·API 약관 확인이 필요할 수 있으니 사전 확인 권장합니다.
- LLM 기반 신호는 지연시간과 API 비용이 발생하므로, 초단기 매매보다는 일봉 이상 저빈도 전략에 적합합니다.
- Rust 빌드 환경 이슈나 어댑터 미지원으로 인해 초기 설정에서 예상보다 시간이 더 걸릴 수 있습니다.
