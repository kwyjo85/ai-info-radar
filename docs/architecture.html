DOC시스템 설명

AI Info Radar는 "AI 기반 업무 효율화·자동화" 관련 정보를 자동으로 수집·선별해서, 실제로 구현할 가치가 있는 것만 골라 매일 아침 텔레그램으로 물어보는 개인용 정보 레이더입니다. 집 MacBook에서 30분 배치로 조용히 돌아가며, 사람이 하는 일은 아침 브리핑에서 버튼 하나 누르는 것뿐입니다.

무엇을 해결하나

  • 정보 과잉 — RSS·Threads·YouTube에 흩어진 AI 자동화 소식을 일일이 찾아볼 필요 없음
  • 선별 피로 — Claude가 관련도 0~100점으로 채점하고 3줄로 요약. 70점 이상만 눈에 들어옴
  • "그래서 어떻게 만들지?" — 고득점 항목은 필요 도구·단계·공수가 담긴 구현 블루프린트가 자동 생성됨
  • 실행 연결 — 텔레그램에서 [구현 진행]을 누르면 Claude Code 작업 지시 파일로 변환되어 바로 개발 착수 가능

설계 원칙

  • 비용 0원 우선 — LLM 호출은 Claude 구독(CLI 헤드리스)을 사용. 필요 시 LLM_BACKEND=api 한 줄로 API 전환
  • 공인 IP 불필요 — 텔레그램 롱폴링 방식이라 포트포워딩·서버 없이 집 맥북으로 충분
  • 사용량 보호 — 실행당 점수 30건·블루프린트 5건 상한으로 구독 한도를 지킴
  • 자동 복구 — 봇은 KeepAlive로 크래시·재부팅 시 자동 재시작, Threads 토큰(60일)은 만료 전 자동 갱신
  • 보안 — 모든 토큰은 .env에만 저장(gitignore), 로그에 토큰이 남지 않도록 차단

GUIDE사용자 매뉴얼

평소에는 아무것도 안 해도 됩니다. 아래는 일상 사용법과 필요할 때 찾아 쓰는 명령 모음입니다.

1. 매일 아침 루틴 (유일한 일상 업무)

  1. 08:00에 텔레그램(@ai_info_radar_bot)으로 상위 5건 브리핑이 도착
  2. 각 항목의 버튼으로 결정:
    • [블루프린트 보기] — 구현 계획 전문을 채팅으로 받아봄
    • [구현 진행] — tasks/pending/에 작업 파일 저장됨. Claude Code를 열고 해당 파일로 구현 시작
    • [스킵] — 관심 없음 처리
  3. 지금 당장 브리핑을 받고 싶으면 봇에게 /brief 전송

2. 대시보드 보기

cd ~/Documents/cocobaby/ai-info-radar
uv run streamlit run dashboard/app.py

브라우저에서 http://localhost:8501 — 피드(카드)·테이블·블루프린트 탭, 사이드바에서 점수/카테고리 필터.

3. 수집 소스 편집

파일내용
config/keywords.yamlThreads 검색 키워드 (심사 통과 후 사용됨)
config/feeds.yamlRSS 피드 URL 목록, YouTube 채널 ID 목록

저장만 하면 다음 30분 사이클부터 자동 반영. YouTube 채널 ID는 채널 페이지 → 더보기 → 채널 공유 → 채널 ID 복사.

4. 수동 실행 명령 모음

# 지금 즉시 수집+처리 한 사이클 돌리기
uv run python -m scripts.cycle

# 수집만 / 처리만
uv run python -m collectors.run
uv run python -m pipeline.process

# Threads 토큰 재발급(60일) / 수동 갱신
uv run python scripts/threads_auth.py auth
uv run python scripts/threads_auth.py refresh

5. 자동화(launchd) 관리

# 상태 확인 (PID가 보이면 실행 중)
launchctl list | grep ai-info-radar

# 사이클 즉시 실행
launchctl kickstart gui/$(id -u)/com.ai-info-radar.cycle

# 중지 / 재시작 (봇)
launchctl bootout gui/$(id -u)/com.ai-info-radar.bot
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.ai-info-radar.bot.plist

6. 로그 확인 (문제 생겼을 때 제일 먼저)

파일내용
logs/launchd.cycle.log30분 사이클 전체 (수집+처리)
logs/launchd.bot.log텔레그램 봇
logs/collect.log / process.log수집 / 처리 개별 로그

7. 자주 겪는 문제

증상원인 · 해결
브리핑이 안 옴맥북이 잠들어 있음 → 전원 연결 + 배터리 설정에서 자동 잠자기 끄기, 또는 caffeinate -s
처리 로그에 "claude CLI 실패"OAuth 토큰 만료 → 터미널에서 claude setup-token 재발급 후 .env의 CLAUDE_CODE_OAUTH_TOKEN 교체
threads "권한 없음" 경고정상 (App Review 승인 전). 심사 통과하면 자동 활성화
봇이 응답 없음launchctl list로 확인 → 위 5번 명령으로 재시작
Threads 토큰 만료(60일)사이클이 자동 갱신하지만, 60일 이상 완전히 꺼두었다면 auth로 재발급
⚠️ 유일한 정기 관리 포인트: 맥북이 전원 연결 + 슬립 방지 상태인지, 그리고 텔레그램 브리핑이 매일 오는지만 확인하면 됩니다. 브리핑이 이틀 연속 안 오면 logs/launchd.cycle.log부터 보세요.
